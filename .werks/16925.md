With this werk we back-pick an early, experimental preview of the reworked "All hosts" monitoring
view from our next major release into Checkmk 2.5.0. We do this so you can try the next
generation of the monitoring user interface long before it becomes the default, and so we can
gather real-world feedback - on usability, on performance in large environments and on the
workflows you miss - while it is still taking shape.

What you can expect from it today: The page lists all monitored hosts with their host state,
IP address and the number of services per service state, plus status icons (for example when
a host is acknowledged or in a scheduled downtime). You can search, filter per column and sort
the list, open a slide-in panel with a host's details, and run the most common monitoring
actions right from the page - acknowledge, schedule a downtime, reschedule the check - as well
as jump to a host's Setup pages. It is experimental for a reason, though: Its scope is
deliberately limited, you may still hit rough edges, and both its look and its behaviour will
still change substantially.

How to enable and disable it: There is no global on/off switch - the preview simply lives next
to the classic view. Open it with the *Try the new "All hosts" view* button on top of the
classic "All hosts" view, and leave it again with the *Return to standard view* button (or
just navigate away as usual). The classic view stays your default and is untouched, so
"disabling" the preview merely means not opening it.

What comes next: Over the coming patch releases we will keep extending the page - more columns
and filters, further monitoring views beyond hosts, and better performance and interaction - with
the long-term goal of matching and then surpassing the classic view, so that it can replace it.

How to give us feedback: Use the *Give feedback on the new view* link on the experimental
page, the Checkmk forum at https://forum.checkmk.com, or feedback@checkmk.com. What we learn
during this experimental phase is exactly what will decide how the new monitoring interface
evolves - so please do not hold back!
