# BI: Differences between frozen and live aggregations not being shown correctly

The view *All differences in frozen aggregations* missed some differences
entirely, and showed the wrong states for the rest.

Changing only how a rule is configured — its aggregation function, say —
without adding or removing any node counted as no difference at all. Such a
node is now marked, and it tells you what actually changed, for example
*aggregation function: best → worst*.

The tree on the right was computed with the frozen rules, so it showed frozen
states rather than what the live aggregation reports: a node you switched from
*best* to *worst* still read OK while the live aggregation was CRIT. It now
shows the live states. Nodes you removed since freezing are still listed, so
you can see that they are gone.

*Freeze aggregations* in that view did nothing at all — it looked for the
snapshot under the wrong name — so the aggregation stayed frozen on its old
structure.
