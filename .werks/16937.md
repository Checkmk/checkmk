# Agent slideout without bakery: working Linux install command

Without access to the Agent Bakery (always in Checkmk Community, missing
permissions in the commercial editions), the *Linux* tab of the agent
installation slideout had three flaws:

* The download URLs contained a literal `{SERVER}/{SITE}` instead of your
  Checkmk server and site, so copying the commands did not work.
* Both the RPM and the DEB download command were shown, regardless of the
  selected package format, and no install step was offered.
* A TGZ toggle was offered without any command behind it.

The slideout now shows a single command for the selected package format that
downloads and installs the agent, e.g. for DEB:

```
wget https://myserver/mysite/check_mk/agents/check-mk-agent_<version>-1_all.deb && \
sudo dpkg -i check-mk-agent_<version>-1_all.deb
```

The TGZ toggle is only shown when there is a TGZ command to show.
