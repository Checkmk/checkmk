# Tag usage: Show 'one of'/'none of' rules

The *Tag usage* page (*Setup > Hosts > Tags > Tag usage*) did not list rules
in the *Used in rule sets* column if they use the tag in a host tag condition
with *one of* or *none of*. Only conditions with *is* and *is not* were found.

The same blind spot also affected deleting or renaming a tag. Rules that
used the tag in a *one of* or *none of* condition were not adjusted and kept
referencing the old tag ID.

Now, all of these conditions are taken into account. When you rename a tag, it
is renamed inside the list as well. When you delete a tag, it is removed from
the list. If the list ends up empty, a *none of* condition is dropped, while a
*one of* condition is treated like an *is* condition: depending on your choice,
the condition or the whole rule is removed.
