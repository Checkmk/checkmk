# Windows HW/SW inventory: IPv6 routes

key        | value
---------- | ---
date       | 2026-10-21T11:08:03.318669+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | checks
level      | 1
compatible | yes

The Windows agent plugin `mk_inventory.ps1` now also reports IPv6 routes
in the section `win_ip_r`. They show up in the HW/SW inventory under
`networking/routes`, next to the IPv4 routes, including the IPv6 default
gateway.

To get the IPv6 routes, update the agent plugin `mk_inventory.ps1` on the
monitored Windows hosts.
