# Windows HW/SW inventory: gateway removed from network adapters

key        | value
---------- | ---
date       | 2026-10-21T11:09:30.144992+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The gateway is network configuration, not hardware. For Windows hosts the
HW/SW inventory showed it under `hardware/nwadapter`, with IPv4 and IPv6
gateways lumped together into one field.

The gateway column has been removed from `hardware/nwadapter`. The gateways
are available in `networking/routes`. IPv6 routes require the updated agent
plugin `mk_inventory.ps1` (see [werk 16941](https://checkmk.com/werk/16941)).
