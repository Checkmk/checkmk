# Varnish Worker Thread Ratio: always 100%

key        | value
---------- | ---
date       | 2026-10-21T11:14:53.329133+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1

The service *Varnish Worker Thread Ratio* always reported 100% as long as
there was at least one worker thread, so its lower levels never triggered.

The ratio is now computed again as the number of worker threads divided by
the number of created worker threads.
