# Events link ignores explicit host

---------- | ---

edition    | community

A "Check event state in Event Console" service whose rule uses
_Specify host explicitly_ has an _Events_ icon whose title names the
explicitly specified host. The link, however, opened the events of the
monitored host, so the events that set the service state were not
shown.

The link now opens the events of the explicitly specified host.
