# Folder dropdown ignored the rule's folder

class      | fix
edition    | community
component  | wato

compatible | yes

When editing a rule with explicit conditions, the folder dropdown opened at
the top of the list with "Main" highlighted, instead of highlighting the
folder that is actually configured. With many folders, or with folders of the
same name below different parents, you could not tell which folder the rule
was bound to.

The configured folder is now highlighted and scrolled into view when the
dropdown opens. As soon as you type into the filter field, the first match is
highlighted, as before.

This affected all dropdowns of the new form rendering with more than five
choices, i.e. those that show a filter field.
