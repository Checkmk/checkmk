# Network topology: improved performance when fetching data from the core

---------- | ---

edition    | cre

The network topology tends to create quite big livestatus file when it specifically asked for hosts and service.
This led to a significant performance issue: some pages took more than 20 seconds to load.
The filtering mechanism has been improved, so that retrieving the data now takes less than 0.5 seconds again.
