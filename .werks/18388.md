# Config anonymizer: Record edition and version of the source site

key        | value
---------- | ---
date       | 2026-11-26T11:03:40+00:00
class      | feature
edition    | community
component  | wato
level      | 1
compatible | yes


`cmk-config-anonymizer` now writes a file `metadata.json` into the target
directory, next to the anonymized `etc/` and `var/` directories. It records
the edition and the version of the site the configuration was taken from:

```
{
    "edition": "ultimatemt",
    "version": "2.5.0p23"
}
```

The anonymized files alone do not tell which Checkmk edition and version
created them. Whoever loads such a configuration into another site needs this
information to set up a matching site.

In addition, this Werk fixes a crash in Checkmk Ultimate with Multi-Tenancy:
The anonymization stopped with an error like
_Unknown host group spec customer_ if a host group or a service group was
assigned to a customer. The customer of these groups is now anonymized in the
same way as it already is for contact groups.
