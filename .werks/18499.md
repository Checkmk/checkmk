# Support Werk files without version

key        | value
---------- | ---
date       | 2026-07-23T08:04:44.815279+00:00
class      | feature
edition    | community
component  | packages
level      | 1
compatible | yes

Customers are not directly affected by this Werk.

It allows developers to create Werks without having to specify the Checkmk
version the Werk will be published with. This makes it easier to pick changes
between branches, and simplifies several edge cases in the release process.

Customers might notice small hiccups on the [Werks
website](https://checkmk.com/werks) or the [Werks mailing
lists](https://lists.checkmk.com/mailman3/postorius/lists/)
