# hp_proliant_da_cntlr: Configure the state of each reported value

The new rule "HPE ProLiant RAID controller" sets the monitoring state for
each value that a controller reports as its condition, board condition and
board status. Without the rule, the states stay as before.

The service output now shows condition, board condition and board status as
separate results, so it names the field that causes a WARN or CRIT. Two
board status values also read differently: "standby (offline)" is now
"standby offline", and "unavailable (offline)" is now "unavailable offline".
