# Eaton UPS environment sensors: fix "enviroment" typo in plugin and service name

The check plugin for temperature and humidity sensors of Eaton UPS devices, its
SNMP section and its service were misspelled as <tt>enviroment</tt>. The plugin
and section have been renamed to <tt>ups_eaton_environment</tt> and the service
description from <tt>Enviroment</tt> to <tt>Environment</tt>.

This change is compatible for existing installations:

- Services that were already discovered are migrated automatically to the new
  plugin name during the update, so no rediscovery is required.
- The service keeps its previous name <tt>Enviroment</tt> on existing sites, so
  historic metrics are preserved. To switch to the corrected name
  <tt>Environment</tt>, enable it under
  <i>Setup > Global settings > Use new service descriptions</i>
  (entry "Eaton UPS: temperature and humidity sensors"). New installations use
  the corrected name by default.

Note that switching to the corrected name <tt>Environment</tt> starts a new
metric history under the new service description; the graphs collected under the
previous name <tt>Enviroment</tt> are not carried over.
