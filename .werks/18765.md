# Distributed monitoring: Configuration connection shows "Read timed out" on busy remote sites

key        | value
---------- | ---
date       | 2026-11-09T10:38:03.614836+00:00
version    | 2.4.0p43
class      | fix
edition    | cre
component  | wato
level      | 1
compatible | yes

On _Setup > General > Distributed monitoring_, the configuration connection of
some remote sites showed `Read timed out. (read timeout=5)`, even though
activating changes on those sites worked.

To show this status, the central site asks each remote site for its version
and the state of its services. Since Checkmk 2.4, the remote site checked
the state of all its services for this, one after another. On busy servers,
for example servers that host many sites, this took longer than the 5 second
limit.

The remote site no longer checks its services for this. It reads from its
own configuration whether the message broker is enabled, which is all the
page needs. You do not need to change your configuration. The fix takes
effect once the remote sites are updated.
