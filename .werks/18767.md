# Detect HP printers with sysObjectID .0.0

Some HP JetDirect printers, for example the HP Color LaserJet Pro MFP 4302,
report the generic system object ID `.0.0` instead of an HP-specific one.
Checkmk uses the system object ID to tell whether an SNMP device is a printer,
so the service discovery on these devices found only interfaces, memory and
SNMP info, but no printer services.

Checkmk now also detects a printer if its system description starts with
`HP ETHERNET MULTI-ENVIRONMENT`. Run a service discovery on the affected hosts
to get the printer supply, input and output tray, alert and page counter
services.
