# Azure: Deprecation of the legacy Azure special agent and its check plug-ins

key        | value
---------- | ---
date       | 2026-10-14T10:50:58+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | checks
level      | 2
compatible | no

The legacy Azure special agent and its check plug-ins are now deprecated in
favor of the Azure special agent v2 that was introduced with Checkmk 2.5.

For more details on the Azure special agent v2, refer to Werk #19467.

In Checkmk 3.0, the rule sets of the legacy special agent, _Azure (deprecated)_,
and of its check plug-ins are deprecated. You can no longer create new rules
with them. Your existing rules still apply.

**In Checkmk 3.1, the legacy special agent and its check plug-ins will be
completely removed. Migration to the Azure special agent v2 must happen while
you are on Checkmk 3.0.**

**Historic data from the legacy special agent is lost when you migrate.**
Azure VMs are the exception: they keep their data as long as their host names
stay the same in v2. This is the default, because the option _Exclude VMs from
unique piggyback host names_ is enabled by default.

These check plug-ins are deprecated and replaced with their v2 counterparts.
Rules of the legacy check plug-ins are not migrated automatically. You must
create new rules for the v2 check plug-ins.
