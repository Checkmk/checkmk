# Keep some specific licenses on update and on new remote sites

In some edge cases, Checkmk lost some specific licenses:

* Updating a site removed its license, even on a patch update such as
  2.5.0p1 to 2.5.0p2. After the update the site was no longer licensed
  and started a new trial period, so you had to license it again.
* In distributed monitoring with central setup, a remote site that you
  added after licensing the central site did not receive the license. It
  only got it with the central site's next license verification.

In both cases, Checkmk wrongly considered the license data of these
licenses incomplete. Updates now keep these licenses, and new remote
sites receive them right away.
