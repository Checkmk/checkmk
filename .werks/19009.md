# Updating a site no longer removes some specific licenses

key        | value
---------- | ---
date       | 2026-10-01T15:17:31.534077+00:00
version    | 2.5.0p16
class      | fix
edition    | pro
component  | omd
level      | 1
compatible | yes

In some edge cases, updating a site removed its license, even on a patch
update such as 2.5.0p1 to 2.5.0p2. After the update the site was no
longer licensed and started a new trial period, so you had to license it
again.

This only affected some specific licenses: during the update, Checkmk
wrongly considered their license data incomplete and reset the licensing
state. The update now keeps these licenses.
