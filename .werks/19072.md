# Registration process for trial sites

Sites in trial period will now require the administrators to provide their email
address for registration purposes. Existing licensed sites will not be affected.

After logging in to a site in trial period, an administrator will be presented
with a new registration flow, which needs to be completed before the site can be
used.

Existing customers with a valid Checkmk license can complete the flow by
verifying their license (online or offline) or choosing to verify the license at
a later time.

In order to use the site for evaluation purposes, the administrator will be
requested to enter a valid email address during the registration flow. A one
time code will be mailed to the provided address for verification purposes.

The registration flow needs to be completed once per site.

REST API, command line tools, distributed monitoring, and other automation, as
well as normal site functionality (monitoring, background tasks, etc.) are not
affected, and can continue even without completing the registration flow.

During registration and trial period sites will attempt to establish an outgoing
HTTPS connection to our analytics service at the following DNS address:
`analytics.checkmk.com`. This is not a strict requirement: sites in restricted
environments (including air-gapped networks) will still be able to complete the
registration flow without any restrictions on Checkmk functionality.
