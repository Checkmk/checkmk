# OTel: Rotate the collector log file

key        | value
---------- | ---
date       | 2026-10-07T15:23:00.563504+00:00
version    | 3.0.0b1
class      | fix
edition    | ultimate
component  | omd
level      | 1
compatible | yes

Previously, the log file of the OpenTelemetry collector,
`~/var/log/otel-collector.log`, was never rotated and kept growing
indefinitely. The logrotate configuration of the site pointed to a
non-existent directory instead of the actual log file.

The collector log is now rotated like the other site logs. This also
applies to log files that already exist in your site, once you update
it to a version containing this fix.

The log is rotated with `copytruncate`, so the running collector keeps
writing to the active log file without needing a restart.
