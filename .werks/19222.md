# Windows agent: fix post-install flag handling during auto update

key        | value
---------- | ---
date       | 2026-07-15T12:53:02.416070+00:00
version    | 2.5.0p10
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The Windows agent installer did not correctly set and clear the post-install
flag due to reading MSI product information from the wrong registry location.
This caused the automatic update process to malfunction, and in particular
could complicate updates of the Python module.

Starting with this release, the installer reads MSI information from the
correct WOW6432Node registry path, ensuring the post-install flag is properly
managed and the auto update process works as expected.
