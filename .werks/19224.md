# mk-sql: instance name is correctly detected for standard deployments

version    | 2.5.0p14
class      | fix
edition    | community
component  | checks
level      | 2
compatible | yes

When monitoring Microsoft SQL Server, the agent used a query variant
intended for Azure SQL for every deployment. On standard (non-Azure) SQL
Server this could determine the instance name incorrectly. For example, a
default instance that had a FileStream share configured was reported
incorrectly under that name, so instance verification failed and the
instance was not monitored as expected.

Starting with this release, the agent selects the query variant appropriately.
Instance names are now determined consistently and correctly for either SQL
Server instances or Azure SQL.
