# Windows BIOS inventory: correct release date and no data loss when it is absent

The BIOS release date collected by the Windows inventory plug-in was interpreted as local time although the agent reports it in UTC, so the same machine was inventorized with a different date depending on the timezone of the monitoring server. On hosts whose firmware does not report a release date at all -- common on virtual machines -- reading the section failed completely, and the BIOS vendor, model and version were missing from the inventory as well.

Starting with this release, the release date is parsed as UTC including the offset sent by the agent, so the value no longer depends on the server's timezone. A firmware that reports no release date at all is skipped, so the BIOS vendor, model and version are inventorized as before. A release date that is present but does not follow the CIM_DATETIME format is now rejected instead of being coerced into a date the firmware never reported. Existing dates are corrected with the next inventory run.
