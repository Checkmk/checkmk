# Site update no longer aborts on dynamic host management connection names

key        | value
---------- | ---
date       | 2026-10-08T09:00:00.000000+00:00
version    | 2.5.0p16
class      | fix
edition    | pro
component  | dcd
level      | 1
compatible | yes

Checkmk 2.5.0p6 started to validate the names of dynamic host management
connections. That validation also ran during a site update: a connection whose
name is not a valid identifier - for example one containing a dot, such as
`test-vcenter.example.com` - made `cmk-update-config` abort, and the update
could not be completed. Such names were accepted in earlier versions, so
setups were affected without having been changed. The only remedy offered was
to rename the connection by hand.

Starting with this release, the validation is removed again. Connection names
are accepted as before, both when creating a connection in Setup and when
updating a site. Hosts managed by a connection whose name is not a valid
identifier still cannot be edited; that problem is addressed separately.
