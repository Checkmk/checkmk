# Show correct "installed size" during debian installation

---------- | ---

version    | 2.5.0p17
class      | fix
edition    | community
component  | omd

compatible | yes

Debian packages built for Checkmk now declare the Installed-Size field in
their control file. Previously the field was missing, so apt reported
"After this operation, 0 B of additional disk space will be used" when
installing Checkmk, which is not true.

apt now shows the actual disk space a package needs before you install it.
This applies to the Checkmk packages and to the Linux agent .deb packages
shipped with Checkmk. Agent packages built by the Agent Bakery already
included this field.
