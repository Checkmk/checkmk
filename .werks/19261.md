# Windows agent MSI: Ship signed PowerShell scripts

---------- | ---

version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Werk #19211 announced that the Windows agent MSI ships signed PowerShell
plugins. However, the PowerShell scripts inside `check_mk_agent.msi`
were not signed. On Windows hosts that only allow signed scripts
(execution policy `AllSigned`), the PowerShell plugins installed with
the agent did not run.

All PowerShell scripts inside the MSI are now signed. This includes
`mk_inventory.ps1` and `configure_and_exec.ps1`, the wrapper the agent
starts every PowerShell plugin with, which were not signed at all
before.

To get the signed scripts, update the agent on your Windows hosts.
