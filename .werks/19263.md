# Update Checkmk Docker Image to Ubuntu 24.04

The Checkmk Docker image is now based on Ubuntu 24.04 (Noble Numbat)
instead of Ubuntu 22.04 (Jammy Jellyfish), and contains the Checkmk
package built for Ubuntu 24.04. Standard support for Ubuntu 22.04 ends
in 2027.

Existing site volumes keep working: the site user still gets uid and gid
1000, so you can start a container from the new image with your existing
volume as usual.

You only need to take action if you build your own images on top of the
Checkmk Docker image, or if you use hook scripts in
`docker-entrypoint.d/` that rely on the operating system. In that case,
please check the following:

* The OS packages come from Ubuntu 24.04 and may have different versions
  or names.
* The APT sources are now configured in
  `/etc/apt/sources.list.d/ubuntu.sources` instead of
  `/etc/apt/sources.list`.
* The `dpkg-sig` package is no longer installed. It is not available on
  Ubuntu 24.04.
* The `ubuntu` user of the official Ubuntu 24.04 base image is removed
  from the Checkmk image.
