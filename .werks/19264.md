# Cease to provide builds for Ubuntu 22.04 (Jammy Jellyfish)

Builds for Ubuntu 22.04 are no longer delivered from Checkmk 3.0.0 on.

Ubuntu 22.04's standard support ends on 2027-06-01, shortly after the
3.0.0 release. If you run Checkmk on Ubuntu 22.04, upgrade the
operating system to Ubuntu 24.04 or later before updating to Checkmk 3.0.0.
