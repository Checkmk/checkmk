# Graph collections keep working when a host moves to another site

Previously, adding a graph to a graph collection also recorded the monitoring
site the host happened to be assigned to at that moment. When the host was later
moved to another site, the collection looked the host up on the old site, found
nothing, and the graph silently disappeared - leaving an empty spot where it used
to be, with no error to explain it.

Graph collections now store only what identifies the graph - the host, the
service and the graph itself - and resolve the site again each time the
collection is rendered.

Existing graph collections are migrated during the update, so graphs that already
stopped working after a host moved will come back on their own.
