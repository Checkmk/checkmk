# Views: Sort by the value of a single metric column

key        | value
---------- | ---
date       | 2026-09-30T07:23:10.643539+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | multisite
level      | 1
compatible | yes

Views can show the value of one metric per host or service in a
`Show single metric` column. These columns could not be sorted so far.

You can now sort a view by such a column: click its heading, or add the new
sorters `Service metric` or `Host metric` in the view's sorting settings and
pick the metric to sort by. Hosts or services that do not have the chosen
metric come first in ascending order.

A view with several single metric columns sorts by the one whose heading you
clicked.
