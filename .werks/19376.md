# Custom graphs: Nested calculations restored incorrectly in the graph editor

key        | value
---------- | ---
date       | 2026-10-27T11:56:22+00:00
version    | 2.5.0p19
class      | fix
edition    | pro
component  | multisite
level      | 1
compatible | yes

In the custom graph editor, a calculation built on top of another
calculation, for example `(Memory total / Memory used) * 100`, was not
restored correctly after saving. The editor and the column "Formula"
showed only the last step, here the constant `100`, so the graph in
the editor showed a constant line. Dissolving the calculation did not
bring back its original parts either. Graphs shown in dashboards were
not affected.

Nested calculations are now saved with all intermediate steps, and the
editor restores them correctly. Custom graphs saved before this fix
are restored correctly as well, so they can be opened and saved again
without losing their formula. Intermediate steps of such graphs get a
default title and color.
