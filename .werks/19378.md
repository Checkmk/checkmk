# Site-specific trusted CAs: choose the CAs inherited from the global settings

A site-specific value of the setting *Trusted certificate authorities for SSL* used to show all of its CAs in a single list. You could not
tell which CAs it had taken over from the global settings and which had been added for that site only.

On the site-specific settings page, the setting now shows two separate entries:

* **Inherited from global settings** lists the CAs from the global settings.
    * In the editor, each CA has a checkbox that sets whether the site trusts it.
    * The read-only view labels each CA as *Trusted* or *Not trusted*.
* **Manually added** contains the CAs added for this site only. They are shown and edited as before.

The global settings page and the stored format of the setting are unchanged.
