# HW/SW Inventory: Nightly tree conversion to JSON finishes within 200 days

Since Checkmk 2.5.0, HW/SW Inventory trees are stored as JSON. A nightly cron job converts the trees that still use the previous file format. It is meant to spread this work over 200
days.

However, each run converted only 1/200 of the trees still left, not 1/200 of all trees. Every run therefore converted fewer trees than the one before, and in the end only one tree per
night. On a site with 1,000 trees the conversion took about 456 days, with 1,000,000 trees about 1,800 days.

Each run now converts 1/200 of all trees, counting those already converted. The conversion finishes within 200 days.

To convert the remaining trees earlier, first check the state of the conversion as the site user:

```
cmk-transform-inventory-trees --show-results
```

`Total #files` is the number of trees still in the previous format. Divide `Total duration` by `Total #transformed files` to get the average time per tree, and multiply it by `Total
#files` to estimate how long converting all remaining trees takes. Then convert them, for example outside business hours, with:

```
cmk-transform-inventory-trees --bundle-length <Total #files>
```

A smaller bundle length converts only part of the trees; the nightly job continues with the rest.

The conversion now records how long each tree took with sub-second precision. Previously these times were cut to whole seconds, so the estimate above was not possible.
