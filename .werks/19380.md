# HW/SW Inventory history: Changed values no longer look unchanged

key        | value
---------- | ---
date       | 2026-11-09T12:46:30.860976+00:00
version    | 2.4.0p42
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

The HW/SW Inventory history shows a changed value as "old → new". Both
sides were rendered with the field's usual precision. Values that differ
only beyond that precision looked the same, for example
"3 GiB → 3 GiB".

Changed numbers are now shown with as many decimals as are needed to
tell them apart. If their precision cannot be raised, for example for a
date, and they would look the same, the difference is shown next to the
new value. Text values are shown as before.

```
Before                      Now
3 GiB → 3 GiB               3.123868942 GiB → 3.123868943 GiB
1.50 → 1.50                 1.5 → 1.5001
2025-11-09 → 2025-11-09     2025-11-09 → 2025-11-09 (+60 s)
```
