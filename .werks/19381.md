# HW/SW Inventory: Saving trees with retention intervals for table columns failed

key        | value
---------- | ---
date       | 2026-11-11T08:42:38+00:00
version    | 2.5.0p21
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

If a rule *Retention intervals for HW/SW inventory* kept columns of a table, the
service *Check_MK HW/SW Inventory* crashed with:

```
TypeError: keys must be str, int, float, bool or None, not tuple
```

The retention intervals of a table were keyed by the values of the row's key columns.
JSON, the format of saved inventory trees, cannot store such keys, so no inventory tree
was saved for the affected hosts.

The retention intervals of tables are now saved in a format JSON can store. Inventory trees
saved by earlier versions can still be read.
