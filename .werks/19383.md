# HW/SW Inventory: Nightly conversion of inventory trees stopped at a tree that could not be converted

key        | value
---------- | ---
date       | 2026-11-19T13:41:01.988009+00:00
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

The nightly conversion of inventory trees to JSON
(`cmk-transform-inventory-trees`) processes a batch of trees per run. If a
tree of this batch could not be converted, the run aborted. Since the next run
took up the same batch again, the conversion of the site's trees did not go on
any more.

The error is now logged and the conversion goes on with the next tree. A tree
that cannot be converted keeps its earlier format.
