# HW/SW Inventory stayed pending on relay-monitored hosts

key        | value
---------- | ---

version    | 3.0.0b1
class      | fix
edition    | ultimate
component  | relay
level      | 1
compatible | yes

On hosts monitored through a relay, the _Check_MK HW/SW Inventory_ service
stayed pending forever, even with an active _Do HW/SW inventory_ rule. No
inventory data was collected for these hosts.

The inventory runs on the site and uses the relay only to fetch the data. The
monitoring core, however, did not schedule any service of a relay-monitored
host, because it assumed the relay runs all of them. The core now schedules
the services that run on the site, and leaves the services the relay runs to
the relay.

Custom checks configured with _Integrate Nagios plug-ins_ are not yet supported
on relay-monitored hosts: neither the relay nor the site runs them, so they
stay pending.
