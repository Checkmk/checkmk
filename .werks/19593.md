# Make Event Console GUI filters for regexes negatable

key        | value
---------- | ---
date       | 2026-10-16T08:50:47.250738+00:00
version    | 2.4.0p39
class      | feature
edition    | cre
component  | ec
level      | 1
compatible | yes

All regex-based GUI filters on fields of Event Console events and their
history have a "negate" option now, e.g. "Message/Text of event (regex)" or
"User that performed action (regex)". Regex filters on the monitored host
of an event, like "Host name or alias (regex)", stay as they are.

Background: The regex syntax here is using the RE2 dialect, which doesn't
include various things, like negative lookahead. So this change makes it
easily possible to e.g. filter out all events which have a message text
matching a regex.
