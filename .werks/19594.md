# Event simulator: Fix "Match site" for remote sites

date       | 2026-10-16T10:35:30.571438+00:00
version    | 2.5.0p17
class      | fix
edition    | community

compatible | yes

Previously, the event simulator checked the "Match site" condition of Event
Console rules against the site the GUI runs on, usually your central site.
It ignored the site you selected under "Simulate for site". In a
distributed setup this had two effects:

* A rule restricted to a remote site never matched when you simulated an
  event for that site.
* A rule restricted to the central site matched even when you simulated an
  event for a remote site.

The simulator now checks the condition against the site you simulate for.

Real event processing wasn't affected, because the Event Console on each
site matches rules against its own site.
