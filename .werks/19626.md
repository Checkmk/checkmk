# winperf_phydisk: stale Disk IO services on busy Windows disks

key        | value
---------- | ---
date       | 2026-11-17T10:00:00+00:00
class      | fix
edition    | community
component  | checks
level      | 2
compatible | yes

The `Disk IO` services of Windows hosts went stale at irregular intervals,
although the agent delivered complete data for the affected disk.

Windows keeps the counters behind `Avg. Disk sec/Read` and `Avg. Disk sec/Write`
in 32 bits. They count in ticks of the performance frequency and restart at zero
once they reach their limit, which a busy disk does within minutes. The check
treated the decreasing value as unusable and discarded the whole disk, including
throughput, IO operations and queue length. Disks under load restarted these
counters most often, so the values that matter most were missing most often.

Starting with this release, the check knows the width of each Windows counter
and computes the correct rate when a 32 bit counter restarts at zero. A counter
reset, for example after a reboot of the monitored host, is still recognized as
such and skipped for one check interval.
