# Windows HW/SW inventory: win_exefiles failed on some locales

compatible | yes

This fixes a regression introduced in Checkmk 2.5.0 when the Windows inventory
plug-in was rewritten in PowerShell.

The plug-in generated file timestamps using the host's regional settings. On
systems using a dot as the date separator, Checkmk could misinterpret the dates
or fail to parse the entire `win_exefiles` section, leaving the executable
inventory empty:

```
Parsing of section win_exefiles failed - please submit a crash report!
```

The plug-in now uses a locale-independent timestamp format. The fix takes
effect once the updated agent runs on the host.

Only hosts with configured executable paths are affected.
