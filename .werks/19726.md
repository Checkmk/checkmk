# Cloned view widgets no longer share one view

key        | value
---------- | ---
date       | 2026-09-09T09:06:22.185089+00:00
version    | 2.5.0p14
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

If you cloned a view widget on a dashboard, the clone and the original widget
used the same view. A change to the columns of one widget then changed both
widgets.

Checkmk now creates a separate view for the widget that you change. The other
widget keeps its columns.

On an existing dashboard, the two widgets become independent when you change the
view of one of them.

Checkmk also saved a change to the view of a widget immediately. The change
stayed even if you then selected "Cancel" in the dashboard. Checkmk now discards
the change together with the other changes to the widget.
