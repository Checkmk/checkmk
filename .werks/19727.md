# mkbackup: Show schedule changes of site backup jobs without a new backup run

If you changed the schedule of a site backup job, the service `OMD <site> backup <job>` showed the old schedule until the job ran again.
For example, if you enabled a disabled schedule again, the service stayed WARN with "Schedule is currently disabled".
If you disabled the schedule, changed the job to manual execution, or moved the next run to a later time, the service could go CRIT with "Next run".

Now Checkmk updates the next run of the job when you save the job in *Setup > Maintenance > Backups*.
The service shows the new next run after the next check.
You no longer have to start the job manually to correct the service.

If the service already shows a wrong state after the update, save the backup job once.
