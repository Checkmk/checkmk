# Allow view widgets with a height of two rows in responsive dashboards

key        | value
---------- | ---
date       | 2026-10-15T11:36:49.856563+00:00
version    | 2.5.0p18
class      | fix
edition    | pro
component  | multisite
level      | 1
compatible | yes

In responsive dashboards, "View" widgets required a minimum height of four rows.
You could not make these widgets smaller.

Now the minimum height of these widgets is two rows on all screen sizes.
The minimum width and the initial size do not change.
