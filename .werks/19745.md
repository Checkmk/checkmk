# New check plug-ins: F5 rSeries appliances (F5OS)

This adds check plug-ins to monitor F5 rSeries appliances running F5OS via SNMP.

The appliance is detected automatically. After enabling SNMP on it and running a
service discovery, the following services are created:

- _F5OS Platform CPU_ - CPU utilization; configurable via the _CPU utilization_ ruleset.
- _F5OS Platform Memory_ - memory usage; configurable via the _Memory percentage used_ ruleset.
- _F5OS Platform Temperature_ - one service per temperature sensor; configurable via the _Temperature_ ruleset.
- _F5OS Fan Speed_ - one service per fan; a stalled fan (0 RPM) is `CRIT`. Configurable via the _Fan speed_ ruleset.
- _F5OS PSU_ - one service per power supply, reporting Active / Standby / Fault with input/output power, voltage and current metrics.
- _F5OS Tenant_ - one service per tenant instance: `OK` while Running, `WARN` during Starting/Stopping, `CRIT` otherwise.

In addition, the hardware/software inventory is populated with the platform model,
the F5OS version, the CPU, the NVMe system disk and the power supplies.
