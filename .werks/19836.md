# juniper_info: Store model and serial number in correct attributes

The HW/SW inventory of Juniper devices stored the model and serial number
in the legacy inventory attributes `hardware.system.model_name` and
`hardware.system.serial_number`. Views, filters and dashboards that use the
regular _Model name_ and _Serial number_ columns therefore showed nothing
for Juniper devices.

Juniper devices now store them in the same attributes as any other
hardware, `hardware.system.model` and `hardware.system.serial`.

If you added the legacy columns or filters to your own views to see Juniper
data, switch them to _Model name_ and _Serial number_. The values move with
the next HW/SW inventory run of each device.
