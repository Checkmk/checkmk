# Relay crash reports are now collected by the site

key        | value
---------- | ---
date       | 2026-08-20T11:54:04.564473+00:00
version    | 3.0.0b1
class      | feature
edition    | ultimate
component  | relay
level      | 2
compatible | yes

The relay now forwards each completed crash report to its site, where it joins
the site's own crash reports and can be submitted to the Checkmk team from
there.

A report is deleted from the relay only once the site has stored it. While the
site is unreachable the reports wait on the relay and are retried, so a short
outage does not lose them. The relay's 5 MB crash report budget still applies
while they wait, so a long one can.
