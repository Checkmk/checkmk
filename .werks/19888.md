# Dashboard sharing indicator now says "Public sharing"

key        | value
---------- | ---
date       | 2026-10-16T09:52:06.973509+00:00
version    | 2.5.0p18
class      | feature
edition    | community

The sharing indicator in the header of a dashboard now reads "Public sharing"
instead of "Sharing", e.g. "Public sharing active", "Public sharing paused"
or "Public sharing until `<date>`". This makes it clear that the dashboard is
accessible via a public link, not just shared with other Checkmk users.
