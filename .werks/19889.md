# REST API: Comment creation endpoints hidden from the interactive GUI

In the interactive REST API GUI (Swagger UI), the endpoints for creating host
and service comments did not show the `comment_type` field, while the API
documentation (ReDoc) showed it correctly. This is caused by a known bug in
Swagger UI that cannot be worked around in Checkmk 2.5.0.

To avoid confusion, the following endpoints are no longer listed in the
interactive GUI:

* `POST /domain-types/comment/collections/host`
* `POST /domain-types/comment/collections/service`

The endpoints themselves are unchanged and still work as before. You can find
their full description in the API documentation (ReDoc).

Checkmk 3.0.0 is not affected by this issue.
