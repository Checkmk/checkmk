# Fix audit log display

key        | value
---------- | ---

component  | wato

Prior to this change, long summaries or object references stretched
the audit log table and the rest of the row stayed vertically
centered next to multi-line cells, which made the entries hard to
read.

Now, all cells of the audit log table are aligned to the top. The
Summary and Object columns wrap long content, breaking long words if
needed.
