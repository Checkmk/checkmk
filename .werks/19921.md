# CRIT state of 'automation helpers' service after update to 2.5

After updating a Checkmk site to version 2.5, the self-monitoring service
"Process ... automation helpers" on the Checkmk server could go CRIT even though
the automation helpers were running fine.

The update procedure now rewrites the stored discovery parameters of affected
services to the current default pattern. Previously, the issue could only be
resolved by rediscovering the services of the affected host. No manual action is
required.
