# NGINX web servers (Linux) plugin crashed on hosts with kernel-owned sockets

key        | value
---------- | ---
date       | 2026-09-10T12:37:52.390610+00:00
version    | 2.5.0p14
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The agent plugin `nginx_status.py` detects running NGINX servers from the output
of `ss -tlnp`. Listening sockets that belong to no user space process, are
listed without a process column. The plugin did not expect that and crashed
with:

```
ValueError: not enough values to unpack (expected 6, got 5)
```

As a result, no NGINX services were reported on hosts that are affected by this
bug. The plugin now skips such lines.
