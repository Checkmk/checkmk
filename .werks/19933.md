# Restore inline help on the rule edit page

With the migration of the rule edit page to the new form rendering, the rule properties (_Description_, _Comment_, _Documentation URL_ and _Rule activation_) lost their inline help texts.

In addition, with the _Show inline help_ option enabled, forms did not display the help text of optional elements as long as they were not checked.

Both issues have been fixed.
