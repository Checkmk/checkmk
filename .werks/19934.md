# Show required indicator on conditionally revealed form fields

Previously, the "(required)" indicator next to form fields was only shown for top-level properties on pages built with the new form rendering engine.

The indicator is now also shown for:

* Fields that are only revealed by selecting an option or ticking a checkbox
* File upload fields, which can never be left empty
* Fields inside Tuple groups that cannot be left empty
