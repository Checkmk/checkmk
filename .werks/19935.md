# Dual-stack clusters: no false warning about different address families

key        | value
---------- | ---
date       | 2026-09-29T13:52:21.421397+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | core
level      | 1
compatible | yes

Since Checkmk 2.5, activating changes warned about every cluster that is
configured as IPv4/IPv6 dual-stack together with its nodes, for example:

_Cluster 'cluster' has different primary address families: cluster: IPv4, node1: DUAL_STACK, node2: DUAL_STACK_

The cluster and its nodes use the same primary address family, so the warning
was wrong. It now only appears when the primary address families actually
differ, or when a node has no IP address.
