# Windows agent: pyOpenSSL was still shipped in 2.5.0p10

key        | value
---------- | ---
date       | 2026-07-28T06:38:48+00:00
version    | 2.5.0p11
class      | fix
edition    | community
component  | agents
level      | 1
compatible | yes

Werk #19966 stated that the Python environment shipped with the Checkmk Windows
agent no longer contains the pyOpenSSL package. This was not correct: because of
a packaging oversight, 2.5.0p10 still contained pyOpenSSL 24.3.0. The package
has now really been removed.
