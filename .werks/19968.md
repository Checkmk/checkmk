# rds_licenses: stop error messages from corrupting other agent sections

key        | value
---------- | ---
date       | 2026-08-03T05:37:25.402986+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The Windows agent plugin `rds_licenses.ps1` wrote its error messages to standard
output, the same channel it uses to send monitoring data.

The messages polluted the agent output and could affect unrelated services.

They are now written to the error stream instead, where they remain visible when
the plugin is run manually on the console for troubleshooting.
