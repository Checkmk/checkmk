# checkengine: Full support for mutiple special agent calls

key        | value
---------- | ---

version    | 2.5.0p11
class      | fix
edition    | community

compatible | yes

If a plugin defines multiple special agent calls in its configuration, only the last one was executed.

With this change, each of these calls gets executed and cached independently.
The order of definition is now regarded in the internal unique identifier.

This fixes the promise of werk 17200 to run _all_ configured special agents.
