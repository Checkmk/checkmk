# Agent Updater: Configuration error on Checkmk update when proxy settings are active

With previous patch versions of Checkmk 2.5, a migration bug in the _Agent Updater_ ruleset could block a site update from Checkmk 2.4 to Checkmk 2.5.
More precisely: When configuring the _Agent Updater_ rule, activating _Proxy Settings > Provide proxy settings_, but _not_ providing credentials, the following traceback shows up on `omd update`, and the site update aborts.
