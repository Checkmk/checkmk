# apc_symmetra: Make the states of battery pack cartridge flags configurable

The service "APC Symmetra status" reports the status flags of each battery
pack cartridge, such as "Disconnected", "Overvoltage" or "Overtemperature
Critical". Until now every flag except "Needs Replacement" resulted in a
WARN state that could not be changed. Setups in which a flag is expected,
for example a battery pack frame without cartridges, therefore had a
permanently WARN service.

The rule "APC Symmetra Checks" now offers the option "States of battery
pack cartridge flags", where the state for each flag can be configured
individually. A cartridge is reported with the worst state of the flags it
has set. Flags without a configured state are still reported as WARN, so
existing setups behave as before. The flag "Needs Replacement" continues
to follow the option "State if battery needs replacement".
