# livestatus_status: tolerate incomplete site status data

The service `OMD <site> performance` could go to UNKNOWN with "check failed -
please submit a crash report!", the crash report showing
`KeyError: 'livestatus_version'`.

This happened when the agent delivered a livestatus_status section that did not
contain the expected status columns. In the reported cases that section carried
the certificate data belonging to the livestatus_ssl_certs section, and no
livestatus_ssl_certs section was sent at all.

Why the agent output ended up that way is not known, so this is a defensive
fix. Instead of crashing, the service now reports UNKNOWN with "Incomplete
livestatus status data received". Sites that send complete status data are not
affected.
