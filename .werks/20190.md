# Synthetic Monitoring: Remove root-deployment restriction for RCC

key        | value
---------- | ---
date       | 2026-09-02T14:20:43.581217+00:00
version    | 2.4.0p37
class      | feature
edition    | cee
component  | checks
level      | 1
compatible | yes

[Werk #19460](https://checkmk.com/werk/19460) disallowed combining root agent deployment on Linux with RCC as environment creation mode, since RCC could otherwise break permissions on `/opt` (e.g. on SLES 16).

This restriction is gone. Baking a Linux agent now always succeeds, regardless of the agent's user context or whether RCC is used. Instead, the affected rules now show clear inline help wherever RCC can be selected as the environment creation mode, so you can make an informed choice instead of being blocked.
