# Fix Vutlan EMS temperature check skipping 0 °C readings

date       | 2026-09-14T07:58:47.751273+00:00
version    | 3.0.0b1
class      | fix
edition    | community

level      | 1
compatible | yes

Previously, the _Temperature_ service for Vutlan EMS devices went UNKNOWN with "Item not found in monitoring data" whenever a sensor's reading was exactly 0 °C. The service was discovered correctly, but the check treated a 0 °C reading the same as "no reading available" and produced no result. This has been fixed: a genuine 0 °C reading is now checked and reported like any other value.
