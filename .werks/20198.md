# Redfish: monitoring could stop after an interrupted agent run

key        | value
---------- | ---
date       | 2026-08-24T12:03:29.532112+00:00
version    | 2.4.0p37
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

Redfish monitoring could stop after an interrupted special agent run when
cached sections were enabled. The affected host stopped delivering data and
failed again on every following run until someone intervened. This only affects
cached Redfish sections.

The agent now discards the damaged cache file and refetches the section on its
next run. Affected hosts recover on their own; no manual cache cleanup and no
configuration change is needed.
