# Remove obsolete Python 2 sapnwrfc module from the SAP agent package

Since Checkmk no longer supports Python 2 agent plug-ins, the SAP R/3 agent plug-in `mk_sap` was ported to the Python 3 module `pyrfc`. The previously bundled Python 2 module `sapnwrfc` is therefore no longer used by the plug-in. It has now been removed from the agent package.

No action is required for existing setups: the Python 3 plug-in already relies on `pyrfc`, which must be installed on the monitored host, independently of the removed bundle.
