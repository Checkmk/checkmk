# mk_sap: Add option to exclude CCMS paths from monitoring

The SAP agent selects which parts of the CCMS monitor tree to collect
via a list of allowed paths. So far this was a pure allow list, so a
single noisy object below a wildcard rule could not be skipped without
also losing the automatic pickup of new objects below that rule.

It is now possible to configure paths that are excluded from monitoring
even when they are matched by one of the allowed paths. The exclude list
can be configured through the agent bakery rule and defaults to empty, so
existing setups are not affected.

Thanks to Simon Harms for the contribution.
