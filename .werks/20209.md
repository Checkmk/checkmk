# mk_sap_hana: Monitor SAP HANA incremental data backups

The SAP HANA agent plug-in reports the most recent complete data backup, log backup and data snapshot as separate SAP HANA Backup services.
It now additionally queries the most recent incremental data backup.
On systems that run incremental backups, a new service "SAP HANA Backup ... - incremental data backup" is discovered after a service re-discovery.
It reports its status, age, comment and message just like the existing backup services.
The change is additive, so existing services are not affected.
