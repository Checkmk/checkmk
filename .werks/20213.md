# mk_sap: Fix lost and duplicate CCMS alerts

date       | 2026-10-29T09:32:58.051053+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The agent plug-in `mk_sap` could lose CCMS alerts of SAP R/3 systems or report them more than once.
Alerts got lost when the agent was called more often than the SAP system host was checked, for example by a service discovery or by `cmk -d`.
Alerts were reported again when the SAP system host was checked before the plug-in delivered new data, for example because the plug-in runs asynchronously or could not connect to the SAP system.

The monitoring site now processes every alert once.
To achieve this, the plug-in sends every alert again for a retention period, which increases the amount of transmitted data.
The retention period defaults to one hour and can be changed with the option `retention_period` in `sap.cfg` or in the agent rule "SAP R/3 monitoring plug-in".
Alerts that were reported before the update are not reported again.

To get the fix, update the agent plug-in on the monitored hosts.
No further action is required, unless the SAP system hosts are checked less often than once per hour.
In that case, set the retention period to at least their check interval.
