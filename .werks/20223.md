# informix_dbspaces: Fix crash with outdated mk_informix agent plugin

edition    | community

The _Informix Tablespace_ services crashed with _KeyError ('system_pagesize')_ when the monitored host still runs a mk_informix agent plugin from before [Werk #17873](https://checkmk.com/werk/17873).
The check now falls back to the previous space calculation for such agent output.
Since the blobspace size fix of [Werk #17873](https://checkmk.com/werk/17873) only takes effect once the updated mk_informix plugin is deployed, the service output points out the outdated plugin and asks to update it.
