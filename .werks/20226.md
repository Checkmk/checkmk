The command `cmk-validate-plugins` now checks the plug-ins of more plug-in APIs:

* Agent bakery API v1, only in Checkmk Pro and higher editions: The plug-ins can be loaded and are configured.
* Agent bakery API v2, only in Checkmk Pro and higher editions: The plug-ins can be loaded and are configured, and their default parameters match their agent rule set.
* Graphing API v1 and v2 (unstable): The plug-ins can be loaded.

The agent bakery configures a plug-in with the agent rule set of the same name.
If no such rule set exists and the plug-in has no default parameters, the plug-in never runs, and so far nothing told you.
Agent rule sets without a matching bakery plug-in are valid and are not reported.
