# Fix crash of cmk-validate-plugins on plug-ins with invalid parameters

---------- | ---

If loading a plug-in raised certain errors, such as a pydantic validation error,
Checkmk did not report the broken plug-in.
Instead, plug-in loading and `cmk-validate-plugins` crashed with a `TypeError`, for example:

`TypeError: ValidationError.__new__() missing 1 required positional argument: 'line_errors'`

Checkmk now reports the error together with the plug-in module that caused it.
