# Update fails if a site ID is a Python keyword

key        | value

edition    | ultimate

level      | 1

If a site ID was a Python keyword, for example `global`, the update to this version failed in the step "OTel collector configuration" with
`ValueError: 'global' is not a valid, non-reserved Python identifier`.
This also happened on sites without any OpenTelemetry collector configuration.
The receiver and Prometheus scrape configuration pages of the OpenTelemetry collector failed with the same error.

The update now succeeds for such sites, and they can be selected in the OpenTelemetry collector configuration like any other site.
On sites without OpenTelemetry collector configuration, the update also no longer creates empty configuration files.
