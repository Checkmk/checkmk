# Fixed disappearing timewarp in BI availability timelines

Previously, opening the timewarp of a BI aggregate's availability timeline could
show nothing at all: the aggregate tree, the phase navigation arrows and the
"Close timewarp" button were simply absent, with no hint why.

This happened whenever the selected timestamp did not exactly match the start of
a phase. Availability time ranges are usually relative ("The last 4 hours"), so
the range moves on every page load. As soon as it had moved past the timestamp
you picked, that timestamp got clamped into the new range, no longer matched any
phase, and the whole timewarp block vanished.

The timewarp now snaps to the phase containing the selected timestamp. The header
shows the timestamp of the phase that is actually displayed and points out when
that differs from the one you selected.

The timewarp is also restricted to the aggregation it was opened from, so a
timeline showing several aggregations no longer warps all of them at once.
