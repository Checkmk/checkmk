# Wrap ssh-keygen to also use the system OpenSSL

Werks [#18935](https://checkmk.com/werk/18935), [#18937](https://checkmk.com/werk/18937) and [#19581](https://checkmk.com/werk/19581) introduced wrappers for several system commands, among them `ssh` and `scp`, so that they use the system OpenSSL instead of the OpenSSL bundled with Checkmk when called by a site user.

We've now extended this to also wrap `ssh-keygen`, which otherwise failed without creating a key, with an error like:

`OpenSSL version mismatch. Built against 30000020, you have 30500070`

This affects the operating systems on which `ssh` is already wrapped, including Ubuntu 22.04 and therefore the Checkmk Docker image.

As with the other wrapped commands, this fix only takes effect when `ssh-keygen` is called by its short name (relying on the site's `PATH`), not via an absolute path. See [Werk #18937](https://checkmk.com/werk/18937) for more background and workarounds.
