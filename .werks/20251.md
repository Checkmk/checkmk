# Cisco Meraki: handle disconnected power supply

key        | value
---------- | ---
date       | 2026-07-31T10:45:49.119758+00:00
version    | 2.5.0p11
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Parsing the Cisco Meraki device status agent section could crash if the
device reported a power supply as disconnected: the Meraki API returns
`model` and `serial` as empty for such a power supply, which the section
parser rejected.

The section parser now accepts a disconnected power supply with no model or
serial. These result values are now simply not shown when not present.
