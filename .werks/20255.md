# Monitor CPU, memory and module state on all HPE/H3C Comware switches

key        | value
---------- | ---
date       | 2026-08-25T12:00:00+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | checks
level      | 1
compatible | yes

CPU utilization, memory usage, module state and temperature are now monitored
on all HPE and H3C switches running Comware, for example the HPE 5710 and 5130
series. Previously these services were only created on three switch models.

One set of services is created per module of a switch, named
`CPU utilization`, `Memory`, `Status` and `Temperature`. A module that does not
report a value leaves out the corresponding service.

Run a service discovery on your existing HPE and H3C hosts to pick up the new
services.
