# Event Console alerts not matched by notification rules migrated from 2.3

---------- | ---

version    | 2.4.0p36
class      | fix

component  | notifications
level      | 1
compatible | yes

Werk #18082 changed how notification rules match Event Console alerts: since
Checkmk 2.4 an alert only matches when *"Event console alerts"* is explicitly
enabled in the rule.

Notification rules created in 2.3 were not aware of this option. After an update
to 2.4 they therefore silently stopped matching Event Console alerts, even though
nothing was changed in the rule.

The update now adjusts such rules automatically to the changed behaviour so that
they keep matching Event Console alerts as before. *"Event console alerts"* is
only enabled for rules that already matched Event Console alerts in 2.3; rules
that did not match them are left unchanged. For the adjusted rules the change is
visible in the *"Triggering events"* section, where *"Event console alerts"* is
now enabled.

No manual interaction is required.
