# Show services of all sites in "All services with this description"

key        | value
---------- | ---
date       | 2026-09-07T08:16:34+00:00
version    | 2.3.0p51
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

When opening *All services with this description* from a service, the view only
showed the services of the site the current host belongs to. The same happened
when using the page navigation or exporting the view, even though no site
filter was set. Pressing *Apply* in the filter menu once showed the services of
all sites again.

The view is no longer restricted to a single site. This regression was
introduced with werk #19555.
