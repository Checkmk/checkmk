# Row count of a view was hidden if the table was wider than the window

key        | value
---------- | ---
date       | 2026-09-17T07:35:54.702971+00:00
version    | 2.3.0p51
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

When a table in a view was wider than the space available for it, the row count
in the upper right corner of the table was no longer visible. This happened for
example after zooming in in the browser, in a narrow browser window, or with
views that show many columns.

The count was placed at the right edge of the table instead of the right edge of
the visible area, so it could only be seen after scrolling all the way to the
right. It now stays at the right edge of the visible area.
