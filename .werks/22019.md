# Notifications: translate notification method edit side panel

compatible | yes

When the Checkmk GUI was configured to a language other than English
(for example Japanese or German), the side panel for creating or editing the
parameters of a notification method was only partly translated. The title and
buttons were shown in the selected language, but the section headers and
field labels stayed in English.

This was already fixed for Checkmk 2.4.0 with werk #19756, but the fix was
missing in Checkmk 2.5.0.

The side panel is now displayed in the language selected by the logged-in
user again.
