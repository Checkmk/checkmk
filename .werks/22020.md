# Custom themes below local/ did not load their theme.css

A custom theme placed only below `local/share/check_mk/web/htdocs/themes/` was
listed in the theme selector, but its `theme.css` was not loaded. The GUI fell back
to the default styling instead. The same applied to the theme's favicon.

Themes installed completely below `local/` now use their own `theme.css`
and favicon.
