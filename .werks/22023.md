# ServiceNow: Repeated problem notification for an open case failed

key        | value
---------- | ---
date       | 2026-10-12T08:28:29.838203+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | notifications
level      | 1
compatible | yes

If the ServiceNow notification plug-in was configured to create cases, a
further problem notification for a host or service that already had an open
case failed with a <tt>KeyError</tt>. The open case was not updated.

Such notifications now update the open case.
