# mknotifyd: tolerate a missing timestamp in the agent section

key        | value
---------- | ---

version    | 2.4.0p36
class      | fix
edition    | cre

level      | 1
compatible | yes

All notification spooler services of a host could go to UNKNOWN with "check
failed - please submit a crash report!", the crash report showing
`ValueError: could not convert string to float`.

The agent section of the notification spooler normally starts with a timestamp
line. Agents that do not send one have been tolerated since Checkmk 1.5.0p23
and 1.6.0p4, but that fallback was lost when the plugin was migrated to the new
plugin API for Checkmk 2.4. Since then such a section made parsing fail and took
every service built from it with it, even though the rest of the section was
complete.

The fallback is restored. If the timestamp line is missing, the age information
the services show is calculated against the time of the check instead.
