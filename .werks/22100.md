# Global search: always show the host of a matching host address

key        | value
---------- | ---
date       | 2026-08-10T05:35:48.921996+00:00
version    | 2.5.0p12
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Searching for a host address in the global search listed the matching IP
addresses without telling which host they belong to. The host name was only
shown as additional context when the same address was configured on two or
more hosts, which made the search results depend on unrelated hosts.

The host name is now always shown as context for host address matches. It is
omitted only if the host is named after its address, where it would merely
repeat the result title.
