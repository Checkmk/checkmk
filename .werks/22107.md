# product_usage: Cron job should not write to STDOUT

---------- | ---

class      | fix
edition    | community

The cmk-product-usage command is executed as a cron job.
It wrote the collected usage data to STDOUT, which caused cron to send an email for every job.

With this change, the command no longer writes to STDOUT.
Hence, administrator do not get spamed with mere informational emails.
