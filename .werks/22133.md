# Views and dashboards: fix crash on a malformed filter context

key        | value
---------- | ---
date       | 2026-08-18T06:20:02.672926+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

A view or dashboard element whose saved context stored a filter value directly,
instead of the set of filter variables Checkmk expects, crashed the page with
`AttributeError: 'str' object has no attribute 'values'`. Such a context can
come from a very old configuration or from a hand edited file.

The affected element now reports its context information as missing, the way it
always did for a filter that was simply not set, instead of taking the page
down.
