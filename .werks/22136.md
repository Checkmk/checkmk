# Crash reports: no more double confirmation when deleting

key        | value
---------- | ---
date       | 2026-09-21T12:34:10.375923+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Deleting crash reports asked you to press "Delete" twice.

On *Monitor > Crash reports*, picking **Commands > Delete crash reports**
opened a small form that contained nothing but a "Delete" and a "Cancel"
button. Pressing "Delete" there only brought up the actual confirmation
dialog, which asks the very same question again.

That first form never carried any options, so it was pure extra clicking. It
is gone now: the menu entry takes you straight to the confirmation dialog,
which still tells you how many crash reports are affected and lets you cancel.
