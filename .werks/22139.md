# Views: Keep all rows and checkboxes after cancelling a command

key        | value
---------- | ---
date       | 2026-09-28T06:00:44.311650+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

If you selected rows in a view (with "Show checkboxes"), picked a command such as
"Delete crash reports" and then clicked "Cancel" in the confirmation dialog, the
view only showed the previously selected rows and the checkboxes were gone.
Nothing was executed, but you had to reload the view to get back to the full list.

Cancelling the confirmation dialog now returns you to the complete view, with the
checkboxes still shown and your selection kept.
