# Fix crash when deleting a group whose customer was deleted

Previously, you could delete a customer that still had host groups, service
groups, contact groups or users assigned to it. Deleting one of those groups
afterwards failed with a crash:

_KeyError: 'cust_sber'_

The group was deleted anyway, even though you saw the crash page.

This has been fixed. Groups whose customer no longer exists can now be deleted
without an error. In addition, Checkmk no longer lets you delete a customer that
still has groups or users assigned to it. The page _Setup > Users > Customers_
and the REST API endpoint for deleting a customer now refuse the deletion and
list the groups and users that still refer to the customer. The REST API
returns status 409.
