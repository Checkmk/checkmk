# xinetd: Report a failed start instead of OK

key        | value
---------- | ---
date       | 2026-09-03T07:23:22.441271+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | omd
level      | 1
compatible | yes

If starting xinetd failed, the init script printed `OK` and exited successfully
anyway. `omd start` then claimed the site had come up, while services relying on
xinetd, such as Livestatus via TCP, were not reachable.

The init script now prints `Error` and exits with a failure, so a failed
xinetd start is visible in the output of `omd start`.
