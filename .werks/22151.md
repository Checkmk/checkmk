# New service for monitoring the data backend health in Checkmk Pro

key        | value
---------- | ---
date       | 2026-09-23T11:50:10.819292+00:00
version    | 3.0.0b1
class      | feature
edition    | pro
component  | checks
level      | 1
compatible | yes

Checkmk Pro now monitors the site's own data backend. On every site where a self-hosted data backend is configured, you get the new service _OMD &lt;site&gt; data backend_.

The service goes `OK` if the data backend's ping endpoint responds with status 200. It goes `CRIT` if the connection fails or the backend reports another status. The error or the response body appears in the service details.

Editions other than Pro are not affected and operate as they did before.
