# Views: fix crash on visuals without a context option

key        | value
---------- | ---
date       | 2026-08-18T06:29:35.861066+00:00
version    | 2.5.0p12
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Opening a view or dashboard that was saved before the "Context information"
option existed crashed the page with `KeyError: 'add_context_to_title'`.

Such a visual is now treated as if the option were enabled, which is what
Checkmk did before the option was introduced, so its title is rendered with the
page context as before.
