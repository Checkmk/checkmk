# AudioCodes: IP groups without connectivity data

edition    | community

compatible | no

If an AudioCodes device did not report the proxy set connectivity of an
IP group, the service "IP group" was CRIT even when the IP group was
active. If the device did not report the name of an IP group, the
service name contained only the index of the IP group. This occurred,
for example, on some MediaPack devices with firmware 6.60A.

If the device does not report the proxy set connectivity, the service
now evaluates only the status of the IP group. The details then show
"Proxy set connectivity: not reported by the device". If the device
does not report a name, the service name now contains the description
of the IP group, for example "IP group 1 IPG_SBC".

The details now show only the fields that have a value. Before, the
details showed "None" for an empty description.

If a device does not report the names of its IP groups, run a service
discovery on the host. The discovery replaces the old services.
