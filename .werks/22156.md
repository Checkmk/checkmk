# AudioCodes: evaluate all LEDs

The service "LED Status" evaluated only one LED of each module, fan
tray and power supply. If the device reported this LED without a color
or as gray, the service showed "unknown-unknown" and was UNKN.

The service now evaluates all LEDs that the device reports. It ignores
LEDs without a color and gray LEDs. Each color gives the same state as
before. Because the service evaluates more LEDs, its state can change.

On a MediaPack MP-124, the service now has two exceptions:

* A flashing red LED is OK. According to the MP-124 documentation, only
  the Data LED flashes red. It shows that the device receives RTP
  packets.
* The service ignores the LEDs of the channels above the number of
  ports that the device reports. If SRTP is enabled, the MP-124 can
  show these LEDs red.

If the device does not report the name of a module, the service now
shows the module type, for example "acMediaPack-124".
