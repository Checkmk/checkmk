# AudioCodes: labels of the operational state

The service "Operational state" showed the highest alarm severity with
the label "Gateway", and the operational state with the label "Highest
alarm severity". The service now uses the labels "Highest alarm
severity" and "Operational state". The details now always show the
operational state.

The details showed "Error message: (empty)" for an empty error message
and "Error ID: 0" for the error ID 0. The service now shows the error
message only if it is not empty, and the error ID only if it is not 0.
