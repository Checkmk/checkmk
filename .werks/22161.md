# smart_posix: Handle 'Pending defect count' in smartctl output

key        | value
---------- | ---

Due to a bug in smartctl, its JSON output may be prefixed with
`Pending defect count:`. This caused _Parsing of section
smart_posix_scan_arg failed_ in the _Check_MK_ service. The prefix is now
ignored.
