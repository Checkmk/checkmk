# omd: Keep permissions of /etc/fstab when removing a site

key        | value
---------- | ---
date       | 2026-11-02T15:18:46.085572+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | omd
level      | 1
compatible | yes

`omd rm` and `omd mv` rewrite `/etc/fstab` through a temporary file to drop
the site's tmpfs entry. The new file took its permissions from the umask of
the `omd` process, so `/etc/fstab` could end up with a different mode than
before. The original mode of `/etc/fstab` is now kept.
