# omd cp/mv/restore: Remove leftover .orig and .rej files after conflicts

key        | value
---------- | ---

version    | 2.5.0p20
class      | fix
edition    | community
component  | omd
level      | 1
compatible | yes

When `omd cp`, `omd mv` or `omd restore` with a new site name ran into a
conflict while adapting a file to the new site name and you chose *install*
or *restore*, the helper files `.orig` and `.rej` were left next to the file.
In `etc/cron.d` this broke the crontab of the site on the next `omd start`
("bad minute"). A leftover `.orig` could also make the new site run the cron
jobs of the old site.

Both files are now always removed. To clean up an affected site, delete the
`*.orig` and `*.rej` files in `etc/cron.d` and run `omd reload crontab`.
