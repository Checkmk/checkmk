# Report a malformed filter request

key        | value
---------- | ---
date       | 2026-08-18T10:42:34.770475+00:00
version    | 2.5.0p12
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

A malformed request to the filter form of a view produced a crash report
with a bare `AssertionError` instead of an error message. This could be
seen after a browser reload during an upgrade, when the page and the
server disagreed about the format of the request.

Such a request is now answered with the message "The request is missing
the filter infos to render" and no crash report is created.
