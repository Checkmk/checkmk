# Kubernetes 1.35 is now officially supported

As of this release of Checkmk, Kubernetes 1.35 is now officially supported.

The following versions of Kubernetes are supported:

```
Checkmk 2.4: 1.26, 1.27, 1.28, 1.29, 1.30, 1.31, 1.32, 1.33, 1.34, 1.35
Checkmk 2.5: 1.32, 1.33, 1.34, 1.35
```

Alongside this change, we drop official support for Kubernetes 1.31 in Checkmk
2.5, in accordance with the supported versions policy documented in
[Werk #19449](https://checkmk.com/werk/19449).
