# Fix crash scheduling host downtime

Scheduling a downtime for the hosts of the selected services crashed
with `KeyError: 'host_name'` when the view the services were selected
in did not show a host column.

The command now works from such a view as well. The number of affected
hosts shown in the confirmation dialog can be lower than the real
number in that case, because it is counted from the columns the view
provides; the downtimes themselves are scheduled for all selected
hosts as before.
