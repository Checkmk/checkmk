# Main menu shortcuts no longer collide with browser shortcuts

key        | value
---------- | ---
date       | 2026-08-18T12:41:41.468181+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

The main menu shortcuts `Alt + C` (Customize) and `Alt + S` (Setup) now
suppress the reaction of the browser to these key combinations, so that they
reliably open the corresponding main menu.

Before, Firefox could act on them first and, for example, open its browsing
history or move the focus into the address bar instead of opening the menu.

This only affects Firefox, and only with certain interface languages, since
Firefox derives these key combinations from its localized menu labels. In all
other browsers, and in Firefox with other languages, `Alt + C` and `Alt + S`
are not assigned to any browser function. No other keyboard shortcut is
changed.
