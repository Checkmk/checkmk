# Sidebar no longer reloads the page after the session has ended

key        | value
---------- | ---
date       | 2026-09-17T07:20:00.000000+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

The sidebar periodically fetches the contents of its snapins, the user
messages, the number of pending changes and the number of unacknowledged
incompatible werks. Whenever one of these requests found the session to be
no longer authenticated, the whole page was reloaded.

During a logout that reload raced with the redirect to the login page: it
cancelled the redirect and reloaded the page you had just left instead. You
then ended up on the login page carrying that page as the login target,
rather than on a plain login page.

The sidebar now stops its periodic updates instead of reloading the page.
