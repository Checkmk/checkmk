# Fix check parameter errors for ASM disk groups and other rulesets

Some check parameter rulesets, for example _ASM Disk Group (used space and
growth)_, _IBM SVC pool capacity_, _AntiVirus last update age_,
_Timemachine backup age_ and many of the AWS rulesets, broke Setup pages
that show their parameters:

- On _Services of host_ with _Display > Show check parameters_ enabled,
  their services showed "Invalid check parameter", although the parameters
  were valid.
- The _Effective parameters_ page of enforced services using one of these
  rulesets crashed with an internal error.

Both pages now show the parameters as expected.
