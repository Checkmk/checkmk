# Setup: keep error messages of invalid fields

key        | value
---------- | ---
date       | 2026-11-17T17:36:11.993623+00:00
version    | 2.5.0p22
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

When you opened a rule with an invalid value, the error message at the affected
field disappeared right after the page loaded for some fields: lists of
checkboxes, dual list choices, and fields whose invalid value Setup replaced
with a valid one. Saving the rule then failed with "Cannot save the form
because it contains errors", without any field marked. This happened, for
example, for _Restrict by state_ without any state in _Systemd single service
discovery_.

The error message now stays at the field until you edit it.
