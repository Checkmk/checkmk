# Restore spacing between labels and fields in Setup forms

key        | value
---------- | ---
date       | 2026-11-25T13:42:31.384679+00:00
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Since 2.5.0, required fields that Setup forms show side by side sat directly
under their labels, without any space in between. You could see this, for
example, in the rule _Check HTTP web service_ for the fields _Prefix_ and
_Name_ under _Service name_.

There is now space between these labels and their fields again, and fields in
the same row are spaced a little further apart.
