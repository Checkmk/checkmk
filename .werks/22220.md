# Azure recovery services vault backup: new option "Alerts for items scheduled for deletion"

key        | value
---------- | ---
date       | 2026-09-23T15:34:53.421715+00:00
version    | 3.0.0b1
class      | feature
edition    | ultimate
component  | checks
level      | 1
compatible | yes

Azure keeps a deleted backup item in the vault for the soft delete grace period,
and the check alerted for that whole period.

The check now shows the remaining time before Azure deletes the item
permanently. The new option "Alerts for items scheduled for deletion" of the rule "Azure
recovery services vault backup" makes the check report OK for such items. The
default behaviour does not change.
