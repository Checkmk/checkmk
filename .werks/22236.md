# rrdtool: remove the graph and graphv sub-commands

key        | value
---------- | ---
date       | 2026-09-22T12:50:13.200628+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | omd
level      | 1
compatible | no

The `rrdtool` command shipped inside a Checkmk site no longer draws images.
`rrdtool graph` and `rrdtool graphv` now fail with:

```
ERROR: the instance of rrdtool has been compiled without graphics
```

The Python binding no longer provides `graph()` and `graphv()`, and the Perl
binding no longer provides `RRDs::graph` and `RRDs::graphv`.

Every other sub-command is unaffected, including `create`, `update`, `fetch`,
`info`, `tune`, `dump`, `restore`, `lastupdate` and `xport`. Collecting and
storing measurements is unaffected, and so are the graphs in the Checkmk user
interface, in notifications and in reports: Checkmk renders those itself.

Leaving out the graph sub-system removes rrdtool's dependency on the Cairo,
Pango, gobject and libpng libraries.

If you produced images from a site's measurement data, use one of the following
instead:

* The `cmk/get_graph` REST endpoint returns the values of a graph, which you can
  plot with a tool of your choice.
* In Checkmk Pro and higher, the user interface can export a graph as a PNG
  image.
* To keep using `rrdtool graph` on a site's RRD files, install the rrdtool
  package of your Linux distribution and run it against those files.
