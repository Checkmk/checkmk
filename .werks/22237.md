# Installed RAM missing for Windows hosts in dashboard and view

The "Installed RAM" widget of the built-in dashboard "Single Windows host"
showed "No data was found with the current parameters of this widget", and the
"Memory installed (last 365d)" column of the built-in view
"Windows [CPU & Memory]" stayed empty.

Both now take the installed RAM from the HW/SW inventory, under
"Hardware > Memory (RAM) > Total usable RAM". HW/SW inventory therefore has to
be enabled for these hosts. Without it the widget shows "n/a" and the column
stays empty.

The column is now titled "Memory installed", because it no longer shows a
one-year average.

The built-in dashboard and the built-in view are updated automatically. If you
created your own copy of either, adjust the widget respectively the column by
hand.
