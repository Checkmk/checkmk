# Micro Core no longer stops when an alert handler is slow to accept an event

key        | value
---------- | ---
date       | 2026-09-03T07:30:49.907342+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | cmc
level      | 2
compatible | yes

On sites that use alert handlers, the Checkmk Micro Core could stop
unexpectedly. Monitoring then paused until the core came back up, and
`cmc.log` ended with

    cannot send alert data: Connection timed out

The core stopped when it could not pass an event to an alert handler
quickly enough, typically while the alert handler was restarting itself
after a configuration change. Such a delay passes on its own, but the
core treated it as fatal.

The core now keeps monitoring and delivers the event as soon as the alert
handler accepts it.
