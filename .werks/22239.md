# Update Windows agent Python runtime to 3.13.15

key        | value

The Checkmk Windows agent bundles its own Python runtime. That runtime now
ships 3.13.15.

The release addresses issues in *tarfile* (a bypass of CVE-2025-4330) and
*http.client* (GHSA-w4q2-g22w-6fr4), and updates the bundled *libexpat* to
2.8.2.

None of these flaws affect Checkmk directly. Updating the runtime reduces the
scope of an attack against the agent.
