# Update Windows agent Python runtime to 3.13.16

key        | value
---------- | ---

The Checkmk Windows agent bundles its own Python runtime. That runtime now
ships 3.13.16.

The release addresses issues in *tarfile* (CVE-2026-82049, CVE-2026-19672,
CVE-2026-87910), *ssl* (CVE-2026-19445, CVE-2026-19553), *zipfile*
(CVE-2026-15310), *urllib.request* (CVE-2026-15806) and *stringprep*
(CVE-2026-17084). It also updates the bundled *libexpat* to 2.8.5 and
*OpenSSL* to 3.5.9.

None of these flaws affect Checkmk directly. Updating the runtime reduces the
scope of an attack against the agent.
