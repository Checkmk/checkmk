# Agent Controller auto-registration: Baking agents failed after renaming or copying a site

key        | value
---------- | ---
date       | 2026-10-21T09:39:49.075717+00:00
version    | 2.4.0p39
class      | fix
edition    | cce
component  | agents
level      | 1
compatible | yes

Previously, if a site had been renamed or copied with `omd mv` or `omd cp`, baking agents with an _Agent Controller auto-registration_ rule failed with this error:

```
Could not load certificate for site '<site ID>'
```

The bakery now finds the site's CA certificate after a rename or copy. Bake the agents again; no other action is needed.
