# Passive Checkmk services no longer turn stale outside their check period

key        | value
---------- | ---
date       | 2026-10-23T10:06:27.374382+00:00
version    | 2.5.0p18
class      | fix
edition    | pro
component  | cmc
level      | 1
compatible | yes

Services with a rule "Check period for passive Checkmk services" turned stale
shortly after their time period ended, although they are not checked outside it.

The Checkmk Micro Core now takes this time period into account when it decides
whether a service is stale, as it already did for "Check period for active
services".

If you added a rule "Check period for active services" as a workaround, you can
remove it.
