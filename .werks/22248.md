# Adding a view widget to a dashboard could fail with an unexpected error

On a site with extension packages installed, adding or editing a "Views" widget
on a dashboard could replace the page with an unexpected error. Existing
dashboards and their widgets kept working; only adding or editing a widget was
affected.

One extension was enough to trigger this, and it then broke the widget wizard
for the whole site - including widgets that had nothing to do with that
extension. This no longer happens.

If this affected you, nothing in your dashboards or your configuration needs to
be repaired. The extension that triggered it should still be corrected by its
maintainer, so report it to them.

## Technical background

The endpoints listing data sources and visual infos passed a plugin's title
into the response model unchanged, so a title that is not a `str` value - a
lazily translated one, for example - made the entire collection fail to
serialize. The title is now coerced at the API boundary. This does not widen
the plugin interface: a title is still required to be a `str` value.
