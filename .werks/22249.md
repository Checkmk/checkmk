# check_sftp: Replace host macros in host name and service name

version    | 2.4.0p38
class      | fix
edition    | cre

level      | 1
compatible | yes

Until now, the _Check SFTP service_ rule used macros like `$HOSTNAME$` literally. If you set the _Host name_ field to `$HOSTNAME$` so you could apply one rule to many hosts, the check tried to connect to a host that is literally named `$HOSTNAME$`. Every service then went CRIT with "Connection failed!".

This is fixed. Host macros in the _Host name_ field and in a custom service name are now replaced with the values of the host the check runs for.
