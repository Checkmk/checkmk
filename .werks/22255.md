# Linux agent: Fix encrypted agent output on hosts with OpenSSL older than 1.1.1

This werk affects you if you use symmetric agent encryption (ruleset _Encryption (Linux, Windows)_
or `encryption.cfg`) with the legacy pull mode of the Linux agent, on hosts with an OpenSSL version
older than 1.1.1, for example RHEL/CentOS 7.
Hosts registered for TLS via `cmk-agent-ctl` are not affected.

Since Checkmk 2.5.0, the Linux agent sent garbage instead of the encrypted agent output on such hosts.
When running `check_mk_agent -d`, you saw errors like `printf: missing hex digit for \x`.
Checkmk failed to decrypt the output with `Decryption failed: MAC mismatch`, so these hosts
could not be monitored any more.
Encrypted real-time checks were affected in the same way.

To fix this, update the agent on the affected hosts.
