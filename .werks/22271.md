# Relay: Do not resend an unchanged task list on every poll

key        | value
---------- | ---
date       | 2026-10-06T20:11:20.559483+00:00
version    | 2.5.0p16
class      | fix
edition    | ultimate
component  | relay
level      | 1
compatible | yes

A relay polls the Checkmk site for pending tasks every half second. Until
now, the site sent the full task list on every poll. While a configuration
task was pending, that list contained the configuration archive, so the
site sent the same large archive again and again.

The site now tags each task list with an ETag. If the list has not changed
since the last poll, the site answers "304 Not Modified" and does not send
the list again.
