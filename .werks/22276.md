# Agent Bakery: migrated rule sets merge all matching rules

The bakery rule sets listed below have been migrated to the new rule set API.
As a consequence, multiple matching rules of these rule sets are now merged to compute the effective parameters: every parameter takes its value from the first matching rule that sets it.
Previously only the first matching rule was applied as a whole, and parameters it did not set were left at their defaults, regardless of what lower priority rules configured.

During the update to this version, existing rules are "filled": parameters an existing rule did not set explicitly are set to the value that was effective before, so that the outcome of the rule evaluation does not change for existing configurations.
Rules created after the update follow the new merge semantics.

Note that the format of the rule values changes for these rule sets as well.
The REST API only accepts rule values in the new format, so scripts that create or edit rules of these rule sets via the REST API may have to be adapted.
