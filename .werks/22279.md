# Wrong Checkmk version comparison for MKP version requirements

Checkmk compared versions incorrectly when checking the "Minimum required
Checkmk version" and "Valid until Checkmk version" of an extension package
(MKP).
Beta versions with a large build number were considered newer than patch
releases of the same version. For example, `2.5.0b999` was considered newer
than `2.5.0p14`.

This affected:

* installing, enabling and updating packages with the `mkp` command,
  including `mkp update-active`, which is run during `omd update`
* enabling packages in _Setup > Extension packages_
* updating the active packages when activating changes
* the check of the minimum and maximum version in the package editor

The versions are now compared correctly.
