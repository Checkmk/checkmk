# Plug-in APIs: obfuscated storage for secrets

Special agents and active checks can now keep values between runs without storing them in plain text:
`cmk.server_side_programs.v1.ObfuscatedStorage` works like `cmk.server_side_programs.v1.Storage`, but passes all values through an obfuscator.

You can find details and an example in the
[plug-in API documentation](https://docs.checkmk.com/plugin-api/master/cmk.server_side_programs/index.html)
or in a running site's "Help" menu, under "Plugin API references".
