# Plug-in APIs: obfuscated storage for secrets

Special agents and active checks can now keep values between runs without storing them in plain text:
`cmk.server_side_programs.v1.ObfuscatedStorage` works like `cmk.server_side_programs.v1.Storage`, but passes all values through an obfuscator.
For secrets, use `cmk.password_store.v1.Obfuscator`.
It obfuscates them with the key of the site's password store.
This is not protection: anyone who can read the site's files can read that key.

You can find details and examples in the plug-in API documentation of the
[server-side programs](https://docs.checkmk.com/plugin-api/master/cmk.server_side_programs/index.html)
and the
[password store](https://docs.checkmk.com/plugin-api/master/cmk.password_store/index.html),
or in a running site's "Help" menu, under "Plugin API references".
