# Pure Storage FlashArray: Failed sections showed data of other sections

key        | value
---------- | ---
date       | 2026-10-16T09:23:52.517400+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Pure Storage FlashArray special agent could not fetch one of its sections
(for example because of an HTTP error), it still wrote that section, but filled
it with the data of the section fetched before. The affected services then showed
wrong data. If the very first section failed, the agent crashed instead.

The special agent now skips sections it could not fetch.
