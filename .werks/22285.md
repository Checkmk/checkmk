# Jenkins: Report failed requests

If a request of the Jenkins special agent failed, for example because the
configured user was missing a permission, the agent silently stopped: the data of
the failed request and of all following requests was missing, while the
_Check_MK_ service stayed `OK`. Unexpected errors were swallowed in the same way.

The _Check_MK_ service now reports such failures. Unexpected errors create a
crash report.

After the update, the _Check_MK_ service of your Jenkins hosts may change its
state if one of the requests has been failing unnoticed.
