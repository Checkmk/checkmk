# Entity sensors: don't crash on sensors without a sensor type

key        | value
---------- | ---
date       | 2026-09-25T12:19:05.838571+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

This werk affects SNMP devices that are monitored through the ENTITY-SENSOR-MIB,
such as Palo Alto, Cisco ASA, Arista and Cisco Firepower devices.

Some devices report sensors without a sensor type, for example the sensors of a
transceiver slot. In this case the section `entity_sensors` crashed with
`KeyError: ''`, and the services _Temperature_, _Fan_ and _Power_ of the whole
device got no data.

Checkmk now skips sensors without a known sensor type and monitors all other
sensors of the device as before.
