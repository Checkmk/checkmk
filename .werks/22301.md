# NetApp ONTAP: Node data missing when a node has no CPU value

key        | value
---------- | ---
date       | 2026-09-29T09:34:59.550230+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

This werk impacts those who monitor NetApp ONTAP systems.

The ONTAP REST API may send a node without its CPU utilization data. The
special agent then failed on the whole node data, and the service
_NetApp ONTAP Agent info_ reported the error `'metric'`.

The special agent now reports the node without a CPU value.
A node that has no CPU value gets no
_CPU utilization Node_ service. If such a service already exists, it goes
`UNKNOWN` until ONTAP sends the value again.
