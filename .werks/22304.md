# Embed certificates for the agent controller

The new option "Embed certificates" of the agent rule "Agent Controller" bakes additional CA certificates into the agent package.
The agent controller trusts each one, on top of the certificate it receives when it registers, but only on connections to the site the certificate belongs to.

This lets hosts trust a site's upcoming CA before the CA is rotated, so they don't need to re-register afterwards.
