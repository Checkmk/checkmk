# Create Agent signature keys with 4096 bits

key        | value
---------- | ---
date       | 2026-10-30T14:20:13.714962+00:00
class      | fix
edition    | pro
component  | core
level      | 1
compatible | yes

Since Checkmk 2.5.0, Agent signature keys created in Setup were generated as 1024-bit RSA keys.
New keys are now generated with 4096 bits again.

Existing keys are not affected and can still be used. Replacing 1024-bit agent signature keys is recommended: a new key should be created and the agents should be baked with it.
