# VEEAM Client: jobs with an empty status are now monitored as UNKNOWN instead of being dropped

key        | value
---------- | ---
date       | 2026-09-23T08:59:19.648678+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Previously, a VEEAM Client job whose agent output reported an empty or missing
status was silently discarded while parsing the `<<<veeam_client>>>` section.
No service was created for such a job, so it disappeared from monitoring
without any indication that something was wrong.

Now the job is kept and its service is reported in the state UNKNOWN. A job
that Veeam reports without a usable status therefore stays visible instead of
vanishing unnoticed.

After the update, a host with such a job may show a new VEEAM Client service in
the state UNKNOWN on the next service discovery. No configuration changes are
required.
