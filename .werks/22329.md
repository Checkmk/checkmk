# EC: no bogus error for expected messages

key        | value
---------- | ---
date       | 2026-10-22T12:11:04.775577+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

For every rule with _Expect regular messages_ which got some, but not enough
messages within its interval, the Event Console logged the error "Cannot remove
event ...: not present" together with a traceback in `var/log/mkeventd.log`.
Apart from cluttering the log, this was harmless: The Event Console opened the
event about the missing messages as configured.

The Event Console now handles this case without logging an error.
