# EC: reload intervals and replication too

key        | value
---------- | ---
date       | 2026-10-22T12:11:05.967503+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

When reloading its configuration, e.g. after activating changes, the Event
Console ignored changes to the global settings _Housekeeping interval_, _State
retention interval_ and _Statistics interval_ and to its replication from a
central Event Console until it was restarted. For example, an Event Console
which you had just configured to replicate the events of a central Event
Console didn't contact it until the next restart.

The Event Console now applies these changes when reloading its configuration.
Changed intervals apply right away, counted from the last run of the respective
task.
