# Notifications: honor EC priority ranges

key        | value
---------- | ---
date       | 2026-10-22T13:06:59.242357+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | notifications
level      | 1
compatible | no

A notification rule filtering Event Console alerts by their _Syslog priority_
only filtered them if the range went from the less to the more severe priority,
like "from warning to emerg". With a range in the other direction, like "from
emerg to warning", or with a single priority, like "from crit to crit", the rule
matched Event Console alerts of every priority.

Such ranges now filter the alerts as configured.

If you use _Syslog priority_ for filtering, review your rules to see if they
still behave as intended.
