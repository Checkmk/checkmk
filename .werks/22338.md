# Reports: keep a graph's heading and the graph itself on the same page

key        | value
---------- | ---
date       | 2026-09-02T10:28:12.707145+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | reporting
level      | 1
compatible | yes

When a graph report element was configured to use its graph's title as
a heading, that heading could end up stranded alone at the bottom of a
page while the graph itself started on the next page - happening
whenever the heading happened to fit in the remaining space but the
graph didn't.

The heading is now always kept together with its graph on the same
page.
