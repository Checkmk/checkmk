# Reports: keep a table's heading and its first rows on the same page

key        | value
---------- | ---
date       | 2026-09-02T10:31:03.034135+00:00
version    | 2.5.0p14
class      | fix
edition    | pro
component  | reporting
level      | 1
compatible | yes

A GUI view or availability table report element's heading could end
up stranded alone at the bottom of a page while its table started on
the next page - happening whenever the heading happened to fit in the
remaining space but the table didn't.

The heading now reserves enough room for itself plus its header row
and first data row, so they stay together. Longer tables can still
continue onto further pages as before.
