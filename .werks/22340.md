# Reports: keep a sub-report's heading with its first content on the same page

key        | value
---------- | ---
date       | 2026-09-02T10:33:52.429722+00:00
version    | 2.4.0p37
class      | fix
edition    | cee
component  | reporting
level      | 1
compatible | yes

The heading of a "Host report for multiple hosts" or "Service report
for multiple services" element (e.g. "5. Report of host xyz") could
end up stranded alone at the bottom of a page while its first content
element started on the next page.

The heading now reserves enough room for itself plus a typical first
child element, so they stay together in the common case.
