# Reports: prevent a graph's custom-titled heading from landing on a different page than its graph

key        | value
---------- | ---
date       | 2026-09-04T08:13:59.319212+00:00
version    | 2.5.0p14
class      | fix
edition    | pro
component  | reporting
level      | 1
compatible | yes

A graph report element's heading was not guaranteed to land on the
same page as its graph when "Customize title" was used: whenever the
heading fit in the space remaining on a page but the graph didn't,
the heading ended up alone at the bottom of that page while the graph
started on the next one.

Before adding the heading, the report now works out the first
graph's real rendered height and breaks to a new page early if
needed, so the heading and its graph always land together.
