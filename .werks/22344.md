# Veeam CDP jobs: discovery of disabled jobs is configurable

version    | 3.0.0b1
class      | feature
edition    | community

compatible | yes

The Veeam agent plug-in reports Continuous Data Protection (CDP) jobs in any
state, including disabled ones, and disabled CDP jobs are discovered as
_VEEAM CDP Job_ services with the state `OK`. Until now, disabled CDP jobs could
only be excluded with a *Disabled services* rule, one service at a time.

You can now decide whether disabled CDP jobs are discovered with the new rule
_Veeam: CDP job discovery_. By default, they are still discovered, so nothing
changes for existing setups. To stop discovering them, disable _Discover disabled
CDP jobs_ in the rule and run a service discovery on the Veeam backup server host.

No update of the agent plug-in is required.
