# Veeam agent plug-in: error handler no longer hides the original error

key        | value
---------- | ---
date       | 2026-10-13T15:27:11.772043+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Veeam agent plug-in (`veeam_backup_status.ps1`) ran into an unexpected
error while collecting data, its final error handler tried to read the
`ItemName` property of the exception. Most exceptions don't have that property.
With PowerShell strict mode enabled, this raised a second error, which replaced
the original one:

_The property 'ItemName' cannot be found on this object. Verify that the property exists._

The actual cause of the failure was therefore not reported.

The error handler now reports the complete original error, including its
message, the script position where it occurred and its error category.

To benefit from this fix, update the agent plug-in on the Veeam backup server.
