# Export as PDF: Views with icons that have no PDF variant failed to render

key        | value
---------- | ---
date       | 2026-10-26T12:37:22+00:00
version    | 2.4.0p40
class      | fix
edition    | cee
component  | reporting
level      | 1
compatible | yes

Exporting a view with _Export > This view as PDF_ failed if a table cell
contained an icon that is only available as SVG. Instead of the table, the
PDF showed the error

_Error while rendering element type 'A Multisite view'_ ...
_ValueError: Image type not supported_

This affected, for example, the view _Monitor > System > Agent update status_
as soon as a host needed an agent update and had a baked agent.

This has been fixed. Such icons are now left out of the PDF and the rest of
the view is rendered as usual.
