# NTNX VMTools: WARN when the guest tools are installed but disabled

key        | value
---------- | ---
date       | 2026-11-11T11:02:34.152649+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Previously, the service _NTNX VMTools_ stayed `OK` with "No tools enabled"
when the Nutanix guest tools of a VM were installed but disabled, even if
the rule _Nutanix Prism VM Tools_ asked for them to be enabled, which is
the default. The service now goes `WARN` with "No tools enabled, but
should be enabled".

VMs without guest tools are not affected: their activation state stays
`OK`, and the install state reports them as before.

This applies to the data of both the legacy and the v4 Prism agent.
After the update, you may see new `WARN` states on VMs whose guest tools
are installed but disabled.
