# Nutanix Prism VM Tools: "not disabled" now reads "disabled"

---------- | ---
date       | 2026-11-11T11:04:52.187911+00:00
version    | 2.4.0p41
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

In the rule _Nutanix Prism VM Tools_, the option for disabled guest
tools under "VMTools activation state" was labelled "not disabled".
The option has always meant that the tools should be disabled: with it,
_NTNX VMTools_ goes `WARN` when the tools are enabled. It is now
labelled "disabled".

Existing rules keep their meaning. If you picked "not disabled"
expecting the tools to be enabled, change the option to "enabled".
