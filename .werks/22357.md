# omd update: Run the pre-flight checks only once

key        | value
---------- | ---
date       | 2026-11-19T14:31:08.312612+00:00
class      | feature
edition    | community
component  | omd
level      | 2
compatible | yes

`omd update` no longer repeats the pre-flight checks. Previously, it ran
them once before the update and a second time while updating the
configuration.

The pre-flight checks now run against the extension packages (MKPs) of
the target version. The update activates them first and restores the
previous ones if it is aborted. Before that, the checks ran against the
old packages and predicted which ones the update would disable. Dropping
this prediction run is where the time saving comes from.
