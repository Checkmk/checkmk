# cisco_temperature_dom: Missing DOM services on IOS XR 25.2.21

Checkmk discovers a DOM service for an optical transceiver only if its
interface is administratively up, unless the rule "Cisco DOM discovery"
says otherwise. To find that interface, Checkmk walks up the device's
hardware tree from the sensor until it reaches a component that the device
maps to an interface.

On Cisco 8000 routers running IOS XR 25.2.21, the device also maps the
management port, which sits directly on the mother board. Checkmk then
gave every optical sensor on the board the admin state of the management
port. If that port was down, Checkmk discovered no DOM services at all,
although the device still reported every reading. If it was up, Checkmk
also discovered DOM services for ports that were shut down.

Now each sensor takes the admin state of the interface closest to it in
the hardware tree. Run a service discovery on the affected hosts to add the
missing services.
