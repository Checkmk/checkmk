# Backup: allow local targets below a mount point

key        | value
---------- | ---
date       | 2026-11-26T12:38:38.500268+00:00
class      | fix
edition    | community
component  | core
level      | 1
compatible | yes

Previously, a local backup target with the _Mount point_ option enabled
failed unless the configured path was a mount point itself. Targets
pointing to a directory below a mounted network share were rejected,
including targets created in the Checkmk appliance web interface, which
allows exactly that setup.

The option now checks that the target is on a dedicated filesystem
instead: before each backup, Checkmk verifies that the target path is
neither on the root filesystem nor on the filesystem the site is stored
on. A backup to an unmounted network share still fails instead of
silently writing to the local disk, and any directory below a mount
point is accepted.
