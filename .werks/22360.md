# Livestatus: Remove "Polling failed: Connection timed out" debug message

key        | value
---------- | ---
date       | 2026-11-03T13:29:27.939704+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | livestatus
level      | 1
compatible | yes

When the Livestatus log level was set to "Debug", the log file filled up
with "Polling failed: Connection timed out" messages. Livestatus wrote
one every 200 ms while a connection was waiting for a query, for example
an idle keep-alive connection.

This timeout is expected and is not an error, so the message has been
removed.
