# Veeam agent plug-in: Close the connection to the backup server

key        | value
---------- | ---
date       | 2026-11-17T11:43:22.334862+00:00
version    | 2.5.0p22
class      | fix
edition    | community
component  | checks
level      | 2
compatible | yes

Since Checkmk 2.4.0p20, the Veeam agent plug-in (`veeam_backup_status.ps1`)
did not always close its connection to the Veeam Backup & Replication server
after collecting data. Runs could leave a `Veeam.Backup.Satellite` process
behind on the backup server. Over time these processes piled up and could
use up the server's memory.

The agent plug-in now disconnects from the backup server at the end of every
run, including runs that end with an error.

To benefit from this fix, update the agent plug-in on the Veeam backup server.
