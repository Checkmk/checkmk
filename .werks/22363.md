# Proxmox VE VM Info: Fix update failure for rules created in 2.4.0

version    | 3.0.0b1

edition    | community

level      | 1
compatible | yes

Previously, the update from 2.4.0 to 2.5.0 could not validate rules of the
ruleset _Proxmox VE VM Info_. `cmk-update-config` showed this warning and
created a crash report:

_Exception in ruleset implementation detected (Ruleset: checkgroup_parameters:proxmox_ve_vm_info, ...)
Validation errors: [ValidationMessage(location=['lock_duration'], message='Required field missing', ...)]_

You then had to fix the rule by hand.

The cause: Checkmk 2.5.0 added the required option _Lock duration levels_ to
this ruleset. Rules created in 2.4.0 do not have this option.

The update now adds _Lock duration levels_ with the default values to these
rules: `WARN` at 15 minutes and `CRIT` at 30 minutes. The check already used
these levels for these rules, so your monitoring results do not change.
Rules that you did not fix yet are migrated on the next update.
