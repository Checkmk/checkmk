# Proxmox VE Replication: don't crash on multi-line replication errors

key        | value
---------- | ---
date       | 2026-09-24T13:28:22.152272+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Proxmox VE replication job failed with an error message of several
lines, the _Proxmox VE Replication_ service crashed with
`ValueError: '\n' not allowed in 'summary'`. An example is the message
`No common base snapshot on volume(s) ...`, followed by
`Please remove the problematic volume(s) ...` on a second line.

The service now goes to `CRIT` and shows the full error message on one line.
