# proxmox_ve: don't crash when a node reports 0 total CPUs or memory

key        | value
---------- | ---
date       | 2026-09-24T13:45:00.000000+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Proxmox VE node reported a total of 0 CPUs or 0 memory (for example, when
the node was offline), the services "Proxmox VE CPU allocation ratio" and
"Proxmox VE Memory allocation ratio" crashed with
"ZeroDivisionError: float division by zero".

Both services now report OK and show the status of the node and its total CPUs
or total memory. For an offline node, or a node that reports a total of 0, the
services no longer calculate the allocation ratio.
