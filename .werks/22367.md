# Proxmox VE: Don't crash on storages with an unknown storage type

key        | value
---------- | ---
date       | 2026-10-09T08:46:00+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The Proxmox VE special agent crashed if a storage in the cluster had a
type that Checkmk did not know. This happens, for example, with
third-party storage plugins such as BlockBridge. The agent stopped with
a `ValidationError` for `SectionNodeStorages`:

_Input should be 'btrfs', 'cephfs', 'cifs', 'dir', ... [type=enum, input_value='blockbridge', input_type=str]_

This stopped the monitoring of the whole Proxmox VE cluster.

The special agent now accepts all storage types. Checkmk discovers a
storage with an unknown type as a _Proxmox VE Storage_ service, the same
as a directory storage. The service summary shows the type from Proxmox
VE and marks it as unknown, for example
`Type: blockbridge (unknown storage type)`.

To get the new storage services, run a service discovery on the affected
Proxmox VE nodes.
