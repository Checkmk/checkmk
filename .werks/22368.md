# Proxmox: no CRIT for pvescheduler child processes

key        | value
---------- | ---
date       | 2026-10-14T09:35:45.599033+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | no

The shipped rule for the ruleset _Process discovery_ that monitors basic
Proxmox processes reported `CRIT` for the `pvescheduler` process on Proxmox
nodes.

The `pvescheduler` daemon regularly starts child processes for replication and
for scheduled jobs, for example backups. The shipped rule allowed exactly one
process, so the service went `CRIT` while such a child process was running.

The shipped rule now allows up to three processes. During an update, Checkmk
corrects the levels of the affected rule automatically.

**Incompatibility hint**

This automatic correction only applies if you did not change the levels of the
rule yourself. The new levels apply only to newly discovered services. To apply
them to existing services, run a service discovery on the affected Proxmox
nodes and accept the changed parameters.
