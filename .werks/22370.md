# Recurring downtimes used UTC on some distros

Since Werk #22241, the core repeats recurring downtimes in the time zone of
their rule. On Debian, SLES and Ubuntu 26.04, the core could not read the time
zone data of the system and used UTC instead.

Downtimes whose first start lies in summer time started an hour early in
winter, and downtimes whose first start lies in winter time would have started
an hour late in summer. Downtimes set with the _Schedule downtimes_ command
were affected in the same way.

If the core cannot read the time zone data of the system, it now uses its
built-in time zone data and logs a warning. No additional action is required.
