# Keep 'Show in dashboard name dropdown' when cloning dashboards

key        | value
---------- | ---
date       | 2026-09-25T15:49:18.127090+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Previously, cloning a dashboard always enabled _Show in dashboard name
dropdown_ on the clone, even if the original dashboard had it disabled.
The clone now keeps the setting of the original dashboard.

Dashboards you have already cloned are not changed. To hide one from the
dropdown again, disable _Show in dashboard name dropdown_ in its
dashboard settings.
