# Update Windows agent Python runtime to 3.13.18

key        | value

The Checkmk Windows agent bundles its own Python runtime. That runtime now
ships 3.13.18.

The release addresses issues in *ssl* (CVE-2026-115557), *tarfile*
(CVE-2026-114583), *tempfile* (CVE-2026-12345) and *mimetypes*
(CVE-2024-3220). It also updates the bundled *libexpat* to 2.9.0
(CVE-2026-77214, CVE-2026-102633).

None of these flaws affect Checkmk directly. Updating the runtime reduces the
scope of an attack against the agent.
