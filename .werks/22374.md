# All hosts / Services of a host: show never-checked rows as pending

---------- | ---
date       | 2026-09-09T16:12:34.049764+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

On the new "All hosts" and "Services of a host" pages, a host or service that had never been checked showed up exactly like a genuinely `OK` one - Livestatus reports state `0` for both, and these pages had no way to tell the two apart.

Such rows are now shown as `PENDING` instead:

* The state filter on both pages gained a `PENDING` option. Filtering by any other state now correctly excludes never-checked rows too, since their raw state doesn't mean anything until the first check comes in.
* On "All hosts", a host's pending services count now links to that host's services filtered to `PENDING`, instead of opening the classic "Services in pending state" view.
