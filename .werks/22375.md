The redesigned "All hosts" page, available as an opt in preview since Checkmk 2.5, is now the
default. It replaces the classic view in the Monitor menu and in the sidebar's "Views" snapin;
existing bookmarks and saved views that point to the classic view keep working.

The new "Services of a host" page is reached by clicking the number of services on a host's row on
the new "All hosts" page, and is part of the same rework.

## What's new on these pages

Both pages let you filter directly from a column's header instead of using a separate filter form,
and let you sort and search the table in place. You can also add or remove columns right on the
page, without the need to create a new view. Clicking a host's or a service's name opens a details
panel with its overview, history and available actions: acknowledging a problem, scheduling a
downtime, or rescheduling a check. You can carry out these actions without losing your place in the
table.

## Sharing a view

For now, a page's filters, sorting and search live entirely in the URL, so sharing or bookmarking
that URL is how you hand someone else, or yourself later, the exact same view. The sidebar's
"Bookmarks" snapin can keep such links per user. Named, reusable saved views, like the classic
views' "Save as", are planned but not available yet.

## Reaching the classic view

Both new pages offer a "Return to classic view" button that takes you back to the classic "All
hosts" or "Services of host" view.

The "Overview" sidebar snapin's host count now links to the new "All hosts" page as well, as long
as it shows the unfiltered total number of hosts. A filtered count, for example in a customized
snapin, still opens the classic view, since the new page does not yet support that filter format.
Support for this is planned, so the new pages can also work as dashboard widgets driven by the
dashboard's filter panel.
