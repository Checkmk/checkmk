# Analyze configuration: Detect an outdated system Apache configuration

key        | value

class      | feature
edition    | community
component  | wato

The system Apache serves a site with the configuration in
`/omd/apache/SITE.conf`. Only root can rewrite it, with
`omd update-apache-config SITE`. If this step is missed after changing the
`APACHE_*` settings of a site, for example with `omd config`, by editing
`site.conf` or by restoring a backup, the site keeps running with the old
configuration. It can then be unreachable on its new address or port, without
any hint why.

The file now records the settings it was created from. The new test
_System Apache configuration up to date_ in
_Setup > Maintenance > Analyze configuration_ warns when they do not match the
site's settings. Run `omd update-apache-config SITE` as root to fix it.

Files written by earlier Checkmk versions don't record any settings. The test
warns about them until root has rewritten them once. Sites in the Checkmk
Docker image are not checked, because no system Apache serves them there.
