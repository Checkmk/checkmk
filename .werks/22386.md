# Splunk: Report failed requests

version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a request of the Splunk special agent failed, for example because the Splunk
server was not reachable for a moment or returned an error, the agent silently
stopped: the data of the failed request and of all following requests was
missing, while the _Check_MK_ service stayed `OK`. Unexpected errors were
swallowed in the same way.

The _Check_MK_ service now reports such failures.

After the update, the _Check_MK_ service of your Splunk hosts may change its
state if one of the requests has been failing unnoticed.
