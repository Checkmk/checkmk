# Docker: Node name of containers missing in HW/SW Inventory

The HW/SW inventory of Docker containers did not contain the name of the
Docker node the container runs on, although the Docker agent plug-in sent
it. The node name now shows up as "Node name" under
"Software > Applications > Docker > Container".
