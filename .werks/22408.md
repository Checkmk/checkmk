# Microsoft Azure: Accept client secrets that start with a dash

key        | value
---------- | ---
date       | 2026-09-29T12:16:42.113836+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

Previously, the Microsoft Azure special agent failed if the client secret
started with a dash (`-`). The agent stopped with the error
`argument --secret: expected one argument` and fetched no data from Azure.
This happened both for explicit passwords and for passwords from the
password store.

The agent now receives the secret as a single argument, so a client secret
can start with any character. You do not need to change your configuration.
