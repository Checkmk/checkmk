# ucd_cpu_util: do not crash when the device sends no CPU data

key        | value
---------- | ---
date       | 2026-09-22T07:30:00.000000+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If a device stopped delivering the UCD CPU statistics, for example because the
polled SNMP subtree came back empty for one cycle, the `CPU utilization` service
produced a crash report with `KeyError: 'error'` instead of a result.

Empty data is now recognised as such and handled like any other missing
section: no result is submitted, so the service keeps its last state and goes
stale.
