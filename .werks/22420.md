# AIX agent: uptime parsing aborted all subsequent sections

key        | value
---------- | ---
date       | 2026-09-29T09:40:18.629752+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

On some AIX 7.3 hosts, `uptime` prints the day count without a
trailing comma, for example `up 96 days  7:43,`. The AIX agent failed
to parse this: it stopped with `syntax error in expression` right
after `<<<uptime>>>` and never produced the remaining sections, spool
files, MRPE, local checks and plug-ins. The affected services went
stale.

The agent now accepts the day count with or without the comma. To
apply the fix, redeploy the AIX agent.
