# Redfish: discovery no longer crashes on numeric resource IDs

key        | value
---------- | ---
date       | 2026-09-29T14:26:25.376789+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Some Redfish devices, for example certain rack PDUs, report the ID of
a resource as a number instead of text. On such hosts the
_Check_MK Discovery_ service crashed with `TypeError: 'item' must be a
non empty string or ommited entirely, got 1`, and the resource was not
discovered.

These resources are now discovered and monitored as usual, e.g. a PDU
with the ID 1 as _PDU 1_. Run a service discovery on affected hosts to
add them.
