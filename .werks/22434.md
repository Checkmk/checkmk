# vsphere: replace macros in the custom host name for SSL certificate checking

version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

In the rule "VMware ESX via vSphere", the option "SSL certificate checking" set to
"Use other host name" states that it supports macros such as `$HOSTNAME$`,
`$HOSTALIAS$` and `$HOSTADDRESS$`. The macros were never replaced, so the special
agent validated the certificate against the literal text and failed with an error
like:

`CertificateError("hostname '$HOSTNAME$.example.com' doesn't match 'vcenter.example.com'")`

The macros in this field are now replaced with the values of the monitored host.
