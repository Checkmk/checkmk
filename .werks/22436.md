# alcatel_memory: Monitor memory usage of Alcatel switches

---------- | ---

The new check plug-in `alcatel_memory` monitors the memory usage of Alcatel
switches via SNMP. It creates one _Memory_ service per switch,
which reports the usage in percent. The service is WARN at 80% and CRIT at 90%. The
levels can be configured with the rule _Memory utilization_.
