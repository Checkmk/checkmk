# Azure costs: explain the cost data delay

The Azure cost services (Azure/Costs) show the costs of the previous day.
Azure needs up to 72 hours to collect all usage for a day. Until then, the
value Azure returns is an estimate. It can rise during the day, and some
Azure service types may still have no costs, so their services show no
data.

The man pages wrongly said that the value is for the last complete day.
They now explain this behavior for both the current and the deprecated
Azure special agent.
