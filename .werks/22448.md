# Views: "Docker node" column showed a wrong node for containers with errors

The "Docker node" column showed a wrong node for some containers: for a
container that reported an error it showed the last word of the error
message, and for a container found on multiple Docker nodes it showed
"information". Such containers were also sorted and grouped by this
wrong value. The column now shows the actual node, and stays empty if
the node is not unique.
