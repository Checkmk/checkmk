# Interface discovery: Add "Match interface name (regex)" condition

---------- | ---
date       | 2026-10-01T14:10:35.874551+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Since [Werk #19972](https://checkmk.com/werk/19972), Fortigate
interfaces carry their name in the name field, not the alias. Rules in
_Network interface and switch port discovery_ that selected these
interfaces via _Match interface alias (regex)_ therefore stopped
matching, and you couldn't select them by name instead.

The ruleset now offers _Match interface name (regex)_ under _Conditions
for this rule to apply_ and under _Generate service labels for
discovered matching interfaces_.

On Fortigate hosts, replace your alias conditions with the new name
condition. Check each pattern against the interface name, which is the
service item when you use _Use name_, then rediscover the affected
hosts.
On other devices, alias conditions are unaffected.
