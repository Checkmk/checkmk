# Apache log rotation no longer reloads Apache

key        | value
---------- | ---
date       | 2026-10-02T06:11:03.679489+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | omd
level      | 1
compatible | yes

The daily log rotation at midnight site time reloaded the Apache of the site
after rotating its logs. The reload starts all GUI worker processes again. On
hosts with many sites, all sites did this at the same time, which caused a CPU
peak every night.

The Apache logs are now rotated with `copytruncate`. Apache keeps
running and continues writing to the same log files.

As a result, memory that the Apache worker processes use for the GUI is
no longer released every night. It is released when Apache is restarted
or reloaded, for example by `omd reload apache`.
