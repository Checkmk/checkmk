# Agent registration no longer waits for long-running Setup actions

key        | value
---------- | ---
date       | 2026-10-28T12:17:30.327017+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Previously, registering an existing host with `cmk-agent-ctl register`
could take minutes while a long-running Setup action, such as a bulk
discovery, was in progress. On Checkmk Ultimate sites with agents in
push mode, all push agents also had to wait until the registration was
done. Each registration also aborted a configuration sync that was
running on the site.

Registrations, including those that use a one-time registration token,
no longer wait for Setup actions and no longer abort a running
configuration sync.
