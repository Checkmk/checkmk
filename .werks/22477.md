# w32time_status: no crash on an error without a message

key        | value
---------- | ---
date       | 2026-09-23T10:38:44.406532+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If `w32tm` failed and the Windows agent delivered only the start of its
error output, e.g. `Folgender Fehler ist aufgetreten:` without the
message itself, the `Windows time service` service crashed with
`ValueError: 'summary' must be non-empty str or None`.

The service now goes to WARN and reports that the Windows time service
returned an error without a message.
