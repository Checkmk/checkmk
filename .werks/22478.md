# azure_v2: fix vaults with DPM items

key        | value
---------- | ---
date       | 2026-09-23T10:47:16.897560+00:00
version    | 2.5.0p15
class      | fix
edition    | ultimate
component  | checks
level      | 1
compatible | yes

If a Recovery Services vault contained items protected via Azure
Backup Server (DPM), all `Azure/Recovery Services Vault Backup
Container` services of that vault crashed with
`ValidationError: ... validation errors for Vault`, because Azure
reports no last backup status and no protection status for such
items.

These items are now monitored with the information Azure provides
for them, and the other backup containers of the vault are monitored
as before.
