# innovaphone: report unknown port states

key        | value
---------- | ---
date       | 2026-09-23T10:53:33.363264+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If an innovaphone PBX reported a port state other than Down or UP,
the `Port L1` service of that port crashed with `KeyError`.

The service now goes to UNKNOWN and names the state value the device
reported. Signal loss and slip errors are still evaluated.
