# elasticsearch: indices without primaries

key        | value
---------- | ---
date       | 2026-09-23T10:56:07.667433+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If Elasticsearch reported no primary shard statistics for a single
index, for example while the primary shard of that index was
unassigned, all Elasticsearch index services of the host crashed with
`ValidationError: 1 validation error for _IndexResponse`.

All other indices are now monitored as usual. The index without
primary shard statistics is left out of the monitoring data for as
long as Elasticsearch does not report them: its own service reports
that the item is not found, and a group containing it counts only its
remaining members.
