# ip_addresses: addresses without prefix

Some SNMP devices report their IP addresses without a network prefix.
For such devices the parsing of the IP address data crashed with
`ValueError: '...' does not appear to be an IPv4 or IPv6 interface`,
so their IP addresses were missing from the HW/SW Inventory and the
`cmk/l3v4_topology` and `cmk/l3v6_topology` host labels were not set.

Addresses without a prefix are now skipped, the same way addresses
with an unknown prefix already were. Addresses the device also reports
together with their netmask are inventoried as before.
