# mobileiron: report connection errors instead of crashing

key        | value
---------- | ---
date       | 2026-09-24T11:00:50.783502+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

When the configured MobileIron host was unreachable (for example, due to a DNS
resolution failure or other network error), the MobileIron special agent crashed
and filed a crash report instead of reporting a clean error.

The agent now exits with a descriptive error message when a connection error
occurs, the same way it already handled timeouts and SSL errors.
