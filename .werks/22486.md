# oracle_performance: ignore empty SIDs

---------- | ---
date       | 2026-09-25T06:55:11.773057+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the Oracle agent plugin reported performance data with an empty
instance name, the service discovery of the host crashed with
`TypeError: 'item' must be a non empty string or ommited entirely, got ''`.
As a result, no new services could be discovered on that host.

Performance data lines without an instance name are now ignored. The
Oracle performance services of all named instances are discovered and
monitored as before. The ignored lines cannot be assigned to any
instance, so no service is created for them.
