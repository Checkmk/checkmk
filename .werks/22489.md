## Widgets wait for data before updating again

Dashboard widgets such as Host statistics, Service statistics, Host
state and Service state requested new data every 60 seconds, even when
the previous request was still pending. On dashboards with many such
widgets and slow sites, requests accumulated and increased the load on
the site.

Widgets now wait until the current request has completed before updating
again 60 seconds later. If errors repeat, they wait longer between
attempts, up to 2 minutes. Changing a widget's filters still updates it
immediately.

[Werk #22324](https://checkmk.com/werk/22324) removed additional
requests right after opening a dashboard.
