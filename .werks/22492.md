# Redfish: skip empty temperature entries in discovery

key        | value
---------- | ---
date       | 2026-10-16T06:57:59.947983+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Redfish device (for example a Dell iDRAC) listed temperature
entries without any data, the service discovery of the host crashed
with `AttributeError: 'NoneType' object has no attribute 'get'`. No
services of the host could be discovered.

The discovery now skips such entries and discovers the remaining
temperature sensors as before.
