# Comments: Deleting an acknowledgement comment kept the acknowledgement

key        | value
---------- | ---
date       | 2026-11-03T07:14:51.262068+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

When you deleted the acknowledgement comment of a host or service in the
comments view, the host or service stayed acknowledged as long as any
other host or service on the site still had an acknowledgement comment.
The acknowledgement was only removed once the acknowledgement comments of
all hosts or services on the site were deleted together.

Deleting the last acknowledgement comment of a host or service now
removes its acknowledgement, regardless of acknowledgements on other
hosts or services. If a host or service has several acknowledgement
comments, deleting only some of them still keeps its acknowledgement.
