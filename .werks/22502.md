# acme_certificates: Report expired certificates instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T08:45:16.807263+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a certificate on an ACME Packet (Oracle) session border controller had
already expired, the `Certificate <name>` service crashed with
`ValueError: Cannot render negative timespan` instead of warning you about it.

Expired certificates are now reported as CRIT, stating how long ago they
expired, e.g. `Expired 1 year 126 days ago`.
