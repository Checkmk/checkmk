# proxmox_ve_vm_snapshot_age: Report missing snapshot data instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T08:56:32.101978+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Proxmox VE special agent could not collect snapshot data for a VM
(for example because the node hosting it could not be queried), the
`Proxmox VE VM Snapshot age` service of that VM crashed with a
`ValidationError` for `SectionSnapshots`.

The service now goes UNKNOWN and tells you that no snapshot data was received
for the VM. VMs with snapshot data are monitored as before.
