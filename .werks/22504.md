# proxmox_ve_vm_snapshot_age: Crash on missing snapshot data

key        | value
---------- | ---
date       | 2026-09-29T08:56:32.101978+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Proxmox VE special agent could not collect snapshot data for a VM
(for example because the node hosting it could not be queried), the
`Proxmox VE VM Snapshot age` service of that VM crashed with a
`ValidationError` for `SectionSnapshots`.

Such VMs are now treated as having no snapshot data: no service is
discovered for them, and an existing service goes UNKNOWN because its item is
not found in the monitoring data. VMs with snapshot data are monitored as
before.
