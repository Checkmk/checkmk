# NTNX special agent: no crash for hosts with an IPv6 address

key        | value
---------- | ---
date       | 2026-10-22T11:00:00.359908+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the host of a Nutanix Prism special agent rule had an IPv6 address,
the agent built an invalid URL (https://2001:db8::7:9440/...) and
crashed with "InvalidURL", creating a crash report on every run.

The agent now puts IPv6 addresses in brackets and works for such hosts.
