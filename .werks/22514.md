# Inline availability timelines were empty or distorted

key        | value
---------- | ---
date       | 2026-10-27T06:58:54.235693+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

The timeline bar in the availability table widened every state span by a
fixed amount, no matter how short the span was. Short spans looked much
longer than they were, and the bar no longer showed how long each state
lasted.

With 200 or more phases in the selected time range (state changes as well as
downtimes and unmonitored periods), the widening used up the whole bar. Every span ended up with zero width, so the timeline bar of
such an object stayed empty.

This affected the timeline column of the availability table in the GUI and
of availability tables in PDF reports. The span widths now match the
durations again. The separate timeline view keeps its minimum span width, so
very short phases stay visible there.
