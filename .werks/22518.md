# Dashboard widgets no longer flash "No data available" while loading

key        | value
---------- | ---
date       | 2026-10-29T12:46:27+00:00
version    | 2.5.0p19
class      | fix
edition    | pro
component  | multisite
level      | 1
compatible | yes

After you opened a dashboard, for example the Main dashboard right after
login, widgets such as Problem notifications, Problem alerts, Single
metric and Average scatterplot could show "No data available" for a
moment before they showed their data. This happened when the widget
changed its size while its data was still loading.

The widgets now show their loading indicator until the data has arrived.
