# HWg-STE/STE2: Sensors without unit monitored as temperature

key        | value
---------- | ---
date       | 2026-11-16T09:27:18.146267+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | no

Checkmk monitored every HWg-STE and STE2 sensor that is not a humidity
sensor as a temperature sensor. Sensors for which the device reports no
unit, such as TVOC or air pressure sensors, became "Temperature" services
in °C and were checked against temperature levels.

These sensors are now discovered as "Sensor" services that show the value
without a unit. The service state follows the status that the device
reports for the sensor. You can also configure levels with the rule
"Generic numeric value".

After the update, the old "Temperature" services of these sensors go
UNKNOWN. Run a service discovery on the affected hosts.
