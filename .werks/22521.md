# netgear_powersupplies: Report unknown power supply states instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T10:08:04.704941+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Netgear switch reported a power supply state that Checkmk does not know
(seen: `11`), the `Power Supply <item>` service crashed with `KeyError: '11'`.

The service now goes UNKNOWN and shows the state value the device sent, e.g.
`Status: unknown state '11' (expected 1, 2 or 3)`, so you can look it up in
the documentation of your device.
