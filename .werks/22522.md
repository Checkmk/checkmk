# hp_proliant_temp: Ignore empty sensor entries instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T10:12:36.581479+00:00
version    | 2.5.0p15
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Some HPE iLO controllers report empty entries in their temperature sensor
table, where only the status is set. The service discovery and all
`Temperature <sensor>` services of such a host then crashed with
`ValueError: invalid literal for int() with base 10: ''`.

These empty entries are now ignored, and all real temperature sensors are
discovered and monitored as usual.
