# pvecm_status: Report missing cluster values instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T10:19:08.102665+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the `pvecm status` output of a Proxmox VE node did not contain the usual
cluster values (for example because the command only printed an error
message), the `PVE Cluster State` service crashed with `KeyError: 'nodes'`.

The service now goes UNKNOWN and lists the values that are missing from the
agent output, e.g.
`Cannot evaluate cluster state, missing in agent output: nodes, quorum, expected votes, total votes`.
