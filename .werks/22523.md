# pvecm_status: Report unavailable cluster state instead of crashing

---------- | ---
date       | 2026-09-29T10:19:08.102665+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the `pvecm status` output of a Proxmox VE node did not contain the usual
cluster values (for example because the command only printed an error
message), the `PVE Cluster State` service crashed with `KeyError: 'nodes'`.

This happens, for example, on a cluster node whose corosync service is down.
The service now goes CRIT and shows the message printed by `pvecm status`,
e.g. `Cluster state unavailable: Cannot initialize CMAP service`. The details
list the cluster values that are missing from the agent output.
