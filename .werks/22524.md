# avaya_chassis_temp: Handle an empty SNMP answer instead of crashing

key        | value
---------- | ---
date       | 2026-09-29T10:23:17.145257+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If an Avaya switch answered the chassis temperature query without a value,
the `Temperature Chassis` service crashed with
`IndexError: list index out of range`.

Such an empty answer is now handled like any other missing monitoring data:
the service reports that no data was received instead of crashing.
