# Invalid rule values no longer crash the whole Check_MK service

key        | value
---------- | ---
date       | 2026-10-12T13:54:46.982076+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | core
level      | 1
compatible | yes

If a rule contained a parameter value in a format Checkmk cannot read, for
example a leftover value from a very old configuration, the "Check_MK" service
of the affected host crashed. As a result, none of the services of that host
were checked anymore.

Now the crash is limited to the service that uses the invalid value: that
service goes to UNKNOWN and the crash report names it, instead of the
"Check_MK" service. All other services of the host are checked as usual.

To get rid of the crash, open the affected rule in the setup and save it again,
or recreate it. When you update a site, `cmk-update-config` lists such rules
with the warning "Invalid rule configuration detected".
