# hp_proliant_da_phydrv: ignore empty rows

---------- | ---
date       | 2026-09-30T06:31:51.808895+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Some HPE ProLiant servers return an additional, completely empty row in
the SNMP table of physical drives. In that case the parsing of the
section failed with `ValueError: invalid literal for int() with base 10:
''`, so none of the `HW Phydrv` services could be checked and the disk
inventory was missing.

Rows that name neither a controller nor a drive are now ignored. All
real drives are monitored and inventorized as before.
