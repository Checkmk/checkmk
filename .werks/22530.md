# Azure vault: container names with spaces

key        | value
---------- | ---
date       | 2026-09-30T06:44:07.882629+00:00
version    | 3.0.0b1
class      | fix
edition    | ultimate
component  | checks
level      | 1
compatible | yes

The services `Backup Container <name>` of Azure Recovery Services vaults
crashed with `ValueError: too many values to unpack` when the name of the
protected item contained a space, for example a virtual machine or a
server with a multi-word display name.

These services are now checked normally, whatever the container is
called. This applies to both the current and the deprecated Azure
integration.
