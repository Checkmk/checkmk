# stormshield_packets: empty counters

key        | value
---------- | ---
date       | 2026-09-30T07:22:21.124588+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Stormshield firewall reported empty packet counters for one of its
interfaces, for example an SSL VPN interface, the parsing of the SNMP
data failed with `ValueError: invalid literal for int() with base 10:
''`. As a result, all `Packet Stats` services of the device crashed.

Empty counters no longer affect the other interfaces. If a monitored
interface itself reports empty counters, its service now goes to
UNKNOWN and names the values that were not received.
