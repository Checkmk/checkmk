# AWS/DynamoDB limits: Keep "No levels"

version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

In the rule _AWS/DynamoDB limits_, you can choose _No levels_ for the
number of tables, the read capacity, or the write capacity. Previously,
Checkmk could not load a rule that you had saved with this option,
because the conversion of old rule values rejected it. During an
update, `cmk-update-config` reported such rules as "Invalid rule
configuration detected" and asked whether to abort the update.

Checkmk now loads such rules. Checkmk did not change or delete the
saved values, so you do not need to do anything. If you deleted or
changed a rule to work around the problem, check it again. Rules that
use _Set levels_ and rules from older Checkmk versions are not
affected.
