# Special agents: no crash reports for network errors

key        | value
---------- | ---
date       | 2026-10-01T04:46:43.432958+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Special agents and active checks filed a crash report whenever they could not
reach the monitored system: when its host name could not be resolved, the
connection was refused or reset, the request timed out, or the TLS handshake
failed. Each run of the program added another crash report for the same
network problem, for example with the MobileIron or the Datadog special agent.

Such errors are caused by the environment and not by Checkmk. The programs now
only report the error message, so the *Check_MK* service goes CRIT as in
Checkmk 2.4.0, and no crash report is created.
