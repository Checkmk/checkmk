# win_cpuinfo: Ignore foreign lines in the agent output

key        | value
---------- | ---
date       | 2026-10-01T05:02:24.315204+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

If another program on a Windows host wrote its own messages into the CPU
section of the agent output (for example `[AGENTGATEWAY] Stopping Agent
Gateway`), the HW/SW inventory of the host failed with
`ValueError: not enough values to unpack (expected 2, got 1)` and a crash
report was created.

Such foreign lines are now ignored, and the CPU data of the host is
inventorized as before.
