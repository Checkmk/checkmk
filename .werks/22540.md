# fireeye_mail_received: Do not crash on unset time window

key        | value
---------- | ---
date       | 2026-10-01T05:13:26.980816+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If a FireEye appliance reported an unset mail statistics time window
(`00/00/00 00:00:00`), the `Mails Received` service crashed with
`ValueError: time data '00/00/00 00:00:00' does not match format`.

The service now shows the number of received mails and goes to UNKNOWN,
stating that the rate cannot be computed for the reported time window.
