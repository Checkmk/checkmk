# fjdarye_ca_ports: Ignore empty SNMP rows

key        | value
---------- | ---
date       | 2026-10-01T06:05:04.360013+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Fujitsu ETERNUS DX storage system answered one of the queried SNMP tables
with a row of empty values, the CA port services of the device failed with
`KeyError: ''` and a crash report was created.

Such empty rows are now ignored, and the CA ports reported by the device are
monitored as before.
