# cisco_redundancy: Do not crash on an empty status table

key        | value
---------- | ---
date       | 2026-10-01T06:21:32.429398+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a Cisco device answered the redundancy framework status table
(CISCO-RF-MIB) without any rows, the `Redundancy Framework Status` service
crashed with `IndexError: list index out of range`.

The service now goes to UNKNOWN, stating that no monitoring data was received,
instead of creating a crash report.
