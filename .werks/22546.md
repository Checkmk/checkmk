# Global search: filter by folder with hf: and sf:

You can now narrow down monitoring results in the global search by
folder. Prefix your search with `hf:` followed by a folder path to find
hosts, for example `hf:hamburg/infrastructure/drucker` to find all
printers in the Hamburg infrastructure folder. Use `sf:` instead to find
the services of the hosts in that folder.

The filter matches the folder names as they appear in the folder path,
not the folder titles. It ignores case, starts at the main folder and
includes all subfolders. Partial names work too, so `hf:hamb` already
finds the hosts below `hamburg`.

You can combine both filters with the other search filters. For
example, `hf:hamburg s:CPU` lists the CPU services of all hosts in the
Hamburg folder.
