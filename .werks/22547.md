# AudioCodes: report incomplete alarms

key        | value
---------- | ---
date       | 2026-10-05T05:18:06.350380+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an AudioCodes device raised or cleared an active alarm while Checkmk
read the alarm table, the "System events" service crashed with
`ValueError: invalid literal for int() with base 10: ''` or
`KeyError: ''`.

Checkmk now shows an alarm that the device raised during the read with
its correct severity. Details that Checkmk could not read are left out.
The next check shows all details.

Checkmk ignores an alarm that the device cleared during the read,
because the alarm is no longer active.
