# AudioCodes: report incomplete alarms

key        | value
---------- | ---
date       | 2026-10-05T05:18:06.350380+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an AudioCodes device reported an active alarm without a sequence
number or without a severity, the "System events" service crashed with
`ValueError: invalid literal for int() with base 10: ''` or
`KeyError: ''`.

Such alarms are now listed like any other. An alarm without a sequence
number is shown as "Alarm (no sequence number)". An alarm without a
severity is shown with severity "unknown" and turns the service UNKNOWN,
so it is not mistaken for a harmless event.
