# APC Symmetra: no crash without UPS data

key        | value
---------- | ---
date       | 2026-10-05T05:35:22.240550+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an APC UPS stopped reporting its battery data while its external
temperature sensors still delivered values, the "APC Symmetra status"
service crashed with `KeyError: 'status'`.

The service now goes to UNKNOWN with "Item not found in monitoring
data" for as long as the battery data is missing, as it already did in
Checkmk 2.4.0. The temperature services keep working.
