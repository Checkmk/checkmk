# Redfish PSU: accept voltage with unit

version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Some Redfish BMCs report the line input voltage of a power supply as
text with a unit, for example `220V`, instead of a number. The
"Power supply" service then crashed with
`ValueError: could not convert string to float: '220V'`.

A trailing "V" is now accepted, so such power supplies report their
input voltage as usual. Any other value that is not a number is shown
as UNKNOWN with the value the device sent, while input power, output
power and capacity are still reported.
