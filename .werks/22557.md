# Metric backend (custom query): reject empty service name templates

key        | value
---------- | ---
date       | 2026-09-30T13:18:58.338445+00:00
version    | 2.5.0p16
class      | fix
edition    | ultimate
component  | checks
level      | 1
compatible | yes

Previously, a rule of the _Metric backend (custom query)_ ruleset with an empty
service name template made the check plugin crash and produced a crash report as
soon as the query returned data.

The rule form now rejects an empty service name template and shows the message
directly at the field.

A template can still resolve to an empty name at runtime, for example when it
consists only of a macro whose attribute value is empty. Such series no longer
crash the plugin. They are collected under the service _Custom query metrics
with empty service name_, which goes `UNKNOWN` and lists the affected metrics so
you can adapt the template.
