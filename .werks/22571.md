# Citrix Hosting Server: no crash if unset

key        | value
---------- | ---
date       | 2026-10-05T06:12:30.083253+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the Citrix agent plug-in reported no hosting server for a machine,
as it does for example while the machine is powered off, the
"Citrix Hosting Server" service crashed with
`ValueError: 'summary' must be non-empty str or None, got`.

The service now shows "No hosting server reported" in that case. The
power state of the machine is still monitored by the "Citrix Instance
State" service.
