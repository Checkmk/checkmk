# FortiSwitch LLDP: tolerate empty index

key        | value
---------- | ---
date       | 2026-10-05T12:36:25.058474+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

Some FortiSwitch devices report LLDP neighbors without a local
interface index. The HW/SW Inventory of such a switch failed with
`KeyError: ''` while parsing the `inv_lldp_cache_fortinet` section, so
none of its LLDP neighbors were inventoried.

These neighbors are now inventoried without a local port, and all other
neighbors of the switch are shown as before.
