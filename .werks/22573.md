# StoreOnce 4.x: report missing dashboard

key        | value
---------- | ---
date       | 2026-10-05T12:43:45.878932+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the StoreOnce REST API answered the dashboard query of an appliance
with an error (for example "Internal server error") instead of the
appliance data, all "Appliance ... " services of the StoreOnce 4.x
monitoring crashed with `KeyError: 'hostname'`.

The "Status" service now still shows the appliance state, serial number
and product name. All four appliance services additionally report
UNKNOWN with "No dashboard data received from the StoreOnce REST API"
until the API delivers the dashboard data again.
