# ucd_mem: no crash on zero total RAM

key        | value
---------- | ---
date       | 2026-10-05T12:52:40.682324+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a device monitored via the UCD SNMP memory table reported a total
RAM of 0, the "Memory" service crashed with
`ZeroDivisionError: float division by zero`.

The service now reports UNKNOWN with "Cannot evaluate RAM: device
reports a total of 0 B". Swap errors reported by the device are still
shown.
