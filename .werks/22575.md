# Opsgenie: "None" as source and user when a tag is removed

key        | value
---------- | ---
date       | 2026-11-04T10:51:24.919699+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | notifications
level      | 1
compatible | yes

When flapping or a downtime of a host or service ended, the Opsgenie
notification plug-in removed the "Flapping" or "Downtime" tag from the
alert. If no source or owner was configured in the notification rule,
the alert log in Opsgenie showed "None" as source and user of this
action.

Unset values are no longer sent, so Opsgenie fills in its defaults, as
it already did for all other actions of the plug-in.
