# DB2 Counters: no crash on missing value

key        | value
---------- | ---
date       | 2026-10-05T13:11:32.380069+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the DB2 agent plug-in reported a counter of a database without a
value, which can happen when it cannot query that database, the
`db2_counters` agent section failed with
`IndexError: list index out of range`. The "DB2 Counters" services of
all databases on that host were affected.

The services of the other databases are now monitored as usual. For the
affected database each counter without a value is reported as UNKNOWN
with "no value reported".
