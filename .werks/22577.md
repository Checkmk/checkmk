# netstat: ignore lines without addresses

key        | value
---------- | ---
date       | 2026-10-05T13:24:32.619127+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the `netstat` agent section contained a line that is not a network
connection, for example the text "No updates pending for installation"
from another agent plug-in, the "TCP Connection" services crashed with
`TypeError: SplitIP.__init__() missing 1 required positional argument:
'port'`.

Lines whose addresses carry no port are now ignored, and the
connections of the host are evaluated as usual.
