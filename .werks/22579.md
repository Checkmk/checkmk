# job: no crash on negative real time

key        | value
---------- | ---
date       | 2026-10-06T04:41:37.515705+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a job monitored via `mk-job` reported a negative real time, the
`Job` service crashed with `ValueError: Cannot render negative
timespan`. This happens when the system clock is set back while the
job is running, for example by a job that runs `chronyc makestep`.

The service now reports the negative value with a hint to check the
system time, like it already does for a job age in the future. The
exit code and job age are evaluated as before.
