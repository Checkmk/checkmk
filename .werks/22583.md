# Cloud trials: transmit product usage data weekly

key        | value
---------- | ---
date       | 2026-11-04T10:40:54.308502+00:00
version    | 3.0.0b1
class      | feature
edition    | cloud
component  | wato
level      | 1
compatible | yes

Checkmk Cloud sites in trial now transmit their product usage data every
7 days instead of every 30 days. This helps us understand how a trial
site develops during the trial period. When such a site gets a license,
it changes to the 30-day interval after its next transmission.

Sites that already have a planned transmission keep it, and change to
the 7-day interval after it. The content of the data does not change.
