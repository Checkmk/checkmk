# NTNX Host: no crash on missing host data

key        | value
---------- | ---
date       | 2026-10-06T04:58:08.239285+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If Nutanix Prism reported no memory capacity or boot time for a host,
for example while the host is in maintenance mode, the `NTNX Host`
service crashed with `TypeError: float() argument must be a string or
a real number, not 'NoneType'`.

The service now reports the host state and the Acropolis connection
as before, and shows each missing value (number of VMs, memory,
boot time) as UNKNOWN with "got no value".
