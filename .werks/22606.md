# NTNX Remote Tunnel: support new format

key        | value
---------- | ---
date       | 2026-10-06T05:09:34.107290+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

On newer Nutanix Prism versions, the `NTNX Remote Tunnel` service
crashed with `AttributeError: 'bool' object has no attribute 'get'`,
because Prism now reports whether remote support is enabled as a plain
flag.

The service now reads the tunnel state from both the old and the new
response format and reports it as before.
