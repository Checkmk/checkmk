# Fix file upload restriction loosened to 1GB

class      | fix
edition    | community

Previously in werk `17982`, Checkmk applied a file upload restriction of 100MB to 2.5.0 as part of our ongoing security hardening practices. This restriction has forced some users to manually update their sites' Apache *LimitRequestBody* in order to update Checkmk.

As of this werk, this limit has been loosened to 1GB by default. This new limit should mitigate the risk of an update failing due a `413 Request Entity Too Large` error.
