# Update certifi to remove untrusted eMudhra (emSign) root CA certificates

On October 17th, Mozilla received a report that private keys for *emSign root CAs* associated with *8 eMudhra intermediate certificates* had been compromised. As of this werk we have updated our bundled root CA python package `certifi` to the first stable and secure release `2026.10.19`. This release has removed all emSign root certificates that were compromised.

We advise our customers to follow Mozilla's recommended actions around GHSA-6q48-6c7w-9gw2 for further steps.
