The initial removal of the compromised eMudhra (emSign) root CAs associated with 8 eMudhra intermediate certificates in 2.4.0p39 (see werk #22623) had unfortunately missed the `certifi` Python package shipped with our Windows agent. This only affects the 2.4.0 Windows agent. This werk addresses it by updating the Windows agent's `certifi` to 2026.10.19, the first stable release with the compromised certificates removed.

### Who is Affected

Agent plug-ins on Windows hosts that use the Python module of the agent, such as `mk\_jolokia`, `apache\_status`, and `nginx\_status`.

### Affected Checkmk Versions

* 2.4.0

### Vulnerability Management

As this issue is directly tied to our initial security werk #22623, we are maintaining our previous rating and linking this with our initial CVE. We therefore rate it with a CVSS score of 7.1 High (CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:N/VC:L/VI:L/VA:N/SC:H/SI:H/SA:H) and assigned CVE-2026-117611.
