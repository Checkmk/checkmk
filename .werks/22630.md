# cmk-agent-ctl: Pass the registration password in an environment variable

edition    | community

level      | 1
compatible | yes

When a host is registered from a script or a configuration management
tool, the password of the Checkmk user had to be passed with the option
`--password`. While the command ran, the password was visible in the
process list to every user of the host.

The agent controller now also reads the password from the environment
variable `CMK_AGENT_CTL_REGISTRATION_PASSWORD`. This applies to the
modes `register`, `register-new` and `proxy-register`, on Linux and on
Windows.

The option `--password` takes precedence over the variable. If neither
is given, the controller asks for the password as before. Like
`--password`, the variable cannot be combined with `--ott`.
