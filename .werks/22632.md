# Show download errors in install commands

key        | value
---------- | ---
date       | 2026-10-06T07:59:37.973057+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | agents
level      | 1
compatible | yes

If the agent download from a generated Linux, Solaris or AIX install
command failed, the terminal only showed `curl: (22) The requested URL
returned error: 404`. The explanation sent by Checkmk, for example
"No baked agent for this host available", was discarded.

The install commands now print the error details returned by Checkmk
and still skip the installation step. They keep working with older curl
versions.

The Solaris install command also referred to a package file name that
did not match the downloaded file. This is fixed as well.
