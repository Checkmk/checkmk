# Analyze configuration: Warn about local files overriding shipped style sheets and scripts

key        | value
---------- | ---
date       | 2026-10-09T06:37:05.359431+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Files below `local/share/check_mk/web/htdocs` are served instead of the
shipped files with the same path. Copies of shipped files, for example of a
whole theme to replace a single logo, are not updated together with Checkmk.
After an update, the outdated style sheets of the older version were still
delivered, which could break the layout of the user interface, e.g. the search
of the main menu covering the navigation bar.

*Analyze configuration* now warns about local style sheets and scripts that
override shipped files. Other local files, e.g. replaced logos, are not
reported. Remove the copies you do not need. To customize the look of the user
interface, use a theme of your own instead of overriding the shipped themes.
