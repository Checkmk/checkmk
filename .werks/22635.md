# Global search: list the folder filters next to host and service

key        | value
---------- | ---

When you type `/` in the global search, the overview of search filters
now shows the folder filters `hf:` and `sf:` right below the host and
service filters instead of at the end of their group. The remaining
host and service filters follow in alphabetical order:

* Host, Host folder, Host group, Host label, Host tag, Address, Alias
* Service, Service folder, Service group, Service label, Service state
