# docker_container_status_uptime: Don't crash on container start time in the future

key        | value
---------- | ---
date       | 2026-10-14T04:56:26.590488+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the clock of a Docker node was ahead of the clock of the Checkmk
server, a freshly started container reported a start time in the
future. Its `Uptime` service then crashed with
`ValueError: Cannot render negative timespan`.

The service now goes to UNKNOWN and states how far the container start
time lies in the future, pointing to the clock synchronization between
the Docker node and the Checkmk server.
