# citrix_state_hosting_server: Don't crash on machines without hosting server

key        | value
---------- | ---
date       | 2026-10-14T05:50:31.674161+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The `Citrix Hosting Server` service was discovered on every machine that
reported a Citrix controller, even if the machine reported no hosting
server, for example a machine with the power state `Unmanaged`. On such
machines the service crashed with `KeyError: 'hosting_server'`.

The service is now only discovered on machines that report a hosting
server. Already discovered services on machines without a hosting server
no longer crash; they are reported as vanished and can be removed by
running a service discovery.
