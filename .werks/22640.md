# hyperv_vm_integration: Don't crash on special cases without a state

key        | value
---------- | ---
date       | 2026-10-14T05:50:36.135096+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

In the rule *Hyper-V VM integration services*, a special case for a
specific service could be saved without setting *State if not default*.
Such a rule made the `Hyper-V VM integration services` service crash with
`KeyError: 'state_if_not_default'`. Rules converted from the old format,
which had no such setting, were affected as well.

Special cases without *State if not default* now use the state configured
for the whole rule.
