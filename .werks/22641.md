# synology_raid: Don't crash on volumes that are no longer reported

key        | value
---------- | ---
date       | 2026-10-14T06:45:07.034086+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If a Synology NAS stopped reporting a volume or storage pool that had
been discovered before (for example after the volume was deleted), its
`Raid <name>` service crashed with `KeyError`.

The service now reports that the item is no longer found, and the
discovery check lists it as vanished, so it can be removed by
re-running the service discovery.
