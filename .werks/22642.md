# hr_cpu: Don't crash on empty processor load

key        | value
---------- | ---
date       | 2026-10-14T06:45:16.729782+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a device reported an empty processor load in the HOST-RESOURCES-MIB
(`hrProcessorLoad`) for one of its processors, the `CPU utilization`
service crashed with
`ValueError: invalid literal for int() with base 10: ''`.

The service now goes to UNKNOWN and names the processor whose load could
not be read, together with the value received. The utilization of the
remaining processors is still reported.
