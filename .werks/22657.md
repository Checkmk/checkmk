# NagVis: Fix XSS in hover menus, labels and context menus

NagVis did not escape check output and object names before displaying them
in hover menus, labels and context menus. A user who can influence the
output of a service shown on a NagVis map could inject JavaScript that ran
in the browser of anyone viewing the map, for example by hovering over the
object.

We have updated NagVis to 1.10.7, which escapes this content. As a side
effect, HTML in check output, notes or object names is now displayed as
plain text instead of being rendered.

This issue was found during internal review.

### Who is Affected

All editions that use NagVis maps.

### Affected Checkmk Versions

* 2.5.0
* 2.4.0
* 2.3.0 (EOL)

### Vulnerability Management

We have rated the issue with a CVSS Score of 7.3 High
(`CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:A/VC:H/VI:H/VA:H/SC:N/SI:L/SA:N`) and
assigned `CVE-2026-103318`.
