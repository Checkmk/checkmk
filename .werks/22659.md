# winperf_msx_queues: report missing offset of enforced services

key        | value
---------- | ---
date       | 2026-10-15T06:05:58.810583+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

An enforced *MS Exchange Message Queues* service crashed with
`KeyError: 'offset'` if its rule did not set the parameter *Offset*. For
discovered services this offset is determined by the discovery rule, but an
enforced service only knows the values of its own rule.

The service now goes to UNKNOWN with the summary
`Queue offset is not configured (set 'Offset' in the enforced service rule)`.
Set *Offset* in the enforced service rule to the counter offset of the
queue you want to monitor.
