# Check HTML form submit: Fix form selection and submission

The active check _Check HTML form submit_ had several bugs when selecting
and submitting a form:

- With exactly one form on the page and _Name of the form to populate and
  submit_ configured, the check went `CRIT` although the name matched, and
  submitted the form if the name did not match.
- An absolute URL as form `action` was appended to the page's directory,
  and an empty `action` made the check crash.
- An absolute path as form `action`, e.g. `/login`, referred to the
  monitored host instead of the host the page was loaded from after
  redirects.
- Input fields like `<input name="token" value>` were submitted with the
  value `None` instead of an empty value.
- A `method` or `name` attribute without a value in the `form` tag could
  make the check crash.
