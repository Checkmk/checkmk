# Fix wrong REST API value of LDAP host/service visibility sync

key        | value
---------- | ---

version    | 2.4.0p39
class      | fix

component  | rest-api
level      | 1
compatible | yes

Previously, the REST API reported a wrong value for LDAP connections that use
the sync plug-in _Groups to custom user attributes_ with the attribute
_Visibility of hosts/services_. For groups configured with `show_all`, the
REST API returned `show_for_user_contacts_only`.

This has been fixed.
