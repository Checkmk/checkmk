# REST API: Fix crash on incomplete Event Console condition in notification rules

---------- | ---
date       | 2026-11-12T17:18:50.961238+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Creating or editing a notification rule through the REST API failed with an internal server error (`KeyError`) if the `event_console_alerts` condition used the match type `match_only_event_console_alerts` and its `values` did not contain all of `match_rule_ids`, `match_syslog_priority`, `match_syslog_facility` and `match_event_comment`.

Fields that are left out are now treated as disabled, as for the other conditions.
