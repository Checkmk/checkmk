# AWS/EC2 Status Check hid short failures

The service _AWS/EC2 Status Check_ reports whether the system and the
instance status checks of an EC2 instance failed. AWS checks each
instance once per minute. The special agent asked CloudWatch for the
average of these results over ten minutes, but the service reported a
failure only if all checks in that period failed.

As a result, the service stayed OK when a status check failed for only
a few minutes. A failure that lasted reported CRIT only after it had
lasted for the whole ten minutes.

The service now reports CRIT if any status check in the period failed.
You may now see CRIT states for short failures that the service did not
show before. You do not need to change your configuration.
