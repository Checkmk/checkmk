# lvm_vgs: ignore foreign lines in agent output

key        | value
---------- | ---
date       | 2026-10-15T06:57:36.139124+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If another program wrote a line to the output of the Checkmk agent while
the `lvm_vgs` section was produced (for example a log message of a CI
runner), the `LVM VG` services crashed with
`ValueError: not enough values to unpack (expected 7, got 1)`.

Lines that do not have the format of a volume group are now ignored, and
the volume groups are monitored as before.
