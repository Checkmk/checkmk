# Cisco Meraki: recover from corrupted cache files

---------- | ---
date       | 2026-10-09T07:20:32.328039+00:00
version    | 2.5.0p16
class      | fix
edition    | community
component  | checks

compatible | yes

Previously, the Cisco Meraki special agent crashed on every run if one of its
cache files was corrupted, for example with:

_JSONDecodeError: Extra data: line 1 column 6586 (char 6585)_

The agent kept crashing until someone deleted the broken file by hand. Now the
agent throws away a corrupted cache entry, fetches fresh data from the Meraki
API and overwrites the file, so it recovers on its own. When you run the special
agent manually, a warning is now emitted when the cache is invalid.

Most corrupted cache files were due to two agents for the same host overlapping
causing a race condition. [Werk #22278](https://checkmk.com/werk/22278)
addresses that issue.
