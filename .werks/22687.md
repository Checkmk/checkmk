# Bazel: recover from corrupted cache files

key        | value
---------- | ---
date       | 2026-10-09T10:50:35.608046+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Previously, the Bazel cache special agent crashed on every run if its version
cache file was corrupted, typically with a _ValidationError_.

The agent kept crashing until someone deleted the broken file by hand. Now the
agent throws away a corrupted version cache, fetches the version information
again and overwrites the file, so it recovers on its own. When you run the
special agent manually, a warning is now emitted when the cache is invalid.

Most corrupted cache files were due to two agents for the same host overlapping
causing a race condition. [Werk #22278](https://checkmk.com/werk/22278)
addresses that issue.
