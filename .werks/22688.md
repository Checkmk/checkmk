# Global search: keep special characters on Enter

key        | value
---------- | ---
date       | 2026-10-14T10:51:08.781375+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

When you pressed Enter in the global search, a query containing `&`,
`#` or `+` was cut off or changed before the search ran. For example,
`h:a&b` only searched for `h:a`, `foo#bar` only for `foo`, and the
regular expression `h:web+` turned into `h:web`. The entry this added
under _Recently viewed_ had the same problem.

The global search now passes the query exactly as you typed it.
_Recently viewed_ entries that were stored before this fix keep the
broken search, even if you run the same search again. Use _Clear all_
next to _Recently viewed_ to remove them.
