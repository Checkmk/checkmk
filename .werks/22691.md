# innovaphone: unknown PRI L2 states/modes

---------- | ---
date       | 2026-10-20T13:33:40.640530+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an innovaphone PBX reported a port state other than Down or UP, or a
port mode other than TE or NT, the `Port L2` service of that port
crashed with `KeyError`.

The service now names the value the device reported. An unrecognized
state is UNKNOWN; an unrecognized mode is CRIT only if it differs from
the mode found during discovery, as for any other mode change.
