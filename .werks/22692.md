# innovaphone: do not crash on channels with a total of 0

key        | value
---------- | ---
date       | 2026-10-20T13:35:15.780855+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an innovaphone PBX reported a channel that is up with a total of 0,
its `Channel` service crashed with `ZeroDivisionError`.

The service is now OK and reports that no channels are available. No
usage metric is reported, as usage cannot be derived from 0 channels.
