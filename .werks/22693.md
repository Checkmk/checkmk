# Global search: no blank page on Enter with empty query

key        | value
---------- | ---
date       | 2026-10-23T13:08:06.293528+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Previously, pressing Enter in the global search with a query of only
spaces, or just a `/`, took you to an empty white page. Enter now does
nothing for such a query, and no blank entry is added to your search
history.
