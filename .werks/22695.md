# Bazel: show cache age for version check

key        | value
---------- | ---
date       | 2026-11-09T15:58:21.862970+00:00
version    | 3.0.0b1
class      | feature
edition    | community
component  | checks
level      | 1
compatible | yes

The Bazel Remote Cache special agent caches the version information it fetches
from GitHub. Until now, the service "Bazel Cache Version" gave no hint that its
data could be cached, so after upgrading Bazel Remote Cache it could keep
showing the old version without any indication of why.

The special agent now embeds the cache timestamp and interval into the
`bazel_cache_version` section header. Checkmk picks this up automatically, so
the service now shows cache age information ("Cache generated X ago", cache
interval, elapsed cache lifespan) in the GUI.

There is nothing for the user to do; this information is shown automatically
once the site is updated.
