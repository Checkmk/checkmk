# oracle_performance: report non-integer file I/O counters

key        | value
---------- | ---
date       | 2026-10-15T07:12:47.754360+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The services `ORA <SID> Performance IO Stats Bytes` and
`ORA <SID> Performance IO Stats Requests` crashed with
`TypeError: unsupported operand type(s) for -: 'NoneType' and 'int'` if the
Oracle agent plug-in reported a file I/O statistics counter that is not an
integer.

The affected counter is now reported as UNKNOWN, for example
`Temp File Large Write: Oracle reported no integer value, counter skipped`,
and the other counters are monitored as before.
