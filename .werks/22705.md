# REST API: Acknowledgements of hosts with the same name on several sites

key        | value
---------- | ---
date       | 2026-11-05T11:21:47.285400+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

When two sites of a distributed setup monitor hosts of the same name, acknowledging problems through the REST API went wrong:

* Acknowledging such a host, by name or by query, failed with an internal server error and acknowledged nothing.
* Acknowledging services of such a host, by name or by query, reached only the first site that knows the host name, so a service on another site stayed unacknowledged.

Each acknowledgement is now sent to the site of each host or service it matches.
