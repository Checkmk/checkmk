# ad_replication: Services missing after a Windows update added columns

compatible | yes

After Windows updates such as KB5131089 and KB5131090,
`repadmin /showrepl /csv` appends four columns to each line: the FQDNs of
the destination and source domain controller and the master naming
contexts of both. Checkmk dropped every line with more than the eleven
columns it expected. Service discovery then found no AD replication
services, and existing services went UNKNOWN because their item was
missing from the agent output.

Checkmk now ignores the additional columns. Run a service discovery on the
affected hosts to add the missing services.
