# REST API: Service downtimes of hosts with the same name on several sites

key        | value
---------- | ---
date       | 2026-11-09T12:45:27.141176+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

When two sites of a distributed setup monitor hosts of the same name, scheduling a downtime for services of such a host by name through the REST API (`downtime_type: service`) went to the local site only. The services on the other site got no downtime.

The downtime is now scheduled on the site of each service it matches.
