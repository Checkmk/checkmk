# EC: fix start time of expectation events

For a rule with _Expect regular messages_ which got some, but not enough
messages within its interval, the Event Console opened an event saying
"Expected message arrived only 1 out of 2 times since ...", followed by the
time of the last message instead of the start of the interval. For example,
with an hourly interval starting at 10:00 and a single message at 10:55, the
event said "since 10:55", suggesting one message within 5 minutes instead of
one within the whole hour.

The event now shows the start of the interval.
