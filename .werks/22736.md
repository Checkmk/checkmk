# Reports: PDF files with graphs twice as large since 2.4.0

key        | value
---------- | ---
date       | 2026-11-17T06:43:03+00:00
version    | 2.5.0p22
class      | fix
edition    | pro
component  | reporting
level      | 1
compatible | yes

Since Checkmk 2.4.0, PDF reports with graphs were about twice as large as
in 2.3.0. This affected graph elements as well as graphs in view elements.

Up to 2.3.0, Livestatus limited every graph curve to 400 data points,
which hid that reports requested two data points per 0.5 mm of graph
width. Since 2.4.0, Livestatus no longer applies this limit, so reports
received and drew twice as many data points as before.

Reports now request fewer data points per graph, at most 400 per curve.
This roughly halves the size of affected reports. Graphs in the GUI, in
dashboards and in notifications are unchanged.
