# db2_connections: don't crash if the port is missing

key        | value
---------- | ---
date       | 2026-10-15T09:06:16.560487+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The `DB2 Connections` service crashed with `KeyError: 'port'` if the
agent plug-in reported the number of connections for a database but not
its port.

The service now checks the connections as usual and only shows the port
when the agent reports it.
