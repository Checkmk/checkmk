# postgres_bloat: report agent output without column header

key        | value
---------- | ---
date       | 2026-10-15T09:14:02.617898+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

All `PostgreSQL Bloat` services of a host crashed with `KeyError: 'tbloat'`
if the `postgres_bloat` section of the agent output did not start with its
column header line. The agent plug-in prints this header only together with
the bloat data of the first database, so it can be missing if no data is
returned for that database.

The services now go to UNKNOWN with the summary
`Cannot evaluate bloat data: column 'tbloat' is missing in the agent output`.
