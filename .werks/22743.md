# veeam_client: don't crash on a negative backup age

key        | value
---------- | ---
date       | 2026-10-15T09:18:06.855023+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The services of the Veeam clients (`VEEAM Client`) crashed with
`ValueError: Cannot render negative timespan` if the last backup appeared
to have finished in the future. This happens when the clocks of the Veeam
host and the Checkmk server differ slightly.

Such a service now goes UNKNOWN with
`Last backup: end time is in the future`.
