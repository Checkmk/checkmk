# fireeye_bypass: don't crash on an empty SNMP reply

key        | value
---------- | ---
date       | 2026-10-15T09:20:34.811818+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The `Bypass Mail Rate` service of FireEye appliances crashed with
`IndexError: list index out of range` if the device returned no value for
the bypass e-mail counter.

An empty reply is now handled like missing monitoring data instead of
crashing the check.
