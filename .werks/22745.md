# Test notification resent on reload

With "Trigger notification for a specific method" enabled, the "Test
notifications" page sent the notification again each time the result page
was loaded again: on reload, on going back and forth in the browser history,
and on clicking the page title.

The notification is now only sent when you click the "Test notifications"
button.
