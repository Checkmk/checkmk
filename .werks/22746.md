# Bulk email: summary only for many events

key        | value
---------- | ---
date       | 2026-11-24T14:24:14.295164+00:00
class      | fix
edition    | community
component  | notifications
level      | 1
compatible | yes

HTML bulk emails started with an "Event summary" table even when the
bulk contained only one event. The table then repeated the single event
that followed directly below it.

A bulk email with only one event now looks like a regular notification
email. The "Event summary" is shown only when the email contains several
events.

In bulk emails with several events, a divider line and the heading
"Event history" now separate the summary from the details of the
individual events. The heading states the order of the events, which
follows the rule's setting "Notification sort order for bulk
notifications".
