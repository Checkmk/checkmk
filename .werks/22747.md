# Notifications fail when the automation helper is disabled

key        | value
---------- | ---
date       | 2026-11-26T07:44:26.495006+00:00
class      | fix
edition    | pro
component  | notifications
level      | 1
compatible | yes

With the automation helper disabled via `omd config set AUTOMATION_HELPER off`,
notifications handed to the notification spooler were not delivered. The spooler
kept deferring them with the message "The automation-helper service is required
for the notification spooler".

Notifications are now delivered without the automation helper when it is disabled.
If the automation helper is enabled but not running, notifications still fail as
before, so please make sure all site services are started.
