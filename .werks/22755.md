# Silverpeak: alarms without alarm details

key        | value
---------- | ---
date       | 2026-10-16T05:11:02.304988+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If a Silver Peak appliance reported a number of active alarms via SNMP
but returned no entries in its alarm table, the `Alarms` service
crashed with `KeyError: 'alarms'`.

The service now shows the reported number of active alarms and goes
to UNKNOWN, stating that the device delivered no alarm details.
