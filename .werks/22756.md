# MySQL Connections: incomplete agent data

compatible | yes

If the agent output of a MySQL or MariaDB instance lacked the server
variable `max_connections`, for example because querying the server
variables failed in one check cycle, the `MySQL Connections` service
crashed with `KeyError: 'max_connections'`.

The service now goes to UNKNOWN and names the missing values, for
example `Connection information is missing: max_connections`. This
message replaces the previous, unspecific `Connection information is
missing`.
