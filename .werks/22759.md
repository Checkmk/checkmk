# TP-Link POE Power: empty SNMP answer

key        | value
---------- | ---

version    | 2.5.0p17
class      | fix
edition    | community
component  | checks
level      | 1

If a TP-Link switch answered the query for its total PoE power
consumption with an empty table, the `POE Power` service crashed with
`IndexError: list index out of range`.

The service now goes to UNKNOWN with `Item not found in monitoring
data` instead.
