# Interface groups: no interfaces reported

If an interface group was configured (for example for the Linux
interfaces via the ruleset "Network interface and switch port
discovery") and the agent then reported no interfaces at all, the
interface group service crashed with `IndexError: list index out of
range`.

The service now goes to UNKNOWN with `Item not found in monitoring
data`, as an ungrouped interface service does in the same situation.
