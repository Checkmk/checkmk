# FAST LTA capacity: empty used value

key        | value
---------- | ---
date       | 2026-10-16T06:19:36.616319+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If a FAST LTA system reported its total Silent Cubes capacity via SNMP
but an empty value for the used capacity, the service
`Fast LTA SC Capacity Total` crashed with `ValueError: invalid literal
for int() with base 10: ''`.

The service now goes to UNKNOWN and shows the values it received, for
example `Cannot parse capacity: got total '200021140045824', used ''
(expected integers)`.
