# HR MIB processes: empty service name

If a rule of the ruleset "Process discovery (HOST-RESOURCES-MIB)"
produced an empty service name for a matching process, the service
discovery of the host crashed with `TypeError: 'item' must be a non
empty string or ommited entirely, got ''`. This happens, for example,
if the service name consists only of `%s` or `%1` and the corresponding
group of the regular expression matches an empty string.

The discovery now continues. A process match that would result in an
empty service name is skipped, so no service is created for it. Adjust
the service name in the rule if you want such processes to be
monitored.
