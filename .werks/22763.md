# DB2 Connections: DB2 error in output

If DB2 answered the agent's connection query with an error message, for
example `SQL20249N The statement was not processed because the package
named ... needs to be explicitly rebound.`, the agent output contained
that message instead of the number of connections, and the
`DB2 Connections` service crashed with `ValueError: dictionary update
sequence element #1 has length 11; 2 is required`.

The service now goes to UNKNOWN and shows the unexpected output, so the
DB2 error message is visible in Checkmk.
