# Number of threads: maximum reported as 0

key        | value
---------- | ---
date       | 2026-10-16T07:48:43.902944+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the agent reported 0 as the maximum number of threads of a host, the
service `Number of threads` crashed with `ZeroDivisionError: float
division by zero`.

The service now checks the number of threads as usual and omits the
thread usage in percent, which cannot be computed without a valid
maximum. This is the same output as for hosts whose agent reports no
maximum at all.
