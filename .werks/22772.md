# HP MSA: component with empty location

key        | value
---------- | ---
date       | 2026-10-16T08:07:56.991845+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If an HP MSA storage system reported a component (for example a power
supply) with an empty location, the service discovery of the host
crashed with `TypeError: 'item' must be a non empty string or ommited
entirely, got ''`.

Such a component is now named after its ID, as components without any
location already are, so it is discovered and monitored like the
others.
