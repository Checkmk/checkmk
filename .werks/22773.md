# ORA Long Active Sessions: extra fields

If the agent reported an active Oracle session with more fields than
expected, for example because the operating system user name contained
non-ASCII characters and was split, the service
`ORA <SID> Long Active Sessions` crashed with `ValueError: too many
values to unpack (expected 9)`.

The session is now counted as usual. If it is the session shown in the
service details, the details state that its information could not be
parsed and how many fields were received.
