# Memory (Linux): missing memory values

key        | value
---------- | ---
date       | 2026-10-16T08:39:21.584547+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the `Memory` service of a Linux host received a memory section
without the Linux specific values, for example only total and free
memory and swap, the service crashed with `KeyError: 'Cached'`.

The service now goes to UNKNOWN and names the missing values, for
example `Memory information is missing: Buffers, Cached, Dirty`.
