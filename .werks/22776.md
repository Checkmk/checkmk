# keepalived: unparsable virtual address

key        | value
---------- | ---
date       | 2026-10-16T09:02:00.986250+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If keepalived reported a virtual IP address via SNMP that is neither a
valid IPv4 nor IPv6 address, all `VRRP Instance` services of the host
crashed with `ValueError: ... does not appear to be an IPv4 or IPv6
address`.

The services now report the state of their VRRP instance as usual. The
unparsable address is shown in the summary together with the raw value
received, for example `IP Address: cannot parse 0x2342 (expected 4 or
16 bytes)`.
