# Huawei switches: detect OID tree 56813

key        | value
---------- | ---
date       | 2026-10-16T12:06:28.381815+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

Newer firmware of Huawei switches, for example S7706, reports its
`sysObjectID` and its private MIBs under the enterprise number 56813
instead of 2011. The OID tree below the enterprise number is the same.

Checkmk did not detect these devices, so no "CPU utilization" and
"Memory" services were discovered on them.

These checks now also support the enterprise number 56813. Run a service
discovery on the affected hosts to get the services.
