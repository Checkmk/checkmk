# OMD broker: survive HTML error pages

key        | value
---------- | ---
date       | 2026-10-19T06:40:49.809950+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The broker agent section reports one line of data per site. If the
message broker management interface of one site answered with an
HTML error page (e.g. "404 Not Found") instead of data, the section
could not be parsed at all and the crash report showed
`JSONDecodeError: Expecting value`. All broker services of the host
were affected, including the ones of healthy sites.

Lines that are not valid broker data are now ignored. The sites that
delivered data are monitored as before. Services of the site that
returned the error page report that their item was not found.
