# db2_bp_hitratios: show DB2 errors

key        | value
---------- | ---
date       | 2026-10-19T06:55:50.218437+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If DB2 answered the buffer pool query of a database with an error
message instead of the hit ratio table, e.g. `SQL20249N The statement
was not processed because the package named ... needs to be
explicitly rebound.`, the service discovery created a bogus
`DB2 BP-Hitratios` service from the words of that message, and the
check crashed with `KeyError` or `ValueError`.

No services are discovered from such an error message any more.
Existing `DB2 BP-Hitratios` services of the affected database now go
UNKNOWN and show the DB2 error message.
