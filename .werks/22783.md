# nfsiostat: support one line per mount

key        | value
---------- | ---
date       | 2026-10-19T07:18:42.451710+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the `nfsiostat` agent section of a host contained the statistics
of each NFS mount on a separate line instead of the single line the
shipped agent plugin produces, the NFS IO services of that host could
not be checked, and the crash report showed `ValueError: too many
values to unpack (expected 1)`.

The section is now parsed regardless of how its content is split
into lines, and all mounts are monitored.
