# win_os: survive duplicate OS rows

key        | value
---------- | ---
date       | 2026-10-19T07:23:59.731624+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

If the Windows agent reported the operating system information of the
`win_os` inventory section more than once, for example because the
inventory plugin was installed twice, the HW/SW inventory of the host
contained no operating system data, and the crash report showed
`ValueError: too many values to unpack (expected 1)`.

The operating system is now inventorized from the first reported
row.
