# ceph_status: handle empty agent section

key        | value
---------- | ---
date       | 2026-10-19T10:12:54.862651+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Ceph agent plugin sent the `ceph_status` section without any
content, for example because the `ceph status` command produced no
output, the Ceph status services could not be checked, and the crash
report showed `JSONDecodeError: Expecting value`.

An empty section is now treated like missing data: the affected
services report that no monitoring data is available instead of
crashing.
