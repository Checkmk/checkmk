# win_wmi_software: read dotted dates

key        | value
---------- | ---
date       | 2026-10-19T10:19:07.064248+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | inv
level      | 1
compatible | yes

If a Windows host reported the install date of an installed package
in a dotted format such as `2021.6.1` instead of `20210601`, the
software inventory of the host failed, and the crash report showed
`ValueError: time data '2021.6.1' does not match format '%Y%m%d'`.

Dotted install dates are now read as year, month and day. All
packages of the host are inventorized again.
