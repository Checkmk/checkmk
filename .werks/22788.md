# emcvnx_info: report naviseccli errors

key        | value
---------- | ---
date       | 2026-10-19T10:25:02.123231+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If the EMC VNX command line tool `naviseccli` printed only an error
message, for example `Unknown exception while executing cli command`,
instead of the system information, the `EMC VNX Info` service
crashed with `IndexError: list index out of range`.

Such messages are now reported like the other `naviseccli` errors:
the `EMC VNX Info` service goes CRIT and shows the error message.
