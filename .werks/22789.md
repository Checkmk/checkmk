# EC: host limits delete the right events

Every event carries two host names: its own one, taken from its message after
any host name translation and rewriting, and the name of the monitored host that
Checkmk matched it to, if any. The host limit of the Event Console counts the
events of each combination of these names separately. With the action _Delete
oldest event, create new event_, however, the Event Console deleted the oldest
event with the same own host name, even if that event was counted separately,
e.g. because it arrived before the host was added to the monitoring. The host
then kept more open events than its limit allowed.

The Event Console now deletes the oldest event counted towards the reached
limit.
