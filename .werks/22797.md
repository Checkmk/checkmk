# Unit lookup: handle missing metric

key        | value
---------- | ---
date       | 2026-10-19T10:53:49.548036+00:00
version    | 2.4.0p38
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

When the unit of a selected metric was looked up for a form that lets
you choose a metric (for example in graph or dashboard settings), a
request without a metric produced a crash report with
`KeyError: 'metric'`.

Such a request is now handled like an empty metric selection, and the
default unit is preselected.
