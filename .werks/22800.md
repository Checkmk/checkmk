# Stop polling pending changes in background browser tabs

key        | value
---------- | ---
date       | 2026-11-17T15:56:15.371126+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Previously, every open Checkmk tab asked the server for the number of
pending changes every few seconds, even while the tab was in the
background. With many tabs open, this added up to a steady stream of
requests for a counter nobody was looking at.

Background tabs now skip these requests. As soon as you switch back to a
tab, the pending changes count is refreshed.
