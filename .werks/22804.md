# ip_addresses: skip invalid address rows

key        | value
---------- | ---
date       | 2026-10-19T11:12:46.991974+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

If an SNMP device reported an IP address entry that is not a valid
IPv4 address with netmask (seen on KEMP load balancers), the HW/SW
inventory of the device lost all its IP addresses, and the crash
report showed `ValueError: ... does not appear to be an IPv4 or IPv6
interface`.

Such an entry is now skipped and all other IP addresses of the
device are inventorized.
