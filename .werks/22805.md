# Check certificates: Resolve macros in proxy server name

key        | value
---------- | ---
date       | 2026-11-24T06:42:49.409296+00:00
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

The _Check certificates_ check now resolves host macros such as
`$HOSTNAME$` or `$HOSTADDRESS$` in the server name of an explicitly
configured HTTP proxy.

Until now, the macro was passed to the check literally, for example as
`--proxy-url http://$HOSTADDRESS$`, so the check could not reach the
proxy.
