# Graphs: accept empty title format

key        | value
---------- | ---
date       | 2026-10-19T11:28:48.086370+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

If the graph options of a view or dashboard element had no title
element selected (stored as an empty title format), the graph could
not be shown and the crash report showed `ValidationError: 1
validation error for GraphRenderOptions title_format`.

An empty title format selection is now accepted, and the graph is
shown without the title elements.
