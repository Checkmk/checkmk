# Dashboards: Save statistics elements of cloned dashboards

---------- | ---

version    | 2.4.0p38
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

Saving the element "Host statistics" or "Service statistics" in the
element editor failed with a crash report showing `KeyError: 'size'`.
This affected copies of the built-in "Main dashboard" (Checkmk Raw) or
"Problem dashboard" (commercial editions) that were created before
Checkmk 2.2.0p21 or 2.3.0p7. Up to then, the built-in dashboard defined
these elements without a size.
[Werk #16314](https://checkmk.com/werk/16314) corrected only the
built-in dashboard, so existing copies kept crashing. The dashboard
itself always displayed them correctly.

The editor now uses the default size of these elements, which is the
size they are displayed with. When you save, the size is stored in the
dashboard, so the problem does not occur again for that element. No
action is required.
