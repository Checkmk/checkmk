# Forms: no crash on file upload fields

key        | value
---------- | ---
date       | 2026-10-19T12:03:17.221935+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Saving or validating settings that contain a file upload field in a
form of the older type (for example certificate or key uploads in
notification parameters or in the agent updater rule) could fail with
a crash report showing `TypeError: Only str and unicode values are
allowed`. This also affected the REST API endpoints for configuration
entities.

The form no longer crashes. Uploading a file is still not possible
in these forms, though: if an upload field is selected, required or
optional, the form now reports that file uploads are not supported
here. Where the field offers it, paste the content instead.
