# Backup: skip unreadable backup info

key        | value
---------- | ---
date       | 2026-10-19T12:43:07.703561+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | core
level      | 1
compatible | yes

If a backup directory of a backup target contained an empty or
unreadable `mkbackup.info` file, for example after an interrupted
backup, the pages listing the backups of that target failed with a
crash report showing `JSONDecodeError: Expecting value`.

Such a backup is now skipped, like a backup directory without an
info file, and all other backups of the target are listed.
