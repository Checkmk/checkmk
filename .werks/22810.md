# Predictive levels: recreate broken files

key        | value
---------- | ---
date       | 2026-10-19T13:03:41.039004+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | core
level      | 1
compatible | yes

If a stored prediction file of a check with predictive levels was
empty or damaged, for example after the disk ran full, every check of
the host using predictive levels crashed on every check cycle with
`ValidationError: 1 validation error for PredictionInfo`, until the
file was removed by hand.

A damaged prediction file is now ignored and recreated, and the
prediction is computed again, as for a new prediction.
