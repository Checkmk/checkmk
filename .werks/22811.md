# Views: perf data with unbalanced quotes

key        | value
---------- | ---
date       | 2026-10-20T04:50:29.087301+00:00
version    | 2.4.0p39
class      | fix
edition    | cre
component  | multisite
level      | 1
compatible | yes

If the performance data of a service contained an unbalanced quote,
for example a metric name with a single apostrophe, views showing the
performance data of that service failed with a crash report showing
`ValueError: No closing quotation`.

Such performance data is now read without the quote handling, so the
view is shown and all readable metrics are displayed.
