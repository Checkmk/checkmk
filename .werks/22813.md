# Quick Setup: Sites with keyword IDs

key        | value
---------- | ---

version    | 2.4.0p39
class      | fix
edition    | cre
component  | wato
level      | 1
compatible | yes

If a site ID was a Python keyword, for example `global`, opening a
Quick Setup with a site selection failed with
`ValueError: 'global' is not a valid, non-reserved Python identifier`.

Such sites can now be selected in the Quick Setup like any other site.
