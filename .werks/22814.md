# Dashboards: Open despite unknown widgets

key        | value
---------- | ---
date       | 2026-10-21T05:57:37.582055+00:00
version    | 2.5.0p18
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Opening a dashboard failed with an error if it contained a widget of a
type that this site does not provide, for example one added by an
extension package that has since been removed. The error named the
widget type, such as `KeyError: 'notification_analysis'`.

The dashboard now opens without that widget. The REST API returns such
a widget with the content type `not_supported`.
