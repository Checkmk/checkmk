# Activation: Broker connection errors

key        | value
---------- | ---
date       | 2026-10-21T10:10:09.013920+00:00
version    | 2.5.0p17
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

If the connection to the local message broker failed while the
piggyback hub configuration was distributed, for example because the
broker presented a certificate the site does not trust, activating
changes ended in a crash report.

The activation of the sites now continues, and a warning in the web log
says that the piggyback hub configuration was not distributed and names
the failing broker connection.
