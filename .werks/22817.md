# Password fields after a session change

Password fields keep an already entered password in the form as a value
that is encrypted with a secret of the current session. If such a form
was submitted after the session changed, for example because it expired
or you logged in again in another tab, the page crashed with
`InvalidTag`.

You now get an error message asking you to enter the password again.
