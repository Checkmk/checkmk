# Password fields after a session change

Password, file upload and SSH key pair fields keep an already entered
value in the form encrypted with a secret of the current session. If
such a form was submitted after the session changed, for example because
it expired or you logged in again in another tab, the page crashed with
`InvalidTag`.

You now get an error message asking you to enter the password or upload
the file again, or to open the page again for an SSH key pair.
