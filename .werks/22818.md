# Relay: Empty fetch results

key        | value
---------- | ---
date       | 2026-10-22T06:42:46.590763+00:00
version    | 3.0.0b1
class      | fix
edition    | ultimate
component  | relay
level      | 1
compatible | yes

If the fetcher process on the relay ended without returning a result,
the relay finished the fetch task with an empty result. Fetching the
data of the host then failed with a crash report (`JSONDecodeError`)
and the host went to UNKNOWN.

This is now reported as a regular fetch error of the host: "The
fetcher on the relay ended without returning a result. See the relay
log for details." Like other connection problems, the host now gets
the state configured for connection errors (CRIT by default) instead of
UNKNOWN.
