# Views snap-in: Show views only, no dashboards

key        | value

edition    | community

The Views snap-in in the sidebar showed the complete Monitor menu, so
dashboards appeared in it next to the views. That doubled up with the
Dashboards snap-in, which is where dashboards belong.

The Views snap-in now leaves dashboards out. Add the Dashboards snap-in
to your sidebar if you want links to them there. The Monitor menu
itself is unchanged and still lists both.
