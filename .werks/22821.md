# Mobile GUI: Fix XSS via jQuery Mobile hash navigation

---------- | ---
date       | 2026-11-02T05:49:05.104336+00:00
version    | 3.0.0b1
class      | security
edition    | community

The mobile GUI (`mobile.py`) was vulnerable to cross-site scripting through
its jQuery Mobile dependency (GHSA-fj93-7wm4-8x2g). jQuery Mobile loaded the
URL given in the location hash via AJAX and inserted the response into the
page. An attacker could craft a link to the mobile GUI whose hash pointed to
a Checkmk page that reflects user input. A logged-in user who opened such a
link executed the attacker's JavaScript in the context of their session.

Checkmk already tried to disable this jQuery Mobile feature, but applied the
setting only after jQuery Mobile had initialized, so it had no effect. The
setting is now applied before jQuery Mobile initializes. The mobile GUI no
longer loads pages from the location hash.

This issue was found during internal review.

### Who is Affected

All editions. Only users who open a crafted link to the mobile GUI are
affected.

### Affected Checkmk Versions

* 2.5.0
* 2.4.0
* 2.3.0 (EOL)

### Vulnerability Management

We have rated the issue with a CVSS Score of HIGH
(`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:P/VC:H/VI:H/VA:H/SC:N/SI:L/SA:N 8.7 HIGH`)
and assigned `CVE-2026-107173`.
