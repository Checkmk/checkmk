# GCP: don't crash on cancelled requests

key        | value
---------- | ---
date       | 2026-11-02T05:54:22.303606+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

When Google Cloud cancelled the request for a single metric (gRPC
error `499 CANCELLED`, for example after a server-side timeout), the
GCP special agent crashed with
`RuntimeError: 499 CANCELLED: <metric name>`. No GCP data was
delivered for that run and a crash report was created.

The agent now treats a cancelled request like a rate limit or an
internal Google Cloud error: it reports the affected metric as an
error and continues with all other metrics.
