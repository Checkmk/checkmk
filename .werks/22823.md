# Proxmox VE: don't crash on import lock

key        | value
---------- | ---
date       | 2026-11-02T06:02:17.953827+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a virtual machine in Proxmox VE was locked by the import wizard
(config lock `import`), the Proxmox VE special agent crashed with
`ValueError: 'import' is not a valid LockState` and no data was
delivered for the whole Proxmox VE cluster.

The agent now knows the `import` lock, as well as the container locks
`destroyed`, `disk`, `fstrim` and `mounted`, and reports the lock in
the VM info service as for any other lock.
