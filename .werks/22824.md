# Windows agent: Python module no longer ships build tools

The Python module of the Windows agent (python-3.cab) carried leftovers
from our build process in the site-packages of its base interpreter:
the dependencies of pipenv and virtualenv (e.g. certifi, distlib,
filelock, packaging, platformdirs), a pipenv benchmark script and a
setuptools hook (distutils-precedence.pth).

The agent's plugins never used them: they run in the module's virtual
environment, which does not see the base site-packages. Vulnerability
scanners on your Windows hosts did report them, though, for example an
additional, separately versioned certifi.

These files are no longer part of the module.
