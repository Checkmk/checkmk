# Cisco Meraki: fix switch port traffic and speed

key        | value
---------- | ---
date       | 2026-11-24T13:55:01.356274+00:00
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Previously, the _Interface_ services of Cisco Meraki switches showed
the port traffic 1000 times too low. The Meraki API reports traffic in
kilobits per second, but Checkmk used the values as bits per second.
This affected the In/Out values and the `if_in_bps`/`if_out_bps`
metrics of these services.

The traffic is now converted correctly. Your graphs will jump to the
real values after the update.

Two smaller issues were fixed along the way:

* A port speed reported in Kbps was converted incorrectly, so the
  HW/SW inventory showed a wrong interface speed.
* The host label `cmk/has_lldp_neighbors:yes` was generated once for
  every port with LLDP neighbors instead of once per host.
