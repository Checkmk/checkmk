Product usage analytics now also sends the following fields:

* `os`: the operating system the site is running on, the same value that is reported with the license usage.
* `users`: counts of the users configured on the site, split into humans and automation users. Each group is counted by built-in role, by type of the connection the users are managed by, and by the users that used the GUI or the REST API in the last 24 hours, 7 days and 30 days. All custom roles are counted together as "custom".
* `languages`: the default language of the user interface and the number of interactive users per language, split into users active in the last 30 days and inactive users. Users without a language in their profile count under the default language. Languages that Checkmk does not ship count as "custom".
* `inventory`: the number of monitored hosts that have HW/SW Inventory data.
* `distributed_monitoring`: whether the site is a remote site of a distributed monitoring setup that the central site configures. The folders and users of such a site are copied from the central site.

Only counts are sent. User names, aliases, email addresses, custom role names and connection names are not included.

This data tells us which operating systems Checkmk runs on, how users and their authentication are set up, which languages we should spend time maintaining, and how much the HW/SW Inventory is used.

Run `cmk-product-usage --dry-run` to see the data, or check
https://analytics.checkmk.com/manifest.
