# SNMP uptime: ignore negative uptime

key        | value
---------- | ---
date       | 2026-11-02T06:08:25.179887+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Some SNMP devices report the host resources uptime (hrSystemUptime)
as a signed 32 bit value, which becomes negative after about 248 days
of uptime. The SNMP `Uptime` service then crashed with
`ValueError: Cannot render negative timespan`.

A negative uptime value is now ignored. The service uses the uptime
of the SNMP agent (sysUpTime) instead and shows the real uptime.
