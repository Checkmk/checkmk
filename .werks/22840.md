# Cisco Meraki: unknown uplink network

---------- | ---

edition    | community

If Cisco Meraki reported the uplink status of an appliance in a
network that was not part of the organization's network list, the
Cisco Meraki special agent crashed with a `KeyError` naming the
network ID. No data was delivered for the remaining organizations.

The agent now reports the uplink status of such an appliance anyway.
The uplink service then shows no network name.
