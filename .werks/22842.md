# Cisco Prime: missing software version

key        | value
---------- | ---
date       | 2026-11-02T06:42:09.591408+00:00
version    | 2.4.0p40
class      | fix
edition    | cre

level      | 1
compatible | yes

If Cisco Prime reported a WLAN controller without a software version,
parsing the Cisco Prime WLAN controller data failed with
`KeyError: 'softwareVersion'`. All `Cisco Prime WLAN Controller`
services of all controllers on the host crashed.

Such a controller is now monitored normally. Its metadata service
simply does not show a software version.
