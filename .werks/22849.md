# Network scan: hosts added although they don't answer pings

key        | value
---------- | ---
date       | 2026-11-25T07:01:24.654139+00:00
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

The network scan of a folder sometimes created hosts for IP addresses
that do not answer ICMP echo requests at all.

The scan treated an address as reachable whenever the `ping` command
succeeded. `ping` also accepts echo replies that come from a different
address.

The network scan now only adds an address if an echo reply came from that
address itself.
