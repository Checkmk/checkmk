# EC: don't open dropped counted events

key        | value
---------- | ---
date       | 2026-10-23T10:07:09.675651+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

When an event limit dropped the event of a rule counting messages with _Count
until triggered_ set to 1, the Event Console nevertheless treated the event as
opened: The event history contained an entry for the event, although it didn't
exist. If the rule had actions, executing them failed with an error and a
traceback in `var/log/mkeventd.log`, and messages received together with the
dropped one could get lost.

The Event Console now drops such events like any other.
