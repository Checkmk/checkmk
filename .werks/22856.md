# EC: syncing slaves refuse more commands

key        | value
---------- | ---
date       | 2026-10-23T10:07:12.589502+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

An Event Console replicating the events of a central Event Console refuses
commands changing its events while it syncs, as its next sync replaces its
events anyway. It accepted archiving all events of a host, though, e.g. via the
command _Archive events of hosts_ in a service view. The next sync brought back
the archived events, but the history of the replicating Event Console kept them
as archived.

The replicating Event Console now refuses this command while it syncs, too.
Archive such events on the central Event Console instead.
