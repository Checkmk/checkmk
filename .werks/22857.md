# EC: remove all events after downtimes

key        | value
---------- | ---
date       | 2026-10-23T10:07:13.552241+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

When the downtime of a host ended, the Event Console removed the events which it
had created during the downtime. Each run of its periodic housekeeping, however,
removed only every second one of them, so with several such events, some of them
stayed open for further minutes.

The Event Console now removes all of them at once.
