# EC: rules can start expecting messages

key        | value
---------- | ---
date       | 2026-10-23T11:00:05.843785+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

If you changed a rule to _Expect regular messages_ while it had open events
which didn't count messages, the Event Console failed when such an expected
message was missing: Merging the event about the missing message into one of
those open events raised an error, which it logged with a traceback in
`var/log/mkeventd.log`. As the interval of the rule never ended, the Event
Console retried and logged the error about every second. Meanwhile, it no longer
saved its current events periodically, and a replicating Event Console no longer
synced with its central Event Console. The Event Console also stopped handling
further rules expecting messages, removing events created during a downtime and
cleaning up the history.

The Event Console now merges the event about a missing message into such an
event like into any other one.
