# EC: overflow events don't pile up

key        | value
---------- | ---
date       | 2026-10-23T14:03:06.213470+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

With the event limit action _Stop creating new events, create overflow event_,
with or without notification, the Event Console created a further overflow event
and notified again, if configured, whenever an event reached the limit while the
overflow event about it was still open, e.g. after you archived only some of the
other events. The overflow events of a limit therefore piled up.

The Event Console now creates no further overflow event about a limit and
doesn't notify again as long as an overflow event about it is open. Overflow
events created by previous versions don't prevent a new one, though.
