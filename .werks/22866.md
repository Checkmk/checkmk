# EC: don't count into overflow events

key        | value
---------- | ---
date       | 2026-10-23T14:03:08.054740+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

A rule counting messages could count them into the overflow event about its rule
limit, e.g. with a limit of 1. This changed the text and the host of the
overflow event, and the event counting the messages didn't open. Likewise, an
event about missing expected messages could be merged into the overflow event
about the limit of its rule.

The Event Console now leaves overflow events alone when counting messages and
when merging events about missing messages.
