# EC: failing tasks don't block the others

key        | value
---------- | ---
date       | 2026-10-23T17:15:12.140210+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

If one of the periodic tasks of the Event Console failed again and again, e.g.
its housekeeping because of the error fixed by
[Werk #22860](https://checkmk.com/werk/22860), the Event Console retried that
task and logged its error about every second. Meanwhile, it didn't run the tasks
after it anymore: Depending on the failing task, it no longer saved its current
events, updated its statistics or, as a replicating Event Console, synced with
its central Event Console.

The Event Console now retries a failing task only after the interval of that
task, and it runs its other tasks in the meantime.
