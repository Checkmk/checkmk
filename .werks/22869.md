# EC: fix group references when rewriting

key        | value
---------- | ---
date       | 2026-10-23T17:19:21.669554+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

When a rule of the Event Console rewrote the text, the comment, the host name,
the application or the contact of an event, it replaced the references to the
matched message one after the other. As a consequence, `\10` and higher referred
to the first match group followed by a digit, even with enough match groups.
Moreover, it also replaced references within a text which an earlier reference
had inserted, e.g. the `\1` within the message `C:\1tmp` inserted by `\0`, or a
reference within an inserted match group.

The Event Console now replaces all references at once, so `\10` refers to the
tenth match group, if there is one, and inserted texts stay as they are.
