# EC: fix rewriting of merged events

key        | value
---------- | ---
date       | 2026-10-23T19:57:08.653377+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

For a rule with _Expect regular messages_ that merges the events about missing
messages into an open one, the Event Console rewrote the host name and the
application of the merged event once more, starting from the already rewritten
values. So a reference to the original value like `\0` in _Rewrite host name_
or _Rewrite application_ piled up with every merge: With `missing-\0` as the
host name, for example, the host name of the event became `missing-` for the
first missing message, `missing-missing-` for the next one, and so on.

Merging now rewrites the host name and the application like for a new event
about missing messages.
