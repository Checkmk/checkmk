# EC: don't cancel overflow events

key        | value
---------- | ---
date       | 2026-10-23T21:04:25.014583+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

A rule cancelling events could cancel the overflow event about its rule limit,
executing its cancelling actions for it. This happened for a cancelling message
with an empty host name, possibly after rewriting it, if the rule cancels by the
syslog application or if the message had the application "Event Console".

The Event Console now leaves overflow events alone when cancelling events.
