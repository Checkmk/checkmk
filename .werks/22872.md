# EC: reloads don't undo mode switches

key        | value
---------- | ---
date       | 2026-10-23T21:30:06.251998+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

When the replication mode of an Event Console replicating the events of a
central Event Console was switched, e.g. to the takeover mode, while it reloaded
its configuration, e.g. when activating changes, the reload could undo the
switch. The Event Console then kept working in its previous replication mode.

Reloading the configuration no longer interferes with switching the replication
mode.
