When uploading a zip file with MIBs, a MIB file was reported as skipped if
recording its pending change failed, although it had already been stored, and
the upload went on with the next MIB file. The MIB file then showed up among the
custom MIBs without a pending change to activate it.

Such an upload fails with an error now, like uploading a single MIB file.
