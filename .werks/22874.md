# Cisco Meraki: fix United States FedRAMP region

key        | value
---------- | ---
date       | 2026-11-25T14:33:33.381255+00:00
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

In the special agent rule _Cisco Meraki_, the option _Meraki region_ >
_United States FedRAMP_ did not work. The special agent used the base
URL `https://api.gov-meraki.com/api/` without the API version, so its
requests to the Meraki API failed and no data was retrieved.

The special agent now uses `https://api.gov-meraki.com/api/v1`, the URL
listed in the Meraki API documentation and in the rule's help text.
The other regions were not affected.
