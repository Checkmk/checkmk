# Tables offer no dragging while searching

key        | value
---------- | ---
date       | 2026-10-30T09:16:04.520784+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Tables listing things in an order you can change by dragging their rows, e.g.
the notification rules, the notification parameters, the LDAP and SAML
connections, the alert handler rules or the content elements of a report,
offered the drag handles also while "Find on this page ..." showed only the
rows matching a search. The position to drop a row at counted the shown rows
only, so the row ended up at the wrong place among all rows.

While such a table shows only the rows matching a search, its drag handles are
greyed out now and tell you to clear the search to move rows again.
