# EC: fix dialog of archiving host events

version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

Selecting services in a view and choosing the command "Archive events of hosts"
showed a confirmation made for the services of a single host. Unless the view
showed the services of one host, it named the host "None", and it always showed
"Affected events: N", with N being the number of selected services instead of a
number of events. The confirmation names the host of the selected services now,
or tells how many hosts they belong to, and leaves out the count.

The help text of the command no longer claims that it needs a rule "Check event
state in Event Console", and it now says that the command archives the events
of the hosts of all selected services.
