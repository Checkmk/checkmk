# EC: archiving finds all events of hosts

key        | value
---------- | ---
date       | 2026-10-30T11:37:30.417082+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

The command "Archive events of hosts" in service views archived only those
events of the hosts of the selected services whose host name was exactly the
name of the monitored host. Events which the Event Console assigned to the host
via its IP address or alias, or via its name written in a different case,
stayed open, although the views listed them for the host. The same held for
events which arrived before the monitoring knew the host. These events are
archived now, too. This includes events which the Event Console assigned to the
host when they arrived, even if the views no longer list them for the host,
e.g. because its IP address has changed since then.

This Werk fixes a regression that occurs since Checkmk 2.0.0p30, 2.1.0p15 and
2.2.0b1.
