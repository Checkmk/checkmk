# check_mkevents: crashes and wrong states

The active check "Check event state in Event Console" (check_mkevents) crashed
on events with an empty or multi-line text, and after an event with a very short
line, it ignored all further events, so it could miss a CRIT event. It also
ranked UNKNOWN above CRIT, and notifications showed vertical bars in event texts
as another character. This is fixed now.
