# check_mkevents: aliases split at spaces

The active check "Check event state in Event Console" (check_mkevents) split
host lists at spaces, too, so the alias "DB server 1" also matched the hosts
"db", "server" and "1". Each host of a list is matched as a whole now. On the
command line, the new option `-q` lets a backslash quote a slash or backslash.

This is incompatible if a service relied on single words of an alias, e.g. on
`srv01` of the alias `srv01 Database`. Translate such host names with the global
setting "Host name translation for incoming messages" of the Event Console, or
add them to the host specification, e.g. `$HOSTNAME$/srv01`.
