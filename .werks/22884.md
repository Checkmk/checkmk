# Windows agent: Python module ships pip only once

The Python module of the Windows agent (python-3.cab) contained pip
twice: once in its virtual environment and once in the site-packages of
its base interpreter. Only the copy in the virtual environment is ever
used, since that is where the agent's plugins run.

The second copy came with its own set of vendored packages (certifi,
urllib3, requests and more), which vulnerability scanners on your
Windows hosts reported in addition to the ones actually in use.

The base interpreter no longer contains pip. If you install additional
packages for your own plugins, nothing changes for you: keep using
`.venv\Scripts\pip install` in the module's directory.
