# Parent scan: gateways accepted although they don't answer pings

key        | value
---------- | ---
date       | 2026-11-25T07:09:28.110721+00:00
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

The parent scan could choose a gateway as parent although that gateway
does not answer ICMP echo requests.

The scan treated a gateway as reachable whenever the `ping` command
succeeded. `ping` also accepts echo replies that come from a different address.

The parent scan now only accepts a gateway if an echo reply came from that
gateway itself.
