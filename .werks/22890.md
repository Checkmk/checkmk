# Host diagnostics and host properties: ping succeeds for hosts that don't answer pings

key        | value
---------- | ---
date       | 2026-11-25T07:09:56.838102+00:00
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Two places could report a host as reachable although it does not answer
ICMP echo requests: the ping test on the *Host diagnostics* page and the
ping indicator next to the host name and IP address fields in the host
properties.

Both treated the host as reachable whenever the `ping` command succeeded.
`ping` also accepts echo replies that come from a different address.

Both now only succeed if an echo reply came from the pinged address itself.
The ping output on the *Host diagnostics* page now shows IP addresses
instead of host names.
