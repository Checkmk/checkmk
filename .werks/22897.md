# check_mkevents: hang and argument errors

The active check "Check event state in Event Console" (check_mkevents) hung
until the core killed it if a remote Event Console didn't answer. It now times
out after 20 seconds, or as set in the new rule option "Timeout", reports a
connection closed without an answer, and rejects invalid options.
