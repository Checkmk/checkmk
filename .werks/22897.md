# check_mkevents: hang and argument errors

The active check "Check event state in Event Console" (check_mkevents) hung
until the core killed it if a remote Event Console didn't answer, e.g. due to a
firewall. It now gives up after 20 seconds.

If the Event Console closed the connection without answering, e.g. for denied
access, the check reported a misleading error. Now it says so and points to
var/log/mkeventd.log. Invalid command line options are rejected now, too.
