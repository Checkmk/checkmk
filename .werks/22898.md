# EC: fix missing row limit warning

key        | value
---------- | ---
date       | 2026-10-30T14:42:40.340737+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

Views of the Event Console warn when their row limit cuts off events. Users who
have neither the permission "See all events" nor "See events not related to a
known host" don't see events which belong to no monitored host and got no
contact groups from their rule. The views counted only the remaining events for
the limit, so if enough of the fetched events were hidden, the warning was
missing although the limit had cut off events. The views now count all fetched
events for the limit.
