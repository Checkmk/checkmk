# Redfish: line breaks in BMC values

key        | value
---------- | ---
date       | 2026-11-02T13:01:58.122248+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

A BMC record can contain a corrupted free-text value with a line break,
for example one of several identical NVIDIA H200 NVL GPUs reporting its
model as `900-2101` followed by `G40-000` on a new line. The Redfish
`CPU` service then crashed with
`ValueError: '\n' not allowed in 'summary'`.

The CPU service and most other Redfish services now replace line
breaks in values reported by the BMC by spaces.
