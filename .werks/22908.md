# aws_ec2_limits: Report WARN again for instance types unknown to Checkmk

This werk partially reverts [Werk #22294](https://checkmk.com/werk/22294),
which stopped reporting WARN when running on-demand EC2 instances were of a
type unknown to Checkmk. As a result, users were not made aware that no limits
were checked for these instance types.

The service "AWS/EC2 Limits" now reports WARN again in this case. The
improvements from Werk #22294 remain: the instance count of such types is
reported as a metric, and the types are named in the service details, for
example "Instance types unknown to Checkmk, no limits checked: r8a.4xlarge (3)".
