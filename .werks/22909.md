# aws_ec2_limits: Configurable state for EC2 instance types unknown to Checkmk

As a follow-up to [Werk #22908](https://checkmk.com/werk/22908), which restored
the WARN state when EC2 instance types were unknown to Checkmk, users can now
select which state the service reports in this situation. WARN remains the
default but can be overridden in the ruleset _AWS/EC2 limits_ for AWS
(deprecated) or _AWS v2/EC2 limits_ for AWS v2.

In all cases, the summary of the _AWS/EC2 Limits_ service shows how many
unrecognized instance types were found, and the service details list each type
with its number of running instances.
