# aws_ec2_limits: Fix timeout on the service parameters page

---------- | ---

class      | fix
edition    | community

level      | 1

Opening _Parameters of this service_ for an _AWS/EC2 Limits_ service took
several minutes and then failed with "Invalid parameter {...}: Your request
timed out after 110 seconds", followed by a very long list of EC2 instance
types.

The default parameters of the check contained explicit levels for every EC2
instance type known to Checkmk, well over a thousand of them, and rendering
these in the GUI was extremely slow. The defaults no longer list the
instance types. The check still applies the same default levels to them, so
the checked limits and the service states do not change, and neither do any
rules you configured in _AWS/EC2 limits_.

As a side effect, the parameters page now shows empty lists for the limits
per instance type and per instance family, unless a rule sets them.
