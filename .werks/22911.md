# aws_ec2_limits: Known EC2 instance types now include t8i

Checkmk now knows the EC2 instance types `t8i.medium`, `t8i.micro`, `t8i.nano`
and `t8i.small`. Running instances of these types are now checked against their
limits, instead of being reported as instance types unknown to Checkmk.

The list of instance types also contained several Dedicated Host families,
which are not instance types and were added by mistake. They have been
removed: `mac2-m1ultra`, `mac2-m2`, `mac2-m2pro`, `u-12tb1`, `u-18tb1`,
`u-24tb1`, `u-6tb1`, `u-9tb1`, `u7i-12tb`, `u7i-6tb`, `u7i-8tb`, `u7in-16tb`,
`u7in-24tb`, `u7in-32tb`.

Selecting one of these in the ruleset _AWS/EC2 limits_ never had any effect.
If one of your rules uses one of these values, the update reports it as an
invalid rule configuration, and the rule editor marks the entry as an invalid
selection. Simply remove the entry and save the rule.
