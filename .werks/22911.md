# aws_ec2_limits: Known EC2 instance types now include t8i

key        | value
---------- | ---
date       | 2026-11-18T10:25:40.676593+00:00
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

Checkmk now knows the EC2 instance types `t8i.medium`, `t8i.micro`, `t8i.nano`
and `t8i.small`. Running instances of these types are now checked against their
limits, instead of being reported as instance types unknown to Checkmk.
