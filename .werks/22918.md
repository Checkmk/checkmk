# Fix stack buffer overflow in mkevent

mkevent built the notifications it forwards to the Event Console in an 8 KB
stack buffer without checking their length. A long host or service output could
crash it, lose the notification or, if crafted, redirect it to an IPv4 address
of the attacker's choice. mkevent now cuts messages off after 8191 bytes.

*Who's Affected*:

All editions, but only sites forwarding notifications to the Event Console with
the notification plug-in "Forward notification to Event Console" or the global
setting "Send notifications to Event Console".

*Affected Versions*:

* 2.5.0
* 2.4.0
* 2.3.0 (EOL)
* 2.2.0 (EOL)

*Mitigations*:

If updating is not possible, disable the notification rules and unset the
global setting mentioned above.

*Vulnerability Management*:

We have rated the issue with a CVSS Score of 2.3 Low
(`CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:L/VI:L/VA:L/SC:N/SI:L/SA:N`) and assigned
`CVE-2026-110470`.

We thank Tristan Madani (Talence Security) for reporting this issue.
