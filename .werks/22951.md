# check_mkevents: remote access via IPv6

The active check "Check event state in Event Console" (check_mkevents) now
reaches a remote Event Console via IPv6, too, trying all its addresses, IPv6
first. If "Access to event status via TCP" there restricts the source
addresses, allow the IPv6 addresses of your site's host, too, or use an IPv4
address in the rule.

Write an IPv6 address with a port in brackets, e.g. `[2001:db8::1]:6558`, and
`cafe:6558` instead of `cafe::6558`, which is an IPv6 address now.
