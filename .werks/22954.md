# EC: don't truncate UDP syslog messages

key        | value
---------- | ---
date       | 2026-11-02T08:45:02.482409+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

The builtin syslog server of the Event Console cut off messages it received via
UDP after 4096 bytes. Mostly, that just cost the end of a long message. But when
the cut split a UTF-8 character, the Event Console couldn't parse the message
anymore: The resulting event had no host, the priority "emerg", and the whole
raw message as its text.

The Event Console now receives such messages completely, up to the largest size
of a UDP datagram. That matters for any device sending long syslog messages via
UDP, e.g. mkevent, which forwards notifications to a remote Event Console with
up to 8191 bytes.
