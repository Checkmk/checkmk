# EC: queries split at more than newlines

key        | value
---------- | ---
date       | 2026-11-02T09:54:41.052209+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | no

The Event Console split queries to its status socket at all line breaks Python
knows, e.g. at a vertical tab, so such a character in a value could change the
query. It now splits queries like Livestatus.

This is incompatible for scripts querying the status socket directly, not for
queries via Livestatus: whitespace at the end of a line is dropped now, and GET
needs a space before the table.
