# EC: queries parsed unlike Livestatus

key        | value
---------- | ---
date       | 2026-11-02T09:54:41.052209+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | no

The Event Console parsed queries to its status socket unlike Livestatus, e.g. a
vertical tab split a query, and "event_host_in_downtime = 0" selected events of
hosts in a downtime. Now it parses them like Livestatus.

Scripts querying the status socket directly may need changes, e.g. GET needs a
space before the table, unsupported headers like `Or` are rejected, and
`Columns` and `Limit` work like in Livestatus. Alternatively, use the Livestatus
tables `eventconsoleevents` and `eventconsolehistory`.
