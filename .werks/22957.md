# Debian package: fix the setuid fallback

The Debian package gives programs like mkeventd_open514 and check_icmp the Linux
capabilities they need while installing. Where that fails, e.g. on a filesystem
without support for capabilities, it was meant to make them setuid root instead,
see Werk #7774. That fallback never worked: The installation printed "Failed to
set capabilities ... Falling back to setuid." and then aborted, as it passed
chmod a wrong path. Now the fallback works, and the installation completes.
