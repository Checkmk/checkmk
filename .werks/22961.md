# File descriptor leak after errors

key        | value
---------- | ---
date       | 2026-11-02T19:20:28.968213+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

Each time the event server of the Event Console restarted after an error, it
leaked a file descriptor of the event pipe, so recurring errors could use them
all up. It also dropped its client connections and partly received messages.

Now it keeps the event pipe, the client connections and such messages across
restarts.
