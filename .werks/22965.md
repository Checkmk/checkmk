# Azure VM: don't crash on multi-line status messages

key        | value
---------- | ---
date       | 2026-11-03T06:53:42.308096+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If Azure reported a status message of several lines for a virtual
machine, the _VM_ service crashed with
`ValueError: '\n' not allowed in 'summary'`. An example is a failed
provisioning with the message `Allocation failed. ...`, followed by
alternative VM sizes on further lines.

The service now shows the full message on one line.
