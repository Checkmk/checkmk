# Proxmox VE: don't crash on an uptime of -1

key        | value
---------- | ---
date       | 2026-11-03T06:57:34.370586+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Proxmox VE API reported an uptime of `-1` for a virtual machine
or container, the Proxmox VE special agent crashed with a
`ValidationError` for `SectionVMInfo`. All services of the monitored
Proxmox VE hosts then went stale.

The agent now treats a negative uptime as unknown. The _Proxmox VE VM
Info_ service of the affected guest then shows no uptime.
