# HiveManager NG devices: don't crash on a vanished device

key        | value
---------- | ---
date       | 2026-11-03T07:06:18.673691+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a device monitored via HiveManager NG was no longer part of the
agent output, its _Client_ service crashed with
`TypeError: 'NoneType' object is not subscriptable`.

The service now goes to `CRIT` with "No data for device.".
