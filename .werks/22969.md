# Kubernetes: don't crash on a node without load averages

key        | value
---------- | ---
date       | 2026-11-03T07:34:51.372305+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If Prometheus returned the CPU count of a Kubernetes node but none of
its load averages, the Kubernetes special agent crashed with a
`ValidationError` for `CPULoad`.

The agent now skips the CPU load data of such a node and continues. The
CPU load service of that node then has no data.
