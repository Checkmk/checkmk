# BGP peer: don't crash on an empty SNMP row

key        | value
---------- | ---
date       | 2026-11-03T07:41:32.976649+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If a device returned an SNMP row without any data for its BGP peers,
parsing the BGP peer data failed with `IndexError: list index out of
range` (Arista) or a `ValueError` (Cisco, BGP4-MIB). The _BGP Peer_
services of the host crashed.

Rows without a peer address are now skipped. All other peers are
monitored as before.
