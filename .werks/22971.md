# DB2 Counters: don't crash on a multi-line error message

key        | value
---------- | ---
date       | 2026-11-03T07:53:55.978697+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If DB2 returned an error message instead of a counter value and the
message wrapped onto a second line, parsing the DB2 counters failed with
`IndexError: list index out of range`. All _DB2 Counters_ services of
the host crashed.

The continuation line is now ignored. The affected database shows the
error as an invalid value (`CRIT`), all other databases are checked as
before.
