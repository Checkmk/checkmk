# Spool files held back by broken entries

key        | value
---------- | ---
date       | 2026-11-02T19:37:38.034372+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | ec
level      | 1
compatible | yes

A directory, a broken symbolic link or an unreadable file in the spool directory
`var/mkeventd/spool` made the Event Console restart its event server every two
seconds, and a FIFO there made it hang. A spool file it couldn't remove was
processed again with each restart.

Now it only reads regular files there and warns once about anything else. It
removes a file before processing it. A file it can't read or remove, or one
bigger than 16 MiB, is renamed to `.<name>.unreadable` if possible, otherwise
skipped. Either way, it logs an error in `var/log/mkeventd.log`.
