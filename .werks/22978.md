# Stalls on long lines without a newline

A long line without a newline, e.g. a few megabytes, made the Event Console use
a lot of memory and stall for minutes.

Now it takes long messages in linear time and truncates them, with a warning in
`var/log/mkeventd.log`: on its event socket to 32 MiB, enough for the log
records of the OpenTelemetry collector, and elsewhere to 65535 bytes, like for
syslog via UDP.

If you send messages longer than 65535 bytes with syslog via TCP, to the event
pipe or in spool files, split them up. If they come from the site itself, you
can send them to the event socket instead.
