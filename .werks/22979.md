# Linux processes: name a cut-off ps line in the crash report

If the Linux agent output received by Checkmk ended in the middle of a
process line, parsing the process data failed with `KeyError: 'rss'`,
which did not say what was wrong.

The crash report now states that a process line is incomplete because
the agent output was cut off. Such output points to a problem between
the agent and the Checkmk site, for example a connection that was closed
before the agent had sent all of its data, so it is still reported
instead of being silently ignored.
