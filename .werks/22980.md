# Product usage analytics: Translate the global setting hint

key        | value
---------- | ---
date       | 2026-11-03T08:06:51.323305+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

With the user interface language set to anything other than English,
the hint on the *Product usage analytics* global setting was always
shown in English, even though a translation exists.

The hint was translated once when the GUI started, before the user's
language was known. It is now translated each time the page is
rendered, so it is shown in the user's language.
