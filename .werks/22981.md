# Master control: crash for down sites

key        | value
---------- | ---
date       | 2026-11-06T09:33:15.880410+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

If a site connection had a _Status host_ and that host was `DOWN`, `UNREACH` or
not yet checked, the _Master control_ snapin showed only an error with the
message `'program_version'` for this site. Now the snapin shows the state of
the site instead, e.g. "This site is currently down."
