# Docker node images: don't crash on a cut-off line

key        | value
---------- | ---
date       | 2026-11-03T08:17:32.396636+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

If the last line of the Docker node images data was cut off, the HW/SW
inventory of the Docker node failed with a `JSONDecodeError`.

Incomplete lines are now skipped. All other images and containers are
inventorized as before.
