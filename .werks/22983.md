# EC: filters dropping events or failing

Livestatus queries of the Event Console tables dropped events or failed with
"received no reply" for some filters, e.g. `event_core_host ~ .` for an event
of an unknown host, `=~` on letters like `µ`, regular expressions with `\p{Lu}`
or filters on a comment with a tab. The MongoDB history filtered differently,
too. All filters work like in Livestatus now.

Like in messages, a tab becomes a space now in texts, applications, comments
and contacts which rules or commands set. Older events and history entries keep
theirs, so a rule setting an application with a tab may no longer cancel or
count up such older events.
