# Event Console hung on a full event pipe

edition    | community

Creating an event, e.g. with EC_CREATE, or an action script writing into the
event pipe, e.g. with mkevent, hung the Event Console for good if the pipe was
full. Now creating an event fails if the pipe stays full for 5 seconds.

Actions now run in the background, one after another. Scripts and e-mails get
killed after a minute, notifications after five minutes, so start lengthy tasks
in the background, e.g. `command >/dev/null 2>&1 &`. Beyond 2000 pending
actions, new ones get dropped, and on stopping, those still pending after about
40 seconds. Scripts can't look up automatically deleted events anymore.
