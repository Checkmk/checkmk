# Micro Core closed helper sockets twice

key        | value
---------- | ---
date       | 2026-11-10T18:11:55.797216+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | cmc
level      | 1
compatible | yes

When the Checkmk Micro Core started or stopped a helper process, e.g. a
fetcher, checker, notification or ICMP helper, it closed the helper's socket
twice. If another part of the core opened a file or connection in between, the
second close hit that one instead, which could cause sporadic errors there.

The core now closes each helper socket once.
