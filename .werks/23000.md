# Proxmox VE: don't crash without node timezone

key        | value
---------- | ---
date       | 2026-11-03T08:50:31.596119+00:00
version    | 2.4.0p40
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

If there was backup data but none of the Proxmox VE nodes reported a
timezone, the Proxmox VE special agent crashed with `StopIteration`.
All services of the monitored Proxmox VE hosts then went stale.

The agent now interprets the backup start times as UTC in this case.
If the nodes run in another timezone, the backup age shown by the
_Proxmox VE VM Backup Status_ service can be off by that offset.
