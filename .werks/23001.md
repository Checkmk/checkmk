# Redfish: don't crash on a corrupted session file

key        | value
---------- | ---
date       | 2026-11-03T08:54:55.830907+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the session file stored by the Redfish special agent was empty or
incomplete, the agent crashed with a `JSONDecodeError`. Overlapping
runs of the agent are a known cause, already fixed with
[Werk #22278](https://checkmk.com/werk/22278).

The agent now ignores an unreadable session file and logs in again.
