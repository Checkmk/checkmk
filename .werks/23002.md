# Proxmox VE: don't crash on a truncated backup cache

key        | value
---------- | ---
date       | 2026-11-03T08:57:20.871677+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the backup log cache file of the Proxmox VE special agent was
truncated, the agent crashed with a `JSONDecodeError` on every run.
All services of the monitored Proxmox VE hosts then went stale until
the file was removed by hand.

The agent now discards an unreadable cache, fetches the backup logs
again and rewrites the cache.
