# Redfish power: no crash on non-power devices

key        | value
---------- | ---
date       | 2026-11-04T07:37:31.506684+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the rule "Redfish compatible power equipment (PDU)" was applied to a
host whose Redfish service offers neither a `PowerEquipment` nor a
`PowerDistribution` resource, the special agent crashed and created a
crash report.

The special agent now exits with an error instead of creating a crash
report.
