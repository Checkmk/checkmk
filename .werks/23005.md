# Azure: no crash on unknown subscription

edition    | community

When a subscription configured in the Azure rule was not visible to the
configured app registration (wrong subscription ID or missing
permissions), the Azure special agent crashed with "Subscription ...
not found in Azure API, please check the client permissions." and
created a crash report.

The agent now reports this message as an error and ends with exit
code 2, like the connection test already did.
