# StoreOnce 4.x: no crash on rejected login

key        | value
---------- | ---
date       | 2026-11-04T07:48:59.518935+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

When an HPE StoreOnce 4.x appliance rejected the login of the special
agent, for example because of a wrong username or password, the agent
crashed with "(missing_token) Missing access token parameter." and
created a crash report.

The agent now reports a login error and ends normally. With `--debug`
the original exception is still raised.
