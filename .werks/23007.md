# Cisco Meraki: no crash if devices are refused

key        | value
---------- | ---
date       | 2026-11-04T07:59:00.720415+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

When the Cisco Meraki API refused the device list of an organisation,
for example with "403 Forbidden" because the API key is limited to
approved subnets or the organisation has no licensed devices, or with
"502 Bad Gateway", the Cisco Meraki special agent crashed and created
a crash report.

The agent now skips the devices of that organisation and continues,
as it already did for the other organisation requests.
