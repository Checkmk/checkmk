# Redfish: no crash if session is refused

key        | value
---------- | ---
date       | 2026-11-04T08:04:51.244784+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

When the Redfish interface of a server refused to create a login
session, for example with HTTP 404 or 503, the Redfish special agent
crashed and created a crash report.

The agent now ends with a login error instead of creating a crash
report, as it already did for unreachable servers and invalid
credentials.
