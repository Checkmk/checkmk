# AWS status: no crash on connection errors

When the AWS Health Dashboard special agent could not fetch the AWS
status feed, for example because the connection was reset, it crashed
and created a crash report.

The agent now reports the connection problem as a regular agent error,
so the Checkmk service of the host shows what went wrong.
