# Azure status: no crash on connection errors

key        | value
---------- | ---
date       | 2026-11-04T09:43:54.196824+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

When the Azure status special agent could not fetch the Azure status
feed, for example because the connection was reset or the TLS
handshake failed, it crashed and created a crash report.

The agent now reports the connection problem as a regular agent error,
so the Checkmk service of the host shows what went wrong.
