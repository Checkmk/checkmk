# Views: no crash on host rows without services

key        | value
---------- | ---
date       | 2026-11-05T05:59:03.699264+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

A view could fail with "argument of type 'NoneType' is not iterable"
when it showed the summary of a host that had no service data in a
service-based view, for example in a view widget on a dashboard.

The host's setting for escaping the plug-in output is now used in
this case.
