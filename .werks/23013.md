# Notification rules API: reject built-in plug-ins as custom

key        | value
---------- | ---
date       | 2026-11-05T06:11:08.286408+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Creating or editing a notification rule via the REST API ended in an
internal server error ("KeyError: 'from_details'") when a built-in
notification method such as "mail" was sent with the option
`create_notification_with_custom_parameters`.

This option is meant for custom notification scripts. The REST API now
rejects built-in methods there with a validation error that points to
the option `create_notification_with_the_following_parameters`.
