# REST API: host and service lists name unreachable sites

key        | value
---------- | ---
date       | 2026-11-03T09:45:38.944809+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

In a distributed setup, when a remote site could not be reached, the REST
API's lists of hosts and services left out that site's hosts and services
without any notice. A script or tool reading these lists couldn't tell that
data was missing, so it could report everything as fine even though the state
of the remote site was unknown.

The lists now name the sites that could not be reached, so you can tell when
the data is incomplete.
