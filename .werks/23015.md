# Deleting a user ends the user's OAuth sessions

key        | value
---------- | ---
date       | 2026-11-25T07:42:11.049951+00:00
class      | fix
edition    | pro
component  | wato
level      | 1
compatible | yes

Deleting a user now revokes all OAuth grants of that user, for example
those of MCP clients the user connected, and deletes their tokens. This
applies whether you delete the user in Setup, via the REST API or by the
LDAP synchronization. On remote sites, it takes effect when you activate
the changes.
