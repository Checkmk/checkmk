# Notifications: no crash on old bulk format

key        | value
---------- | ---
date       | 2026-11-05T06:23:38.741147+00:00
version    | 2.5.0p21
class      | fix
edition    | community
component  | notifications
level      | 1
compatible | yes

Opening a notification rule in the notification setup could fail with
"KeyError: 0" when the rule stored its bulk notification setting in
the format of old Checkmk versions. Reading such a rule via the REST
API failed as well.

Such a setting is now read as "Always bulk", the same way the
notification processing already handles it.
