# Passwords: no crash on contact groups with hyphens

key        | value
---------- | ---
date       | 2026-11-05T07:13:50.354217+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Opening the dialog for adding a password, for example from a rule
form, failed with "... is not a valid, non-reserved Python identifier"
when a contact group name contained characters such as a hyphen.

Contact groups with such names are now offered in the "Editable by"
and "Share with" settings of the dialog.
