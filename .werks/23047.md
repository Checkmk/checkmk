# Host properties: no crash on unknown site

version    | 3.0.0b1
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

The reachability check next to the network address fields in the
properties of a host could fail with an internal error when the host was
assigned to a site that is no longer configured. The same applied to the
agent and SNMP connection tests and to the lookup of the agent receiver
port.

The reachability check and the connection tests now report "Unknown
site" in this case, and the agent receiver port falls back to the
default port.
