# Dashboard tag filter: no crash without tag group

key        | value
---------- | ---
date       | 2026-11-05T10:20:57.790349+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

The tag filter of a dashboard could fail with "KeyError: 'group_id'"
when the tag value field was used before a tag group was selected.

The tag value field now offers no choices until a tag group is
selected.
