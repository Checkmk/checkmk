# HTML email parameters: no crash on unknown settings

key        | value
---------- | ---
date       | 2026-11-05T10:59:35.833232+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | notifications
level      | 1
compatible | yes

The page with the parameters of the HTML email notification method
could fail with "KeyError: 'smtp'" on a Checkmk Community site when
the stored parameters contained settings that only exist in other
editions, such as the synchronous delivery via SMTP.

The parameters are now shown, without the settings the form does not
know. Saving the rule in the GUI removes these settings from it.
