# Custom graphs: no crash on lines without metrics

key        | value
---------- | ---
date       | 2026-11-05T12:36:47.911281+00:00
version    | 2.5.0p20
class      | fix
edition    | pro
component  | multisite
level      | 1
compatible | yes

Opening a custom graph could fail with an internal error when one of its
lines was an operation or a percentile that referred only to metrics
which are no longer part of the graph.

Such lines are now left out, as werk #19051 already does for single
operands that can no longer be found.
