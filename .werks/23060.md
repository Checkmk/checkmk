# REST API: no crash on hosts without credentials

key        | value
---------- | ---
date       | 2026-11-05T13:59:45.745164+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Listing or showing hosts via the REST API failed with an internal error
when a host had its SNMP credentials or the SNMP or IPMI credentials of
its management board stored without a value.

Such attributes are now left out of the response.
