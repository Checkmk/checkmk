# Setup: no crash on invalid host name in URL

key        | value
---------- | ---
date       | 2026-11-05T14:09:36.487954+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Some Setup pages failed with "invalid host address" when the URL
contained a host name that is not valid, for example one with spaces:
the folder pages, which look up the folder of the given host, and the
page for creating a cluster.

An invalid host name is now treated like a host that does not exist.
