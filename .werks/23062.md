# Software packages: no crash when sorting by version

Sorting the inventory view "Software packages" by version or package
version failed with "'>' not supported between instances of 'int' and
'str'" when the versions were made up of differently split parts, for
example "a1" and "a.1".

Such versions can now be sorted.
