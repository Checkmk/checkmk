# REST API: no crash when moving a rule without folder or rule ID

key        | value
---------- | ---
date       | 2026-11-09T06:50:56.396033+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Moving a rule via the REST API to `top_of_folder` or `bottom_of_folder`
without specifying a `folder` resulted in an internal server error. The
same happened when moving a rule to `before_specific_rule` or
`after_specific_rule` without specifying a `rule_id`.

The REST API now answers such a request with a validation error that
names the missing field.
