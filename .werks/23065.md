# REST API: no crash when moving a rule without folder

key        | value
---------- | ---
date       | 2026-11-09T06:50:56.396033+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Moving a rule via the REST API to `top_of_folder` or `bottom_of_folder`
without specifying a `folder` resulted in an internal server error.

The REST API now answers such a request with a validation error that
names the missing field.
