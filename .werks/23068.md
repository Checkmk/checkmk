# Dashboards: no crash for widgets from Checkmk 2.0

key        | value
---------- | ---
date       | 2026-11-09T08:12:14.269276+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Dashboards with single metric or gauge widgets that had not been edited since Checkmk 2.0 failed to open with a crash report, and could not be repaired in the GUI. These widgets still stored their service status display under the old name, which the dashboard did not find when loading.

Dashboards now convert this setting to the current name when they are loaded.
