# Dashboards: properties page keeps the layout

key        | value
---------- | ---
date       | 2026-11-09T08:37:07.079379+00:00
version    | 2.5.0p19
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

Saving a dashboard on its legacy properties page removed the layout and the embedded views of the dashboard. This page is linked from the error message that is shown when you try to delete a contact group a dashboard is still published to. A dashboard with a responsive grid layout then turned into one with a relative grid layout, its embedded views were lost, and opening it failed with a crash report.

The properties page now keeps the layout, the embedded views and the sharing token of the dashboard.

Dashboards that already lost their layout are not repaired. Recreate them, or restore them from a backup.
