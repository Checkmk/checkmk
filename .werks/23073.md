# dell_idrac_fans: fan without speed reading

---------- | ---

Some Dell iDRAC devices report fans (e.g. the second rotor "Fan1_2") with
the status OK but without a speed reading. The check
`dell_idrac_fans` crashed on these fans with
`ValueError: invalid literal for int() with base 10: ''`.

These fans now only show their status.
