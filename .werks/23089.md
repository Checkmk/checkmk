The piggyback hub crashed with `ValueError: invalid host address` when a
file whose name is no valid host name was deleted from
`tmp/check_mk/piggyback_sources`, e.g. a leftover temporary file
`.<source>.new...` or an editor backup file such as `<source>~`.

Such files are now ignored.
