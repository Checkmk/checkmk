# Site connections: no crash on a new site

Saving a new site connection could crash with a `KeyError` on the new
site ID when the page was shown again, e.g. after a validation error,
because the customer field looked the site up in the active configuration,
which does not contain the site yet.

The form now shows the regular customer choice for such sites.
