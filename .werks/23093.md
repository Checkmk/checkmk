# Dynamic host management: no crash on unknown site

key        | value
---------- | ---
date       | 2026-11-11T10:04:05.031675+00:00
version    | 2.4.0p42
class      | fix
edition    | cee
component  | dcd
level      | 1
compatible | yes

The dynamic host management fetches the results of a connection via the
internal REST API endpoint `fetch_phase_one`. If the connection referred to
a site that no longer exists, the endpoint crashed with a `KeyError`.

The endpoint now rejects an unknown site with a validation error.
