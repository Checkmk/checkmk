# Network scan: crash when the run-as user is gone

key        | value
---------- | ---
date       | 2026-11-12T06:08:45.246833+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

When a folder's network scan ran as a user that no longer existed, for
example after the user was deleted or removed by an LDAP sync, the
network scan job crashed with "The user ... used by the network scan of
the folder ... does not exist.". It saved no scan result, so it tried
the scan again a minute later and crashed again.

The scan is now recorded as failed with this message, which is shown in
the folder's network scan status, and runs again after the configured
interval. Choose an existing user in the folder's network scan settings
to make the scan work again.
