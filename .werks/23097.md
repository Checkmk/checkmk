# REST API: crash on a rule value of unknown shape

key        | value
---------- | ---
date       | 2026-11-12T06:20:42.509350+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

Creating or editing a rule via the REST API crashed with an internal
server error and a crash report, for example `KeyError:
'piggybacked_hostname_expressions'`, when the `value_raw` had a shape
that the ruleset could not read. This happened for rulesets that
convert older value formats, such as "Processing of piggybacked host
data".

The REST API now rejects such a value with status 400 and names the
part of the value it could not read.
