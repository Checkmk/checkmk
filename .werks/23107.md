# omd backup: skip UNIX domain sockets instead of failing

key        | value
---------- | ---
date       | 2026-11-10T16:30:53.394627+00:00
version    | 2.5.0p20
class      | fix
edition    | community
component  | omd
level      | 1
compatible | yes

Previously, `omd backup` aborted as soon as it encountered a UNIX domain socket
inside the site directory. The backup failed with:

_Failed to get tarinfo for file '/omd/sites/mysite/local/custom.sock'_

Sockets cannot be stored in a tar archive anyway. `omd backup` now skips them,
prints a warning naming the skipped file on stderr, and continues with the
remaining files:

_Warning: '/omd/sites/mysite/local/custom.sock' is a UNIX domain socket. Excluding it from the backup._

Sockets created by Checkmk itself live below `tmp/` and were never part of the
backup. This change only affects custom sockets placed elsewhere in the site
directory.
