# cmcdump: Fix hosts without services

key        | value
---------- | ---

version    | 3.0.0b1
class      | fix
edition    | pro
component  | cmc
level      | 1
compatible | yes

If a host dumped by `cmcdump -C` had no services, e.g. due to `-S` options,
the site importing the dump failed to create its core configuration. Such
hosts now get an empty list of services.
