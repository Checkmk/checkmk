# cmcdump: Fix dumps with -O

edition    | pro

level      | 1
compatible | no

`-O` options, and `-H` options with filters that hosts and services interpret
differently, e.g. `Filter: groups >= web`, can leave out a host, but not its
services. For such services, `cmcdump -C` failed with an error showing only a
host name, and the core importing the state dump logged "Ignoring command ...:
invalid parameters". Both dumps now leave out these services.

This is incompatible if you dump the state with other `-O` or `-H` options than
the configuration: The services of hosts left out of the state dump no longer
get state updates. Use the same options for both dumps.
