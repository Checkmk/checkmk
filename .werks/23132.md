# aruba_fans: one unknown fan state no longer breaks all fans

key        | value
---------- | ---
date       | 2026-11-17T05:37:48.571448+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If one fan of an Aruba switch reported a state or type that the check
`aruba_fans` did not know, or left out its tray or failure count, the
parsing of the whole section failed, so none of the fan services of the
switch could be checked.

Now only the service of the affected fan shows an UNKNOWN result that
names the value that could not be parsed, next to the values that could.
Checkmk creates a crash report for it that you can send to us. A tray or
failure count that the fan leaves out is simply not shown. The other
fans are checked as before.
