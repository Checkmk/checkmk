# cmcdump: Fix parents with -C and -p

key        | value
---------- | ---
date       | 2026-11-16T11:29:26.326549+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | cmc
level      | 1
compatible | no

`cmcdump -C -p PREFIX` didn't add the prefix to the parents of the dumped
hosts, so the importing site looked them up among its own hosts. The parents
now get the prefix, too.

This is incompatible if the importing site has a host named like a parent: It
is no longer the parent. To keep it, adjust `shadow_hosts` in a `conf.d` file
loaded after the dump. If you added the prefix to the parents yourself, remove
that.
