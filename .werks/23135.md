# aruba_aps: unreadable access point count goes UNKNOWN

key        | value
---------- | ---
date       | 2026-11-17T05:37:55.937337+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If an Aruba switch sent an access point count that is not a number,
the service "Access Points" of the check `aruba_aps` gave no result
and did not say why.

The service now goes UNKNOWN, shows the value it could not parse, and
Checkmk creates a crash report that you can send to us.
