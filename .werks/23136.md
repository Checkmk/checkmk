# cmcdump: Fix -C with multi-line options

A line break in an option of `cmcdump -C`, e.g. in a `-H` option with several
headers, ended the comment with the command line at the top of the dump, so
loading the dump usually failed. Bytes that are not valid UTF-8, e.g. in the
socket path, broke the dump, too. The command line is now quoted for bash, with
these characters escaped.
