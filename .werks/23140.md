# heartbeat_crm: don't crash on enforced services without expected node count

key        | value
---------- | ---
date       | 2026-11-17T06:05:20.494754+00:00
version    | 3.0.0b1
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the service "Heartbeat CRM General" was created as an enforced
service and its rule did not set an expected number of nodes or
resources, the service went to UNKNOWN with `KeyError: 'num_nodes'`.

The check now only compares the number of nodes and resources when the
rule specifies them, and reports the cluster status as usual otherwise.
