# REST API: check password editor and share groups again

key        | value
---------- | ---
date       | 2026-11-17T07:46:44.226587+00:00
version    | 2.5.0p22
class      | fix
edition    | community
component  | rest-api
level      | 1
compatible | yes

A REST API user without the permission to edit all passwords could create
a password that is editable by a contact group they are not a member of.
The password was saved, but the request crashed with `KeyError` because
the user could no longer see it. The same happened when such a user left
*editable_by* out, as it defaults to the admin group. Unknown groups were
accepted, too.

As in Checkmk 2.4.0, the REST API now checks *editable_by* and *shared*
against the contact groups the user may use, and rejects other values
with a 400 error.

A user without that permission now has to name *editable_by* when creating
a password.
