# Views: don't crash on inventory columns of rows without host name

key        | value
---------- | ---
date       | 2026-11-17T08:10:34.423735+00:00
version    | 2.5.0p22
class      | fix
edition    | community
component  | inv
level      | 1
compatible | yes

A view of another data source, for example the log, that shows a host
inventory attribute column crashed with an `AssertionError`, because such
a view does not fetch the host name the inventory column checks.

The inventory cells of such rows now stay empty, and the view is shown.
