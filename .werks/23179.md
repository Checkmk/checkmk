# Docker container CPU, memory and disk IO: don't crash on containers of multiple nodes

key        | value
---------- | ---
date       | 2026-11-17T09:57:17.135960+00:00
version    | 2.4.0p43
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

When two Docker nodes delivered the same swarm container as piggyback
data, the sections `docker_container_cpu`, `docker_container_mem` and
`docker_container_diskstat` crashed with a `ValueError`, because they then
contain the data of both nodes.

Such a container now gets no CPU utilization, memory and disk IO services,
like the other Docker container sections since werk 17769. Its status
service already reports that the container is monitored by multiple Docker
nodes.
