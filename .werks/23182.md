# Agent bakery: don't crash when a rule value cannot be rendered

key        | value
---------- | ---
date       | 2026-11-17T11:39:53.633034+00:00
version    | 2.4.0p43
class      | fix
edition    | cee
component  | agents
level      | 1
compatible | yes

When the value of an agent rule could not be rendered on the agents page,
the page shows "Failed to render value:" followed by the raw value. For
rule values that are not plain text, which is the usual case, this
fallback itself crashed with `TypeError: Unsupported type`.

The fallback now shows the raw value as text.
