# hp_proliant_raid: Crash on empty logical drive row

key        | value
---------- | ---
date       | 2026-11-17T13:37:29.908305+00:00
version    | 2.4.0p43
class      | fix
edition    | cre
component  | checks
level      | 1
compatible | yes

Some HPE ProLiant devices answer the logical drive table with a row in
which all columns are empty.
The section parser of the check plug-in `hp_proliant_raid` crashed on
such a row with "ValueError: invalid literal for int() with base 10".

Rows without a logical drive number are now skipped.
