# Backup: don't crash on an inaccessible local target path

key        | value
---------- | ---
date       | 2026-11-18T06:00:09.265048+00:00
version    | 2.5.0p22
class      | fix
edition    | community
component  | core
level      | 1
compatible | yes

Saving a backup job crashed with `PermissionError` when the path of its
local backup target lies below a directory that the site user cannot
access, for example the home directory of another user.

The job form now shows the error "Local target path is not accessible for
the site user" instead.
