# Backup: don't crash on a target directory the site user cannot enter

key        | value
---------- | ---
date       | 2026-11-18T06:59:40.081760+00:00
version    | 2.4.0p43
class      | fix
edition    | cre
component  | core
level      | 1
compatible | yes

Saving a local backup target, or a backup job using it, crashed with
`PermissionError` when the target directory exists but the site user
cannot enter it.

The form now shows the error "Failed to write to the configured
directory" instead.
