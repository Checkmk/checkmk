# Extension packages: don't crash when a package cannot be fully disabled

key        | value
---------- | ---
date       | 2026-11-18T09:47:55.337629+00:00
version    | 3.0.0b1
class      | fix
edition    | pro
component  | packages
level      | 1
compatible | yes

Disabling an extension package crashed with `PackageError` when one of
the package's files could not be removed, for example because the
package lists a directory instead of a file.

The page now removes all files it can, reloads the affected services and
reports which files could not be removed. The package stays enabled
until the cause is fixed and it is disabled again.
