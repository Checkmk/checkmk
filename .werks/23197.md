# Proxmox VE: don't crash on a replication job without a duration

key        | value
---------- | ---
date       | 2026-11-26T06:39:22.223717+00:00
version    | 2.5.0p23
class      | fix
edition    | community
component  | checks
level      | 1
compatible | yes

If the Proxmox VE API reported a replication job without a duration,
for example a job that has not run yet, the Proxmox VE special agent
crashed with `KeyError: 'duration'`. Such jobs are now monitored like
all other replication jobs.
