# Views: name a missing data source instead of crashing

key        | value
---------- | ---
date       | 2026-11-26T06:52:59.333514+00:00
class      | fix
edition    | community
component  | multisite
level      | 1
compatible | yes

If a view, for example in a dashboard widget, used a data source that
the site does not provide, opening it crashed with
`RecursionError: maximum recursion depth exceeded`. This happens, for
example, with a view on the "customers" data source in an edition
without customer management. The page now shows that the view cannot
be rendered because its data source does not exist.
