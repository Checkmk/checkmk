# Setup: reject form data in an unexpected format instead of crashing

key        | value
---------- | ---
date       | 2026-11-26T07:07:57.457715+00:00
version    | 2.5.0p23
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Setup pages that use the new form elements crashed with
`JSONDecodeError` when a request carried a form value in an
unexpected format, for example when a script called the audit log page
with a plain file name in `selected_filename`. Such requests are now
rejected as invalid input; the audit log shows its default view.
