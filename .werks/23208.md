# OAuth2 connections: don't crash for users without contact groups

key        | value
---------- | ---
date       | 2026-11-26T07:33:48.259834+00:00
version    | 2.5.0p23
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

A user without the permission "Write access to all passwords" who was
not a member of any contact group could not open the OAuth2 connection
form: it crashed with `ValueError: Default element 'contact_group' is
not one of the specified elements`. The form now opens and explains
that the connection cannot be assigned to a contact group because the
user is not a member of any.
