# BI: don't crash on rule pages without a BI pack

key        | value
---------- | ---
date       | 2026-11-26T07:40:43.924721+00:00
version    | 2.5.0p23
class      | fix
edition    | community
component  | bi
level      | 1

Opening the BI rule pages, for example "Edit rule" or the rule list,
with a URL that names no BI pack crashed with an `AssertionError`.
Such requests now show the error "Please choose a BI pack.".
