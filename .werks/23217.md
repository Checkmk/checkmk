# OAuth2 connections: reject token requests without form data

key        | value
---------- | ---
date       | 2026-11-26T09:34:20.469683+00:00
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

The page that requests an access token for an OAuth2 connection
crashed when it received a request without the expected JSON form
data, for example a request that was modified by hand. Such requests
are now rejected with an error message.
