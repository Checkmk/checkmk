# Rules: reject slide-in rule data without properties instead of crashing

key        | value
---------- | ---
date       | 2026-11-26T09:48:45.168919+00:00
version    | 2.5.0p23
class      | fix
edition    | community
component  | wato
level      | 1
compatible | yes

Creating a rule from a slide-in (for example when a special agent rule
is created from within another dialog) crashed with a `KeyError`
when the request did not contain the rule properties or the rule ID,
for example a request that was modified by hand. Such requests are now
answered with a validation error.
