# Sharper corners: user interface uses a 2px corner radius

key        | value
---------- | ---
date       | 2026-11-18T17:22:28.705764+00:00
class      | feature
edition    | community
component  | wato
level      | 1
compatible | yes

Checkmk's user interface now uses a 2px corner radius instead of 4px for
surfaces and controls such as buttons, input fields, menus, dialogs and
dashboard widgets. Elements that were strongly rounded before, for example
some panels and the dashlet resize handles, now use the same 2px radius.

This is part of the new Checkmk visual language. The change applies to
both themes and to both the classic pages and the newer Vue-based pages.
