# ntopng: widgets show a warning instead of crashing without connection

key        | value
---------- | ---
date       | 2026-11-26T10:03:22.090396+00:00
class      | fix
edition    | pro
component  | ntopng_integration
level      | 1
compatible | yes

Some ntopng widgets, for example the interface statistics and the
interface traffic, crashed with "ntopng integration is not activated in
the global settings" when the ntopng integration was not activated or
not configured, for example on a dashboard that still shows ntopng
widgets. These widgets now show this as a warning, like the other
ntopng widgets do.
